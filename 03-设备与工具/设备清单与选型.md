# 设备清单与选型

> Fab Lab 官方标准清单 + 柴火实践清单 + 分阶段采购策略
> 调研时间：2026-08

## 一、Fab Lab 官方核心设备标准

Fab Foundation 对 Fab Lab 的设备要求（"共享工具与流程"准入标准的具体化）：

| 设备 | 用途 |
|------|------|
| **激光切割机** | 2D/3D 结构切割与雕刻（纸、木、亚克力、皮革）|
| **3D 打印机** | 树脂等材料的三维输出 |
| **高精度 CNC 铣床** | 电路板、精密零件、铸造模具 |
| **大型木工雕刻机（Router）** | 家具与房屋构件 |
| **切纸/贴膜机（Vinyl Cutter）** | 柔性电路、贴纸、标识 |
| **电子工作台全套** | 元器件 + 低成本高速微控制器 + 现场快速电路原型 |

**官方清单**（设备 + 工具 + 耗材，research 级 Fab Lab 全量）：
- http://inventory.fabcloud.io/（FabCloud 官方库存清单）
- 历史版本：http://fab.cba.mit.edu/about/fab/inv.html

> 核心理念：**不是设备的堆砌，而是流程与能力的对齐**——保证"我在波士顿做的设计发给你，你在莫斯科能复现"。

## 三、分阶段采购策略（Makerspace Playbook × 柴火指南）

### First / Next / Additional 三段式

| 阶段 | 目标 | 典型内容 |
|------|------|----------|
| **首次购买** | 能开工 | 手工工具、电子焊接工具、万用表、桌面 3D 打印机、基础耗材 |
| **再次购买** | 能造复杂件 | 激光切割机、桌面 CNC、更好的计算机、更多材料 |
| **额外购买** | 能造特别的 | 陶瓷打印、电窑、专业缝纫、水刀、大 CNC |

> 柴火《创客空间搭建及运营指南》附件收录了完整的中文化三段采购清单（第 195–197 页），可直接套用。

### 采购原则

1. **运营目标决定设备**（先定"授课 or 服务会员 or 兼有"，再定清单）
2. **从本地问题与用户兴趣出发**，不要设备先行
3. **复制成熟方案**：参考已完成建设的实验室清单（inventory.fabcloud.io + 邻近 Fab Lab 实际配置）
4. **面向教育时优先"班规配置"**：套件数量按班级规模（如 30 人）配置，而非设备种类堆砌
5. **存储空间与耗材补充机制**在采购期就纳入预算（官方警告：所有实验室都低估了这块）

## 四、设备管理最佳实践

### 德国 maker-space 模式（会员制标杆）

- 全部设备在网站上**按平面图分区域可视化**，可预约日程表公开
- 每台设备有独立主页：图片、介绍、文档、价格、预约日历
- 贵重设备按时计费（如水刀 ¥250/小时级），轻量设备标注"无需预约"
- 单次预约时长上限（如 6 小时）保障公平

### 柴火模式（人性化验证）

新会员申请大型设备 → 管理员询问基本问题确认能力 → 决定直接放行 / 给予必要指导。
**开放优先于管控**——避免"设备展厅化"死循环。

### 设备管理的正反循环

```
正循环：培训后开放使用 → 设备被频繁使用 → 问题早发现早维修 → 用户能力成长 → 反哺空间运维
反循环：怕坏而封闭 → 没人用没人会修 → 坏了闲置 → 用户流失 → 空间沦为展厅
```

## 五、软件环境（Fab 官方栈，全部免费/开源优先）

| 用途 | 软件 |
|------|------|
| 2D 图像 | Gimp、Photoshop、MyPaint |
| 矢量设计 | Inkscape、LibreOffice Draw、Illustrator、Scribus |
| 3D 建模 | FreeCAD、OpenSCAD、Rhino 3D、SketchUp、SolidWorks |
| 电子设计 | KiCad（Fab 生态常用）、EDA 工具链 |
| 音视频 | Audacity、KDENLIVE、FFMpeg |
| 仿真 | Elmer、COMSOL、Ansys |
| 教育云端 CAD | xDesign（SOLIDWORKS 3DEXPERIENCE，Fab-in-a-Box 配套）|

计算环境：Windows/Ubuntu 双系统，工作流程尽量跑在 Linux 分区。
