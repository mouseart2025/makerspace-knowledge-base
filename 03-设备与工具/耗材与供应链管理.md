## 一、耗材为什么重要

- **成本占比高**：Delaware Design Studio年运营$50k中，材料/耗材约占50%；Fab标准运营预算中耗材约占40-50%
- **断供即停摆**：耗材缺货直接导致设备闲置、教学中断
- **浪费即流失**：耗材易被无序领用、过量囤积、过期报废
- **管理可量化**：耗材消耗数据是使用率、成本效率的晴雨表

## 二、耗材分类清单

### 2.1 按功能区分类

| 功能区 | 典型耗材 |
|--------|---------|
| **数字制造** | 3D打印线材（PLA/ABS/PETG/树脂）、激光切割板材（亚克力/木板）、CNC刀具/毛坯、砂纸 |
| **电子制作** | 焊锡、导线、面包板、电阻电容、Arduino/传感器套件、杜邦线、热缩管 |
| **手工/木工** | 木材、胶水、螺丝五金、涂料、砂纸、刀具耗材 |
| **机器人** | 电池、电机、螺丝、结构件、打印备件、润滑油 |
| **新能源** | 绝缘胶带、热缩管、电池极片/测试耗材、防滑垫 |
| **通用** | PPE（护目镜/手套/口罩）、清洁用品、打印纸、标记笔 |

### 2.2 按属性分类

| 类型 | 特点 | 管理策略 |
|------|------|---------|
| **A类高频低成本** | 焊锡、线材、胶带 | 批量采购、低值易耗、宽松领用 |
| **B类中频中成本** | 打印线材、木板、电池 | 安全库存+限量领用 |
| **C类低频高成本** | 专用刀具、树脂、特殊材料 | 按项目申请、严格控制 |
| **危险品** | 溶剂、喷漆、树脂 | 专用柜、双人领用、台账 |

## 三、预算与采购

### 3.1 40/40/20预算规则（Edu Lab China）

> 采购预算分配参考：**40%数字制造设备 + 40%模块化家具与安全设施 + 20%初始耗材与备件**。["https://www.edulabchina.com/blogs/what-is-a-maker-space-and-what-equipment-does-it-need/"]

> 年运营中耗材占比：Delaware约50%、通用实践40-50%。

### 3.2 采购策略

| 策略 | 说明 |
|------|------|
| **安全库存** | 安全库存 = 日均消耗量 × 补货周期 + 波动缓冲量["https://www.jiandaoyun.com/nblog/463696/"] |
| **建议采购量** | 建议采购量 = 目标库存 - 当前可用库存 - 在途量 |
| **ABC分类** | A类严格管控、B类常规、C类宽松 |
| **FIFO先进先出** | 防止线材/树脂等过期 |
| **供应商管理** | 核心耗材锁定2-3家供应商，比价+备选 |
| **集中采购** | 学期初集中采购、批量议价 |

### 3.3 耗材单价参考（3D打印示例）

| 耗材 | 规格 | 参考价 | 消耗节奏 |
|------|------|--------|---------|
| PLA线材 | 1kg/卷 | ~80-150元 | 每台FDM每月约1卷（教学） |
| 树脂清洗液 | 环保型1L | ~120元 | 2台SLA约每2周1瓶 |
| 激光亚克力板 | 3mm | ~15-30元/张 | 按项目 |

> 参考中小学创客课堂3D打印材料采购清单["https://doc.mbalib.com/m/view/d77aed8d7e1987cf7d483c580bde8035.html"]、Algonquin创客空间材料价格表["https://makerspace.aapld.org/visiting-us/material-price-list/"]

## 四、库存与领用管理

### 4.1 管理流程

```
入库（验收登记） → 库存管理（库位/数量/安全库存） → 领用（登记/限量） → 盘点（定期） → 报废/补充
```

| 环节 | 要点 |
|------|------|
| **入库** | 验收、编号、货位编码、录入台账 |
| **库存** | 库位编码+二维码标签，"找得到、算得清" |
| **领用** | 登记制，A类限量、B类审批、C类申请 |
| **盘点** | 学期初末全面盘点，季度抽查 |
| **报废** | FIFO过期清理，走报废流程 |

### 4.2 差异化库存策略（简道云实践）

- 针对不同类型耗材制定差异化策略（安全库存、FIFO、ABC分类）
- 重构入库、出库、盘点、报废业务流程，让每一次耗材流转有迹可循，避免账实不符和责任不清
- 数据驱动：利用库存数据分析消耗规律、优化补货
- 来源：["https://www.jiandaoyun.com/nblog/471522/"]

### 4.3 二维码信息化

| 方案 | 说明 |
|------|------|
| 耗材柜/箱贴码 | 扫码看库存、领用登记、盘点 |
| 开源库存App | maker-studio-inventory（Android）：扫码入库、重量/数量更新、库位绑定、二维码盘点["https://github.com/llleeeqi/maker-studio-inventory"] |
| 电子元件全生命周期追踪 | 多层级分类、BOM管理、状态监控（在用/闲置/报废）["https://blog.csdn.net/gitblog_01169/article/details/156501929"] |
| 进销存表 | 单位换算规范、库存周转率分析["https://www.jiandaoyun.com/nblog/463696/"] |

## 五、成本控制与节约（7S"节约"维度）

| 措施 | 说明 |
|------|------|
| **限量领用** | 设置个人/项目月度额度 |
| **共享耗材池** | 公共耗材统一管理，个人项目按量计价（如有收费） |
| **边角料利用** | 木板/亚克力边角料回收做小件 |
| **打印优化** | 3D打印填充率/支撑优化，减少废料 |
| **待机管理** | 设备待机断电，节能 |
| **采购比价** | 批量+比价+国产替代 |
| **学期预算制** | 每学期固定耗材预算，超支审批 |
| **消耗数据化** | 耗材消耗与项目数/课时挂钩，异常预警 |

## 六、材料收费模式（开源/教育实践）

| 模式 | 适用 | 说明 |
|------|------|------|
| 免费（校内教学） | 课程实训 | 校内经费覆盖，教学耗材不计费 |
| 按量收费（个人项目） | 个人/竞赛项目 | 打印按克、激光按时、材料按成本价 |
| 材料成本价+服务费 | 对外服务 | 科普研学、企业服务 |
| 耗材包/订阅 | 会员制 | 月度耗材额度 |

> 参考：Algonquin创客空间材料价格表公开透明定价（如樱桃木12"×12"×1/8" $6，限量每周2片）["https://makerspace.aapld.org/visiting-us/material-price-list/"]
