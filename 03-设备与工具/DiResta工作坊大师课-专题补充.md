# DiResta 工作坊大师课——工具哲学与工艺速查（专题补充）

## 一、作者速写：为什么值得读他

**Jimmy DiResta**，美国创客圈顶流 YouTuber，前纽约玩具设计师（持 25 项专利），曾主持 HGTV《Hammered》、Discovery《Against the Grain》等节目。他的路径是"工业设计师 → 自由制作人 → 内容创作者"，30 年手作经验横跨木、金、塑、皮四大材料。

三个标签：
- **全能型手艺人**：不是某一道具的专家，而是"什么活都接、什么料都做"的通才——这正是创客空间讲师的原型画像
- **内容创作先驱**：视频不讲精确 how-to，讲"我怎么试、怎么错、怎么修"——与知识库 [DMP 教育方法论](../04-运营与管理/设计-制作-玩耍教育方法论.md) 的 Play 精神互证
- **节俭的务实派**：大量设备是二手捡来的、工具是自己修复/自制的——低成本创业的方法论样本

## 二、大师工具哲学（五条核心理念）

| # | 理念 | 原书语境 | 对柴火的启示 |
|---|------|---------|-------------|
| 1 | **第一台机器买带锯** | "可切直线、曲线，可切金属/木/塑料/皮革——是最万能的入门机器" | 零基础个人工作室的采购第一性建议；空间级采购仍按 Fab Lab 清单走（两者不冲突） |
| 2 | **二手设备是正道** | 整店收购带锯 $100、South Bend 车床 $500–$2300、Wilton 虎钳回收场 0 元、1965 年 Bridgeport 铣床免费送、Grizzly 钻床免费 | 美国渠道：回收场、整店收购、搬迁甩卖。**国内映射：闲鱼、厂房搬迁、废品站、设备租赁商换代**。老铸铁机比新入门机精度更稳 |
| 3 | **免费接活学习法** | "I still take jobs for free to learn new things"——为学 CNC 什么单都接 | 空间冷启动期可接社区低偿活儿练手 + 积累案例，与"教育产品化"路线互补 |
| 4 | **视觉判断标准** | "Visually, if it looks right, it is right"（没人拿千分尺量招牌） | 工艺类课程的验收观：非精密件用目视 + 手感验收，别用工程标准吓退初学者 |
| 5 | **工具分级使用** | 钻头分"好套/坏套"（好套=数量齐全可带工地）；自己的好凿子谁都不许碰（DO NOT USE） | 就是柴火"讲师专用 vs 会员公用"的美国民间版——印证 [工具组织与现场管理](工具组织与现场管理.md) 的分级思路 |

## 三、工艺速查表（三张最实用的表）

### 3.1 胶水选择表（全书最实用）

| 胶水 | 适用场景 | 要点 |
|------|---------|------|
| 木工胶（PVA，黄胶）| 木-木常规粘接 | 强度高于木材本身；夹持时间足够 |
| 3M 喷胶 #77 | 临时定位、模板贴附 | 低粘可反复揭下 |
| 3M 喷胶 #90 | 永久贴附 | 与 #77 的区别就是"可拆 vs 不可拆"，别买错 |
| CA 胶（502）+ 活化剂 | 快速定位、小件 | 喷活化剂实现"秒干"，木工里先 CA 定位再补 PVA 是经典组合 |
| PVA 白胶 | 皮革贴木 | 干后保持柔韧，不会把皮革弄硬 |
| West System 环氧 + 填料 | 结构性粘接、填补 | 加填料（胶衣粉/木粉）可调色、增稠；修补铸铁件的神器 |

### 3.2 CNC 刀具速查

**刀具五要素**：柄径（夹头规格）/ 切削直径 / 总长 / 齿数 / 排屑方向。

**排屑方向三种**：
- **Up-cut（螺旋向上）**：排屑最好，但会把板材往上带——切薄板会飞
- **Down-cut（向下）**：把板材压住，上表面切口干净，但屑往下堵
- **Compression（上下合压）**：进出口都干净， Plywood 贴面件首选，贵

**七种常用刀型**（按用途）：平刀（开槽/开料）、球刀（3D 曲面）、V 刀（刻字/V 槽）、圆鼻刀（粗加工留强度）、燕尾刀（拼板）、凿孔刀（hinge 槽）、泡沫锯刀。

> ⭐ **60° V 刀是 CNC 入门首选**——刻字、打标、V 槽折弯都能干，几乎切不动自己（安全）。

### 3.3 Styrene（ABS 板）全套工艺

塑料章节最成体系的一节——**styrene 是道具/模型制作的标准材料**：

- **切割**：薄板"划 + 掰"（美工刀划深线后直接掰断），厚板上锯
- **冷弯**：薄料绕心轴冷弯即可成型，**比加热热弯更好用**（不冒烟不变形）
- **粘接**：Weld-On 溶剂型胶水 + 针头滴瓶——溶剂溶化表面后熔为一体，接缝近乎隐形；针头瓶控制用量防流挂
- **真空成型**：正模（简单、脱模容易）vs 石膏负模（细节好、可吸塑深腔）的选择逻辑

## 四、零散金句工艺汇编（按工种）

### 木工
- **台锯切厚料三段法**：台锯升起切上半 → 翻面再切 → 中间连皮用往复锯收尾（厚料硬切会烧锯+反弹）
- **平刨 snipe（啃头）**：进/出料各垫一块与工件同厚的牺牲板，啃头啃在牺牲板上
- **街捡木料先检查**：混凝土钉、砂粒、金属件秒毁刀具——先用金属探测器或磁铁过一遍，看不出就放弃
- **砂磨进阶序列**：砂纸逐级 → #000 钢丝绒 → 抛光轮 + 蜡；上油件用钢丝绒比细砂纸更柔顺

### 金属
- **铝用粗齿 4TPI**：细齿粘屑堵齿，铝屑把锯齿糊死是新手最常见故障
- **焊接跳焊（分段点焊）**：连续焊道拉高温大变形；点-点-点跳着焊，边焊边校正
- **不锈钢难在导热差**：热量局部堆积，低速低压力多道次

### 塑料/皮革（精选）
- 亚克力激光切完别急着掰支撑边——内应力会让它自己裂，先在切口保温缓冷
- 皮革裁切用旋转刻刀 + 自制模板；缝线先打菱斩孔再手缝，机器缝反而打皱

## 五、自制与修复工具（第 7 章精华）

这章是"创客文化"的黄金素材——工具本身就是作品：

| 案例 | 工艺链 | 教学价值 |
|------|--------|---------|
| **斧头修复** | 喷砂除锈 → 旧柄当样板 → 铝坯带锯切八面 → 锉磨成型 → 铜楔锁死 | "测绘 → 复制 → 装配"完整闭环，一天可完成的入门修复课 |
| **锉刀变匕首** | 锻打退火（软化）→ 磨形 → 重新淬火 + 油淬（回硬）| **热处理闭环**教学案例：退火/淬火/油淬一次讲清，成本≈0 |
| **冰锥量产 1000+ 支** | CNC 刻标 → 车床批量 → CA 胶可换头设计 | 个人创客**小批量生产**完整样本：设计-for-量产思维（可换头=可维修=可持续卖） |

## 六、对柴火的落地建议

1. **设备采购章增补**：在 [设备清单与选型](设备清单与选型.md) 增"二手渠道与验机要点"小节——闲鱼/厂房搬迁/设备商换代三类渠道 + 老铸铁机验机清单（导轨、主轴间隙、电气）
2. **工艺课素材**：3.1–3.3 三张速查表可直接进激光/CNC 分层准入培训的讲义附录
3. **修复工坊活动**：第 7 章三个案例适合做成"工具修复日"社区活动——旧工具捐赠 + 会员修复 + 成果展示，一举三得（社区活跃 + 技能培训 + 空间素材产出）
4. **教育观引用**：DiResta 的"我不是在教你正确方法，我是想激发你自己去试"——可作为 M0/训练营讲师培训的开场引言
5. **低成本叙事**：二手设备 + 自制工具的案例库，是向政府/园区汇报"创客精神=资源再利用"的现成故事
