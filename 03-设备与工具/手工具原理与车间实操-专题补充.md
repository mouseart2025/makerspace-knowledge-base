## 〇、一句话核心

**工具的差别不在「有没有」，而在「同一件工具有 8 个变体、你知不知道该挑哪个」；车间的效率也不在「买了什么」，而在「常用的是否离你最近、夹得够不够牢、刃口还利不利」。**

Platt 的教法可以一句话概括：**先给你一个要做的小物，再让工具在做的过程中出场**——而不是先摆一张工具清单让你背。Branwyn 的教法则是反过来：**把散落在无数视频与文章里的「那 10 秒钟的诀窍」收集成一本可检索的手册**。

## 一、Make: Tools 的教法：20 个递进项目 = 一条工具学习阶梯

### 1.1 结构：三条腿 —— 木 → 塑料 → 车间本身

全书 20 章各有一个可完成的小项目，**材料主线是「木 → 木+五金 → 塑料 → 透明塑料 → 彩色塑料 → 车间」**，每一章只引入 2–5 个新工具或新知识点。这个顺序本身就有教学含义：**先让读者在便宜、容错、可反复重做的木材上把「锯直、钻正、夹牢」练出来，再进入不可逆、有化学风险的塑料加工。**

| 章 | 项目 | 本章新引入的工具 / 知识点 | 台阶作用 |
|---|---|---|---|
| 1 | A Perplexing Puzzler | 测量、斜切盒锯（miter box）、砂纸修边、粘接与夹持、聚氨酯涂装 | 建立「测量→锯→修→粘→夹→涂」最小闭环 |
| 2 | The Curious Cube | 立体粘接（gluing in 3D） | 从平面转立体，第一次遇到「夹持顺序」问题 |
| 3 | Big Dice | 硬木 vs 软木、木纹与翘曲、不用斜切盒锯的锯法、模板、刷漆 | 引入**材料各向异性**（顺纹/逆纹）这一木材加工的根本变量 |
| 4 | Nailing It | 敲钉手法、钉入统一深度、绘图案、**钉子种类**、**锤子种类** | 补上「最基本的操作其实最不简单」 |
| 5 | Framing It | 角度测量、斜接角、非矩形框架、自制夹具（jig） | 引入「**夹具 = 把技巧固化进木头**」的思想 |
| 6 | A Geometrical Jigsaw | 胶合板与复合板、矢量绘图软件、纸样转印、木器染色、整边切板 | 第一次把**数字工具**（矢量软件）接进手工流程 |
| 7 | A Piece of Parquetry | 拼花、环氧胶 | 精度与拼缝，粘接剂升级 |
| 8 | Drilling It | 钻的选用、钻头认识、**钻出干净且垂直的孔** | 钻孔是全书的第二个核心动作 |
| 9 | A Swanee Whistle | 另一种夹具、精密钻孔、哨子的发声原理 | 「为什么响」——工具与物理原理挂钩 |
| 10 | A Basic Box | **螺钉种类**、**螺丝刀种类**、3D 设计、**角接种类** | 从钉转螺钉，引入可拆连接 |
| 11 | A Bare-Minimum Bookcase | 书柜设计要素、**不下垂的层板**、木塞对接 | 第一次做「承重结构」，引入挠度概念 |
| 12 | Hanging On the Wall | 挂而不掉、钢/塑料挂件 | 从「做东西」转向「把东西装到墙上」 |
| 13 | A Monster Truck | **曲线锯（coping saw）**、扩孔与塑孔、金属锉 | 从直线到曲线 |
| 14 | A Pantograph | **螺母/螺栓/垫圈**全解、螺栓 vs 木螺钉的取舍、连杆/枢轴/摩擦 | 从「固定连接」到「可运动连接」 |
| 15 | Bending It | **ABS 塑料的切割与热弯** | **材料切换点**：木 → 塑料 |
| 16 | A Better Box | **ABS 溶剂粘接**（solvent cement） | 塑料的化学连接，首次要求防化手套与护目镜 |
| 17 | Another Better Box | ABS + 不锈钢自攻螺钉 | 塑料的机械连接 |
| 18 | Transparency | **聚碳酸酯与亚克力** | 从「不透明塑料」到「透明塑料」，工艺窗口不同 |
| 19 | Color | 透明/半透明/不透明彩色塑料、**终极斜切夹具**、用锯切槽 | 综合：把前 18 章的技艺合成一件作品 |
| 20 | More Tools | **工作台规格**、**工具与材料储藏**、补充手工具、基础电动工具 | **视角反转：从「做东西」转到「做车间」** |

### 1.2 三条读法（对本库的用法）

**读法一：把第 20 章当第 1 章读。** 全书唯一直接讲「工作台怎么造、工具怎么存」的是第 20 章，但它是**先做 19 个项目、踩够了坑之后才给的建议**。给创客空间用，可以反过来先读——因为它给的是**硬件规格**而不是感受。

**读法二：每章的 "NEW TOPICS IN THIS CHAPTER" 框就是学习目标清单。** 该书每章开头固定给出「本章新知识点 + 需要准备的材料清单（YOU WILL NEED）」，**这个格式本身就是课程设计的可复用模板**：一个项目 = 一句新知识 + 一张料单。

**读法三：第 5、9 章的「自制夹具」是全书的暗线。** Platt 反复演示：把一件依赖手感的事，转成一件依赖夹具的事。**这条暗线直接对应创客空间的对外价值——让初学者也能做出稳定的结果。**

## 二、工作台与储藏：可直接抄的规格（第 20 章）

这一节的价值在于**给的是数字与理由，不是审美**。

| 项目 | Platt 给出的规格 | 背后的理由 |
|---|---|---|
| 台面材料 | **¾″（19mm）胶合板**最优；OSB 可但不够光滑；刨花板易碎 | 不需要高等级，单面好（good-one-side）就够 |
| 台面深度 | **前后 24″–30″（610–762mm）** | 大部分作业在**前缘**完成；太深只是浪费 |
| 台面后缘 | **应贴墙** | 钻头之类的小件滚落时不会掉到看不见的地方 |
| 稳定做法 | 台面下 **2×4 木方框架**，脚用 2×4 或 4×4；**2½″（64mm）地板螺钉**拧紧连接；**腿对间距 24″（610mm）** | 间距 24″ 时台面足够强，可以在上面敲打 |
| 台高 | **站在台边、手臂弯曲时，台面略低于肘部** | 既可用体重压住工件，又不必低头看细节 |
| 不能靠墙时 | 加**背板**（¼″ 胶合板，多点固定）+ **端板** | 提高刚性 |
| 核心判据 | **"不需要好看，必须绝对牢固"** | 工件一动或一振，就会出错 |
| 附加工作桌 | **两张 48″×48″（1220×1220mm）独立桌，中间留 3″（76mm）缝** | 可绕桌走；**长料切割时锯片下探进缝里**，无需同时支撑两侧 |
| 工具收纳 | 两条路线：**挂墙/洞洞板**（取用最快）vs **装箱贴标**（防尘、整洁） | Platt 选后者：**≥50 个贴标塑料箱**，做项目时只取出需要的；洞洞板做「合页翻页式」并不比开箱快，且更费墙面 |
| 收纳的唯一铁律 | **"任何体系都行，但必须被想过、规划过，而不是自然长成"** | —— |
| 板材储存 | **可放 48″×48″ 的可移动板架，装大脚轮**，两面可存取、后面好打扫 | 余料不可能为零，必须预留存放 |
| 长条料储存 | 传统用货架，但占墙面且不易翻找；Platt 主张**竖立存放**，或用**上下两层铁丝网格箱**，每根从孔中插入对应孔位 | 小占地、可分类 |
| 紧固件收纳 | 方法化的**贴标 + 颜色编码**零件抽屉 | 做到「再也不用翻找」 |
| 临时工作台 | **锯木架（saw horses）+ 一块 ¾″ 胶合板** | 需要把作业搬到室外时的即插即用方案 |
| 照明 | **容易被忽视，但精密作业与安全都依赖它** | 亮度是安全项，不只是舒适项 |

## 三、补充工具与电动工具：Platt 的选购顺序

Platt 的判断有价值，因为**他明确给出了排序与理由**，而不是罗列清单。

### 3.1 手工具补充（按「什么时候你会需要」）

| 工具 | 补它的理由（Platt 原意） |
|---|---|
| 长直尺 36″/48″ | 18″ 只够小件；48″ 可横跨整张标准胶合板划线 |
| 卷尺 | 小件加工里不易用准；**它的场景是家装维修，不是精细制造** |
| **卡尺** | 要量钉径/棒径，靠直尺只能得模糊值；**带表卡尺（dial caliper）不需电池**，最小刻度可到 1/1000″ |
| 更多夹子 | 建议起步：**大中小快速夹（trigger clamp）各 2 把 + 至少 1 把螺旋夹** |
| 更多锯 | **钢锯（hacksaw）必备**，哪怕不做金属——剪螺栓用；建议试**日式拉锯**；**工具箱锯可比夹背锯「切入切口中」** |
| 钳类 | 中型水泵钳、长嘴电工钳、**双关节钳**（小件大力）、**钢丝钳（lineman's）**、**锁定钳（Vise-Grip）** |
| 金属锉组 | 不只锉金属：**硬木可用、塑料锯边可去毛刺** |
| 木锉（rasp） | 粗齿快削，只能做**粗略成形**，之后必须换砂磨 |
| 扳手 | **可调扳手不够好**；应上**小套筒组** + **内六角（Allen）全套，公制英制都要** |
| 金属剪 | 剪薄金属板，也可剪地毯、剪塑料棒 |
| 断线钳 | 粗线、粗缆 |
| 玻璃刀 | 用金刚石轮划痕、对棱再掰；**先练几次、必须戴手套**（玻璃边可锋利如手术刀） |
| 台虎钳 | 有工作台就该装；**夹金属的虎钳夹木头时要垫软料**（Platt 用 L 形塑料条） |
| 车间吸尘器 | 集尘是车间作业必需环节；**软管要能接电动锯，在源头吸尘** |
| 砂磨设备 | 见 3.3 |

### 3.2 砂磨设备：Platt 的明确排序

> **有用程度排序：台式盘砂机（disc sander）> 手持偏心砂光机（orbital）> 装机砂盘（sanding disc）> 手持带式砂光机（belt sander）。**

| 设备 | 优劣（Platt 的判断） |
|---|---|
| 台式盘砂机 | 优点：**把工件送到砂盘**（不是反向），控制好得多；带可 90° 或带角度刻度的托台；盘径常 ≥8″（203mm）；多数机型兼有砂带（顺纹磨、可整平）。**不必买名牌高端**。缺点：机身后面集尘袋收不到多少灰 |
| 手持偏心砂光机 | 平面磨平且均匀极佳；**圆边不好用**；靠魔术贴砂碟、碟片带孔（自带小吸尘）；**大部分灰能进袋** |
| 装机砂盘 | 最便宜；装在电钻夹头上。缺点：① 要在「钻孔」和「磨」之间换装 ② **不适合磨平面**——手持扫动难以走直线，易留下月牙形痕迹。适用：**倒边、用细砂去除平面小瑕疵** |
| 手持带式砂光机 | 对「把大件磨平」这件事很强，但**通用性差** |
| ⚠️ 安全 | **转动的砂纸看起来不危险，但皮肤比木头软得多**：一碰就去掉表皮；手可能被夹在托台与砂盘之间的缝里；碰到砂盘边缘会在几分之一秒内削出一道沟 |

### 3.3 电动工具：按「看起来最安全 → 最危险」排序

Platt 用**风险递增**来组织电动工具介绍，这个排序本身就是一份安全教学顺序：

| 序 | 工具 | 关键判据 |
|---|---|---|
| 1 | **台钻（drill press）** | 价值全在**精度**：钻头垂直、工件可固定角度、**有标尺告诉你钻了多深**、转速可通过塔轮皮带调整；**台式（bench-mounted）够用，不必买 5 英尺落地式**；必须配**台钻虎钳**夹工件 |
| 2 | 饼干榫机（biscuit jointer） | 内含水平圆锯片，在木料边缘开出月牙槽，两件对准后夹入压缩木「饼干」+ 胶——**它让「对齐」这件事不再必需** |
| 3+ | （其余手持电动工具） | 原文顺序即为「越来越危险」，讲评中反复强调**夹牢 + 试走一遍流程** |

## 四、Tips and Tales：21 类车间技巧地图

Branwyn 把全书分成 21 章，**这个分类本身就可以直接当作一间创客工坊的「作业知识树」**。下表给出每章的定位与它最值得记的一条。

| 章 | 主题 | 该章最值得记的一条 |
|---|---|---|
| 1 | Organizing 组织 | **第一取用顺序**（Adam Savage）：**越常用的工具/材料放得离你越近**，偶尔用的放远 |
| 2 | Project Planning 项目计划 | 「先画图，哪怕你觉得自己很清楚」；**画图不够就做模型，模型不够就重新定义问题、去翻书** |
| 3 | Measuring 测量 | 徒手测量法、用指甲/三指测刃口（见 §五） |
| 4 | Marking 划线 | 划痕线（scratch a mark）比铅笔线更可靠 |
| 5 | Cutting 切割 | 组合角尺/速度角尺（speed square）的用法：量角、划线、当靠尺 |
| 6 | Clamping 夹持 | **"夹子永远不够"**；买耗材时顺手加两把；**夹口的软垫防压痕**（皮革边角料） |
| 7 | Joining 连接 | **接头做「凸出」（proud）再磨平**——让接缝最后必然齐平 |
| 8 | Gluing 粘接 | 胶的历史与用法；**双面胶暂时固定小零件并标注位置**，拆装不丢件 |
| 9 | Drilling 钻孔 | 定位、防崩边、垂直度 |
| 10 | Fastening 紧固 | 「若它动了但不该动 → 胶带；若它不动但该动 → WD-40」 |
| 11 | General Electronics 电子 | **在 eBay 上买元件的出价与验货要点**（含"拍卖杂项"注意事项） |
| 12 | Soldering 焊接 | 焊点判断与维护 |
| 13 | Molding and Casting 翻模与浇注 | 模具与浇注基本流程 |
| 14 | Sanding and Finishing 砂磨与表面 | **从粗砂纸起步逐级变细**；直接上细砂纸永远得不到好结果 |
| 15 | Painting 涂装 | 表面处理决定涂装质量 |
| 16 | **Sharpening 刃磨** | **15° ≈ 一盒火柴的角度**；**陶瓷马克杯底圈（未上釉部分）= 应急磨石**；水石加洗洁精防堵塞 |
| 17 | **Desktop Fabrication 桌面制造** | 3D 打印/CNC/激光的车间级诀窍（见 §六.4） |
| 18 | Sewing 缝纫 | 家用缝纫机维护（熨斗清洁、底板/蒸汽孔） |
| 19 | Troubleshooting, Maintenance & Repair 维修 | **维修咖啡馆（Repair Café）**模式；**旧电路板上的固定胶会随时间变导电**——检修老电路必须查它 |
| 20 | **Safety and First Aid 安全与急救** | **开工前「彩排」一遍操作**（见 §五） |
| 21 | Miscellaneous 杂项 | 各类跨领域诀窍 |

### 4.1 关于第 20 章的一个判断

Branwyn 专门解释了创客圈那句玩笑 **"Safety third!"** 的用法：它**不是鼓励鲁莽**，而是**反讽一种"过度保护到没人敢动手"的文化**。他给的正面原则是：

> **关键不是回避风险，而是 ① 尽可能了解风险是什么 → ② 知道怎么预防 → ③ 知道出事时怎么办。**

**这条对本库的用法**：创客空间的安全教育若只讲"不许"，会把创客文化里"敢试"的授权感一起掐掉。Branwyn 的框架给了第三条路——**把风险讲清楚，把防护给到位，然后把动手权还给人**。

## 五、Branwyn 的可直接落地诀窍（精选 14 条）

按「落到创客空间哪个环节」归类。

### 5.1 布局与收纳（对应 §二）

1. **第一取用顺序**：常用 → 近，罕用 → 远。这是唯一被标注为来自 Adam Savage 的布局原则。
2. **透明收纳箱**（Make: 编辑 Bill Livolsi）：买透明塑料鞋盒当收纳单元，**按「用途」而非「材质」归类**——例如「砂磨相关」全放一箱，而不是砂纸一箱、砂块一箱、腻子一箱。
3. **设备死角相互靠拢**（Jay Bates）：每台机器都有一面你永远不站过去的「死角」，**把各机器的死角边归拢在一起**，把省下来的操作面留给动线。
4. **工具墙先在纸上排版**（PancakeBot 作者 Miguel Valenzuela）：上墙之前先在纸上摆一遍。
5. **窗帘夹做理线**：桌沿排一排长尾夹即可当理线器。
6. **拆装小零件用双面胶定位**：把双面胶贴在一张纸上，把零件粘在上面并**写下它属于哪个位置**。
7. **降落伞包收纳紧固件**：圆形多格帆布包、抽绳收口，容量大、占地小、可拎走，重型的不到 US$25。

### 5.2 夹持与连接

8. **PVC 自制弹簧夹**：从 PVC/ABS 排水管上切一段圆环、再开一道缝，就是一把弹簧夹；**环切得越厚夹力越大**；加粗橡皮筋可增张力；上下打孔穿螺柱+垫圈+蝶形螺母即可变可调夹。
9. **单手快开快合 C 型夹**：握住手柄，剩下部分自由，**转动手腕让夹子自旋**即可开合——老木匠动作。
10. **填缝枪当夹子 / 夹子当填缝枪**：紧急情况下互为替代。
11. **夹口垫皮革**（Darbin Orvar 的 Linn）：买皮革边角料给夹具和钳口做垫，避免金属在工件上留痕。
12. **延长杆夹**：拆掉原有铆钉，换一根同高同厚的型材条，在新位置钻孔装回挡块，可做出任意长度的杆夹。

### 5.3 刃磨与维护（第 16 章）

13. **磨刀角度**：多数刀在磨石上**与石面约 15°**（"差不多是一盒火柴的角度"），这一角度好记；起始配置建议 1000/6000 双面组合水石。
14. **锋钝自检两法**：① **指甲法**——让刀的自重压在指甲上横拉，**阻力大 = 利，几乎无阻力 = 很钝**；② **三指法**——沿刃口（不是横切）轻拉三根手指，**平滑 = 钝，有阻力 = 利**（有风险，须极轻）。
15. **防堵**：水石上滴一点洗洁精，随着加水一起用。
16. **陶瓷杯底应急磨石**：翻过马克杯，用底部未上釉的圈当磨石磨美工刀/小刀/剪刀。
17. **随身皮拉（keychain strop）**：钥匙串挂一小条皮子 + 研磨膏，随时可修刃。
18. **钻头刃磨角度规**：把两颗六角螺栓固定在废钢/木块上、让两条棱相贴，磨完把钻头放进去对角度；**关键是钻头须与螺栓杆垂直**，角度才正确。
19. **刨底整平**：刨刀留在刨身内但退到完全看不见（保持使用时的张力），砂纸用最低目数、喷润滑剂，然后把刨底在砂纸上磨平。

### 5.4 安全与急救（第 20 章）

20. **开工前「彩排」一遍（rehearse your tool use）**：任何会动的切削/钻孔/冲压电动工具，开机前先走一遍步骤——**椅子高度对不对、有没有线缆挡路、夹具与治具是否都到位并拧紧、头发与衣物是否收好**；作业中持续想「下一步要做什么才不会受伤」。
21. **急救箱三件容易被忘的东西**（英国创伤专科医师 Caroline Lewis 建议）：① **处方药**（很多急救箱自带空药瓶就是为此）② **一次性剃刀**——剃掉伤口周围毛发，胶布/闭合条才贴得住 ③ **好的创伤剪**，它还要能剪开衣服。
22. **三角巾替代法**：用安全别针把袖口固定在胸前衣襟上，**尽量多抓布料**，避免手臂重量把布撕开。
23. **创可贴之外的深切口处置**（Craig Smith 转述，须谨慎）：对**深但不需要缝针、或缝针位置不方便**的切口，氰基丙烯酸酯（强力胶）可作为应急手段；**做法是横跨切口点两三下"缝"，不要沿着切口走、不要完全封死**。⚠️ **本条属急救常识转述，正式场景应以当地医疗规范与专业人员判断为准；创客空间应备正规急救培训与物资，而非依赖此法。**
24. **儿童电子作业 5 条安全建议**：原文单列一节，可作亲子工作坊的家长沟通材料来源。

## 六、向创客空间迁移：可直接采用的 8 条

### 6.1 硬件层（照 §二 规格落地）

| 建议 | 依据 |
|---|---|
| 工作台**靠墙固定 + 加背板**，台面 ¾″ 胶合板、深 610–762mm、高为「站姿肘下」 | 稳定性优先于美观；后缘贴墙防滚落 |
| 至少**一张能绕行走的独立大桌**（或两张，中间留缝） | 长料切割无需支撑两侧；大件作业可绕行 |
| **可移动板架 + 长条料竖放/网格箱** | 余料必然存在，须预留存放位，且要能动、好打扫 |
| 台钻上「**风险递增**」的安全教学顺序 | 让初学者从最可控的机器开始建立信心 |

### 6.2 教学层

| 建议 | 依据 |
|---|---|
| 用 Platt 的**「20 个小项目」结构**做入门课：一节 = 一句新知识 + 一张料单 + 一个能带走的成品 | 每章固定的 "NEW TOPICS + YOU WILL NEED" 框就是现成模板 |
| 入门材料顺序照抄：**木 → 木+五金 → 塑料** | 木材便宜、可重做；塑料不可逆且有化学风险，后置 |
| 把「**自制夹具**」作为独立的进阶主题 | 第 5、9 章暗线：把依赖手感的事转成依赖夹具的事 |
| 安全课用 **"彩排"** 作为动作要求，而不是只给禁令 | 第 20 章：了解风险 → 知道预防 → 知道急救 |

### 6.3 日常运营层

- **刃口管理**：设「磨刀站」与固定周期（Branwyn 的指甲法/三指法可直接印在牌上做自检卡）。
- **维修文化**：可参照 Repair Café 模式做月度开放维修日——与创客空间"让理解技术"的定位天然吻合。
- **耗材纪律**：买夹子当成耗材，随主料一起采购（"夹子永远不够"）；砂纸从粗到细**整级备货**，不要只备细砂。

## 七、局限与注意

| 项 | 说明 |
|---|---|
| 度量制 | 两书全英制，且大量使用北美耗材命名（2×4、#6 螺钉、penny 钉号）。**国内落地须逐项换算并按 GB/国标品对应**，不可直接抄 SKU |
| 价格与渠道 | Branwyn 提到的 Harbor Freight、eBay 竞价、Ponoko 等均为北美渠道；价格区间（如"不到 US$25"）只可作量级参考 |
| 时效 | 《Tips and Tales》成书 2018，其"桌面制造"章部分内容（3D 打印早期技巧）已被今日设备默认能力覆盖；**技巧的"为什么"仍成立，"怎么做"需按现役机型复核** |
| 安全条款 | 书中若干急救技巧（强力胶缝切口等）属北美个人经验转述。**创客空间应以本地法规、职业健康规范与正规急救培训为准**，本篇仅作信息来源标注 |
| 视角 | Platt 明言自己的意见「别人可能不同意」（尤其工具收纳两派之争）。**收纳体系应服从各空间的实际作业频次与清洁要求**，不作教条 |
| 覆盖边界 | 两书**不覆盖**：木工大型机械（台锯/带锯/压刨）、金属加工、焊接结构、数控设备操作——这些需另找来源（本库 [设备摆放与布局规范.md](../02-空间搭建/设备摆放与布局规范.md) 与 [DiResta工作坊大师课-专题补充.md](DiResta工作坊大师课-专题补充.md) 可部分补位） |
