## 一、5S 现场管理法（工具组织的方法论底座）

| 步骤 | 日文/中文 | 本场景含义 |
|------|-----------|-----------|
| 1S 整理 | Seiri | 区分要与不要：坏工具、重复工具、长期不用的——淘汰或归档 |
| 2S 整顿 | Seiton | **定置**：每样东西有固定位置（影子板是 2S 的核心工具）|
| 3S 清扫 | Seiso | 用后即清：工具擦净归位、台面清理 |
| 4S 清洁 | Seiketsu | 标准化：把上述做法固化为检查表和日常流程 |
| 5S 素养 | Shitsuke | 习惯化：全员遵守，靠社区文化而非监督 |

> **关键顺序**（Kaizumi 建议）：**先做标签/台账，再做影子板**——先知道有哪些工具、归谁管，再谈摆放，否则影子板会越做越乱。

## 二、工具墙与影子板

### 2.1 影子板三要素（Flexpipe）

```
① ID 标签（工具名 + 编号，与台账一致）
② 颜色编码（红 = 日用品 / 绿 = 周用品）
③ 轮廓（按工具形状描线/铣槽）
```

**效果**：缺失一眼可见——谁拿走了、少了哪个，路过即发现。这是 5S 整顿（定置）最直观的落地。

### 2.2 制作四步（ToolsRadar 实操）

1. **底板**：3/4"（约 19mm）胶合板 + 1/4"（约 6mm）泡沫板垫层（工具嵌入防滑）
2. **描轮廓**：工具放上描形，激光切割泡沫/铣槽嵌入（OSAAP 等供应商有泡沫激光切割板）
3. **颜色编码**：红色区域放日用品、绿色区域放周用品
4. **上墙**：法式挂条（French Cleat）或直接挂墙

### 2.3 French Cleat 法式挂条（工具墙灵活方案）

- 5 分钟即可**重配置**工具墙布局（工具变多、变少、换位随时调整）
- 成本：约 **$2/平方英尺**（vs 工具柜 $10）——预算敏感期的首选
- 实测收益：**找工具时间 -68%**（2.3 vs 7.1 分钟，ToolsRadar 实测）

### 2.4 选择「上板」工具的决策流程

**只上高频工具**（不是全部）：

```
问：这个工具每天/每周用吗？
  ├─ 是 → 上影子板（红区日用品 / 绿区周用品）
  ├─ 偶尔 → 放抽屉/柜内，贴标签即可
  └─ 几乎不用 → 归档或共享库
```

> 上板过多 → 板面拥挤、维护成本高；上板过少 → 失去"一眼可见"的意义。高频小工具（螺丝刀、钳子、扳手、锤子）是影子板的主角。

## 三、工具标识与盘点（一机一码）

| 机制 | 做法 | 来源 |
|------|------|------|
| **设备台账** | 每台设备/每件贵重工具一档：编号、品牌型号、购入日期、价格、位置、责任人 | 高校制度范本 |
| **一机一码 / 一物一档** | 每件资产贴编号/QR 码标牌，与台账关联 | 小学创客制度 |
| **标签材质** | ⚠️ 油手场景纸标签/油性笔编号**会磨掉** → 用标签打印机（Brother QL 等）或金属标牌 | ACM HCI 研究 |
| **盘点周期** | 每学期末全面盘点（高校范本）；空间常态运营建议每月抽盘 + 每季全盘 | 兰州理工 |
| **数字化** | QR 扫码借还 + 系统台账（见 [设备管理系统选型.md](设备管理系统选型.md)）| #20 |

## 四、借用与归还流程（闭环）

### 4.1 标准流程

```
借用登记（登记本 或 系统扫码）
   ↓
使用（用后即清：擦净、断电、归还原位）
   ↓
归还核验（检查数量/完好性）→ 销账
   ↓
（贵重件）人工核验归还，不纯自助  ← ACM HCI 结论
```

### 4.2 登记要素

| 字段 | 说明 |
|------|------|
| 借用日期/时间 | 用于逾期判定 |
| 借用人 | 姓名/会员号，与安全认证记录关联 |
| 工具编号 | 与台账对应（一机一码）|
| 用途/项目 | 简短记录，便于回溯 |
| 预计归还时间 | 逾期提醒依据 |
| 归还核验人 | 当日值班导师/管理员 |

### 4.3 关键制度点（高校范本汇总）

- **固定摆放点，不得随意移动**；贵重设备不动（兰州理工）
- **外借签批流程**：工具带出空间需管理员签批（合肥工业）
- **每日《设备申领登记表》**：领用归还双向闭环，账实每日相符（小学创客制度）
- **24 小时内故障响应**：归还时发现损坏 → 当日上报（同上）
- **逾期处理**：提醒 → 停借 → （工具图书馆模式）逾期费

## 五、丢失与损坏责任界定

| 情形 | 处理原则 |
|------|---------|
| 正常磨损 | 空间运维成本，不追责（保护"敢用"氛围）|
| 操作不当损坏 | 按制度担责：维修费分担或暂停使用资格（高校范本：操作不当损坏担责）|
| 丢失 | 台账记录 + 责任人说明；贵重件走外借签批可追溯 |
| 故意破坏/私自带出 | 视严重程度：警告 → 暂停会员资格 → 法律途径（极端）|

> 平衡点：**责任清晰但不吓人**——空间开放哲学（见 [设备清单与选型.md](设备清单与选型.md) 正反循环）要求制度给使用者安全感，追责针对「违规操作」而非「正常使用损耗」。

## 六、易耗品与补给（Kanban 思想）

- **耗材双箱/双量法**：每个耗材两个量——「可用量」+「再订购点」，用到再订购点即补货（OpenMakerSuite 的 3×5" 索引卡 + QR 扫码补货是数字化版）
- **补给责任**：每月盘点时清点耗材（螺丝、焊锡、砂纸、胶水、胶带、3D 打印耗材），低于再订购点 → 列采购单
- **供应商留痕**：记录供应商、单价、交期历史（OpenMakerSuite 功能），复购有据
- **采购原则**（工具图书馆经验）：**买易清洗、易维修、备件便宜的型号**——系统救不了难维护的耗材

## 七、智能工具柜（可选数字化升级）

国内商用方案（RFID 电子标签）：无人自助借还、维保/损坏/待归还专用柜格、**关柜自动盘点**、工具定位亮灯、临期预警——工具全生命周期管理。

- **适用**：高频小工具（螺丝刀套装、万用表、电钻）集中管理；开放时段无人值守场景
- **成本**：商业采购，按柜格计价；中大型空间可评估
- **衔接**：与 [设备管理系统选型.md](设备管理系统选型.md) 的台账/借还模块数据打通，避免两套账

## 八、现场管理日常节奏

| 频率 | 动作 |
|------|------|
| **每日闭店** | 工具归位检查（影子板缺口扫描）、台面清理、设备断电、耗材登记 |
| **每周** | 工具清洁保养（按 [设备维护保养规范.md](设备维护保养规范.md) 周级项目）、影子板补位 |
| **每月** | 设备巡检日合并（安全与规范管理既有制度）+ 耗材盘点补货 + 台账抽盘 |
| **每季** | 全面盘点、工具状态评估（淘汰/维修/添置）|
| **每学期末** | 全校/全空间清点 + 年度采购计划（教育场景）|
