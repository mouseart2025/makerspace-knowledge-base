> 书目：Paolo Aliverti & Andrea Maietti, **《The Maker's Manual — A Practical Guide to the New Industrial Revolution》**, Maker Media, 2015（本地 PDF，229 页；4 部分 / 20 章；意文原版作者来自意大利 FabLab 网络，全书案例多取自米兰 Politecnico 与 FabCafe 语境）

## 〇、一句话核心

**数字制造不是"三台机器"，而是"三条链"——每条链都是 `想法 → CAD 模型 → 中间格式 → （CAM / G 代码）→ 机器控制 → 后处理` 同一结构的变体；三台机器的真正区别在"材料怎么来"和"形状自由度从哪来"。**

Aliverti 与 Maietta 的组织方式很干净：**先把工艺按「材料是加上去还是削下来」分成两大族，再把每条链拆成三类软件，最后才讲机器。** 这个顺序保证读者先建立"工艺地图"，再往里填具体设备。

## 一、工艺三族：加法、减法、二维模切（以及它们的组合）

| 族 | 定义 | 对应机器 | 原文的例子 | 创客空间的典型用途 |
|---|---|---|---|---|
| **加法制造**（additive） | **一层一层往上堆材料**直到成体 | 部分 3D 打印机（挤出式） | 挤出机像一支"高科技热熔胶枪"，按电脑模型逐层堆塑料 | 原型件、异形件、替换零件、治具 |
| **减法制造**（subtractive） | 从一整块材料**削掉多余部分** | CNC 铣床（数控机床） | 旋转刀具像牙钻，从木/泡沫/树脂乃至金属块中"解放"出形状 | 板材与块料的精确成形、模具、结构件 |
| **二维模切**（die-cutting / 2D） | **只在二维上切除既有材料**（刀、激光、高压水） | 激光切割机、刀模机 | 切板材；再用拼接把二维件组合出立体（"像木制恐龙骨架套件"） | 亚克力/胶合板结构件、外壳、齿箱、标牌 |
| **组合** | 减法 + 加法互相服务 | 铣床/打印机做模具 → 浇注；或做骨架 → 覆纸浆/玻璃钢 | 用铣床和打印机制出模具，再灌入熔融材料或铺覆层 | 复模、批量小件 |

**判断价值**：写方案或课时，**先问"这件东西的材料是加上去、削下来、还是从板上切出来"**，答案直接决定用哪台机器、需要哪种软件、以及废料与工时怎么估。

## 二、三条软件链：同构的三段式

该书最有迁移价值的结构判断是：**3D 打印与 CNC 铣削需要"三类软件"，激光切割需要"一条矢量链"**——本质上是同一件事的三次实例化。

| 链 | 第 1 段（造模型） | 第 2 段（转成机器语言） | 第 3 段（控制机器） |
|---|---|---|---|
| **3D 打印** | CAD 三维建模 → 导出 **STL** | **切片（slicer）**：把三维网格切成逐层指令 | 打印机固件 / 主机软件（SD 卡直打 或 电脑联机） |
| **CNC 铣削** | CAD 建模 → 导出 **STL / EPS / DXF** | **CAM**：生成刀具路径与 **G 代码** | 机床控制软件 |
| **激光切割** | 矢量绘图（2D）→ **SVG / DXF** | 路径处理：**转路径、拆合、去重复线、排版嵌套** | 激光机控制面板（功率 / 速度 / 焦点） |

### 2.1 关于模型文件的共同事实

- **CAD = 把想法变成"比特"的第一步**。该书点明：多数 CAD 用私有格式，但存在公共标准，**STL 是其中最通用的一个**。
- **STL 的本质是网格（mesh）：用一系列三角形逼近曲面**——**三角形越多，模型定义越细**。这条决定了后续所有"打印出来是圆的还是多边形的"问题。

### 2.2 该书提及的建模软件（按"为什么会被提到"分类，非推荐清单）

| 类型 | 该书举例 | 该书给的理由 |
|---|---|---|
| 参数化 / 工业向 | Rhino（+Grasshopper 插件可做生成式设计） | 易学、格式兼容广、支持参数化设计 |
| 开源全能 | **Blender** | 开源、能力远超建模（还能做流体模拟）；虽非为工程图而生，但**导出 STL 很在行** |
| 简易在线 | Autodesk 123D 系列、3DTin（浏览器内运行） | 上手快；3DTin 免费但**模型须公开共享** |
| 建模 + 出图 | SketchUp Make/Pro | 不直接出 STL，**需插件转换**（多一道手续） |
| 代码化建模 | **OpenSCAD**（ch11，用脚本描述实体） | "懒是好事"——用变量与函数替代重复劳动；作者专门用一整章讲它 |

## 三、3D 打印（ch12）：FDM 的机器事实与切片参数

### 3.1 工艺定位与机器事实

| 项 | 该书给出的事实 | 备注 |
|---|---|---|
| 主流技术 | **FDM（熔融沉积）**——当时"最易得、最划算"，故全书以此为主线 | 其他路线：激光烧结粉末、光固化树脂（SLA）、层叠板材 |
| 运动结构 | 平台沿 **Z 轴**上下；挤出机在 **X-Y 平面**移动；每轴至少一个步进电机（有时一个轴两个） | 驱动电路称 driver |
| 精度 | 步进电机可做到 X/Y 数十微米、Z 约 2.5μm；**但受挤出机尺寸限制，实际层厚一般 100–350μm** | **"定位精度 ≠ 打印分辨率"**——这是选型时最容易搞错的一条 |
| 喷头温度 | 加热到约 **250°C**（部分挤出机可 >300°C）；**必须高于材料熔点**，才能流动顺畅又不至于滴落 | 触摸即伤，换料前必须等温到位 |
| 成形尺寸 | 桌面机主流 **200×200×200mm**，被视为桌面机的"最佳折中"；更大件**分件打印后拼接** | 该书成书年代；今天桌面机尺寸已普遍上移 |
| 简化操作 | 近年机型：装料 + 插 SD 卡 + 按按钮即可 | 典型家用路径 |

### 3.2 材料对比（该书成书时的三大主力）

| 材料 | 熔点 / 挤出温度 | 优点 | 坑 |
|---|---|---|---|
| **ABS** | 熔 105°C；**挤出 215–250°C** | 易得、注塑广泛使用（乐高即 ABS） | ① 打印气味重（本身无毒，**但加热挥发物有刺激性 → 必须通风或排风**）② **冷却收缩不均 → 翘边变形** |
| **PLA** | **挤出 160–220°C** | 玉米/马铃薯淀粉来源、可生物降解；**可在非加热平台打印**；**没有 ABS 那样的冷却变形问题** | ① 成品质量略低于 ABS ② **"优点即缺点"：湿度 >90% 或温度 >60°C 的环境会启动降解，慢慢变成糊状** |
| **PVA** | 比 ABS/PLA 都低 | **水溶**——最适合做支撑结构，事后泡掉 | 与 PLA 同样的储存条件要求 |

### 3.3 切片参数：该书明确给出的"默认值"

| 参数 | 该书建议 | 理由 |
|---|---|---|
| **Perimeters（外壁圈数）** | **3 圈**是好的选择 | 同心向内叠加，**保持外形尺寸不变**；圈数越多壁越厚、越刚，但同时留给填充的空间越小 |
| **Infill（填充率）** | **典型值 10%**（内部 10% 实、90% 空） | 100% 会又重又费料又费时；填充率越高越强；**填充花纹（矩形/六边形…）可试出更结实的配法** |
| **Overhang / 悬垂** | **最大 45°** | 超过就要靠**bridging 算法**（会有毛边）或**加支撑结构**；支撑事后要拆掉，**可能留痕** |
| **Raft（筏板）** | 需要时加 | 防翘角 + 提升附着力 |
| **平台附着辅助** | 玻璃平台 + 发胶 或 固体胶棒；**切勿把发胶直接喷在机器上（齿轮会卡死）** | 另可加 shield / baffle / **mouse ears** 等防变形结构 |
| **后处理** | 砂纸（**必须由粗到细**）、清漆；或用**热风枪**轻烤表面出光泽 | **砂磨时避免吸入粉末** |

### 3.4 平台调平：可量化的判据

- **目标**：平台与喷头距离"不能太远、也不能太近"——太远挤出的料落不到位，太近会堵喷头。
- **起手动作**：**新机开箱也要重调**（运输颠簸会改变出厂设置）。
- **纸厚法（paper test）**：把喷头高度设为第一层高度，用**一张纸**在平台的**四角与中心共 5 个位置**测试——**纸能被拉动、但喷头同时接触纸**，即为合格。
- **自检**：若第一层"糊成一团"，通常是喷头离床太近；若挤出机构发出打滑声，通常是出料过多 → 重新校准，目标仍是"一张纸的厚度"。

### 3.5 换料与运行

- 料线端头必须**切口干净**，否则易卡或不进料；**料盘必须能自由转动**；进料前挤出机须已达温（>180°C）。
- 老式挤出机是打印件 + 拨轮压料，**能看见料走到哪、哪里堵**；新式挤出机封闭紧凑，插孔进料后**一见到喷头滴出细流即可开始打印**。
- 联机软件（该书举例 Printrun / Repetier-Host）可手动输入、读诊断、看温度、**估算剩余时间与层数**；**SD 卡直打的适用场景**：已调好参数、不想带电脑、或一次跑多台机器。

### 3.6 这台机器"能干什么"（该书列的应用面）

机器人零件（米兰理工机器人与 AI 实验室、Michael Overstreet 的工作室）｜**修东西**（做停产零件：书架关节、洗衣机洗涤剂盒）｜**定制**（万向节、手机壳、吉他琴体、任意尺寸电控箱）｜**产品开发快速迭代**（设计→打印→装进去试→改文件→再打印）｜复刻童年玩具 | 手办/模型/地貌细节 | 建筑模型 | 艺术创作。

## 四、CNC 铣削（ch13）：减法链的三条约束

该书用米开朗基罗的比喻定调：**"减法就是把人像从大理石里解放出来"**——它不创造材料，只释放形状。

### 4.1 机器与几何约束

| 约束 | 内容 | 对作业的含义 |
|---|---|---|
| **三轴** | 工件放在工作台上，主轴做三轴运动；**必须定义参考点/坐标原点，且每台机器不同** | 上机前先设原点，否则整件报废 |
| **毛坯与余量** | 除"真实工件"外，**必须额外留出夹持/对位销的位置**，必要时在工件之外另造夹持区（tabs） | **不能只按成品尺寸备料** |
| **主轴可达范围** | 主轴本身有长度与体积**占用相当大空间** | **不能想挖哪就挖哪**——靠近边界与墙的位置挖不到 |
| **夹持可行性** | "怎么可靠地压住工件"是入门 CNC 的第一道难关（Branwyn 另有整节专讲治具） | 夹具设计本身就是课程内容 |

### 4.2 软件链（与 3D 打印同构）

- **CAD**：出 **STL / EPS / DXF**。该书点名 **Inkscape**（免费开源，2D CAD 好用）与 **Autodesk Fusion 360**（对学生/教育者/初创免费，2D 到 3D 通吃）。
- **CAM**：把模型转成刀具路径与 G 代码。该书指出行业现状：**商用 CAM 极贵、界面又旧又复杂**；开源自制机床的普及催生了一批"给创客用"的廉价 CAM——该书推荐 **FreeMill（MechSoft）**，由 VisualMill 派生、免费、算法简单但可用。
- **CAM 操作顺序（FreeMill 为例）**：① 设定机床轴向 → ② 设定毛坯尺寸与余量 → ③ 设定参考点/原点（因机而异）→ ④ 选刀具（平头/圆鼻/球头）及尺寸、主轴长度与参数 → 生成路径。
- **控制软件**：驱动机床执行。

## 五、激光切割（ch14）：二维链的四个专属概念

### 5.1 机器事实

| 项 | 内容 |
|---|---|
| 主流形式 | **CO₂ 气体激光**最普及 |
| 光路 | 激光管固定，**一组可动反射镜**把光束送到平面任意位置（运动方式类似喷墨打印头，但走两轴） |
| 本质 | **激光切割机本质上就是一台 CNC 机床**——读指令、引导刀具 |
| 辅助系统 | 光学聚焦系统 + **吹气/吹风**清除切割碎屑 |
| 空气动力学细节 | 有的机型激光固定、材料移动；有的是材料固定、光束移动 |

### 5.2 三种加工方式（同一台机器，靠功率+焦点切换）

**切（cut）｜划（score，便于后续折断/折弯）｜雕（engrave，写字或画图）**

### 5.3 材料与厚度

可加工：**亚克力、纸与纸板、木、毛毡、织物、橡胶、皮革、有机玻璃（Plexiglas）**；**机器功率够时也可以切部分金属**。
标准厚度为**数毫米**，也有能处理数十毫米的机型。
**二维不等于二维成品**：通过设计卡扣与榫接口，可拼出从简单盒子到复杂产品的三维物；也可用**垂直剖面互插**或**平行薄片层叠**做立体。

### 5.4 四个专属概念（本节的真正价值）

| 概念 | 含义 | 为什么重要 |
|---|---|---|
| **Kerf（切缝损耗）** | 和手锯"吃掉几毫米"同理，**激光也会吃掉材料，只是量级更小** | **必须按切缝补偿尺寸**，否则拼装会松或卡死 |
| **嵌套（nesting）** | 把件排布到最少空白 | **激光切割的成本与"加工时间 + 材料"直接相关**——排版即省钱 |
| **重复切割线** | 两个形状相邻时会共用一条线 → 该线被切两遍 | **既伤材料又浪费能量**；须先做并集/拆分把重复线去掉 |
| **矢量路径化** | 文字与位图都要先转成路径（Path）；位图用 **Trace Bitmap** 描边后再清理冗余路径 | 激光只认矢量；这一步是激光链里最容易出错也最耗时的一环 |

### 5.5 开放与外包

- **开源机型：Lasersaur** —— 开源激光切割机，安全与功率满足创客需要、成本合理，**全流程文档化**（可 fork 项目、克隆文档库作为起点）。
- **"不该自己买"的判断（该书原话立场）**：**即便有开源方案，能负担得起激光切割机的仍是少数**。好消息是**切割服务遍地都是**（该书建议直接搜 "laser cutting service"），很多服务商还能在建模阶段帮忙；**激光切割机是 Fab Lab 与多数 makerspace/hackerspace 的标配设备**，与其买，不如加入或付费使用邻近空间的机器。

## 六、外包路线：先算"该不该自己做"

该书在三条链上各给了一次相同的建议——**没有机器不等于做不出**：

| 工艺 | 该书点名的在线原型服务 | 使用方式 | 计价因素 |
|---|---|---|---|
| 3D 打印 | **Ponoko、3D Hubs、i.materialise、Shapeways、Sculpteo** | 注册 → 传文件 → 从材料目录选料（视地区可含金属）→ 下单 → 数天到数周收货 | **材料、尺寸、填充参数** |
| 激光切割 | 大量本地切割服务 | 上传矢量文件即可 | 材料 + 切割时间（故与 nesting 相关） |

**服务的额外价值**：多数服务商提供建模建议，**有些会主动指出模型里的错误与问题**——对没有经验的团队，这等于半个技术评审。

**对创客空间的判断**：**"买设备"和"用服务"不是二选一，而是按使用频次分层**，与本库 [设备清单与选型.md](设备清单与选型.md) 的选型逻辑一致——高频、教学必需的买；低频、贵、且有人代劳的先外包。

### 7.1 第 5 章"需求"一节的四条性质（值得单独记）

该书给出的**需求（Requirements）≠ 功能清单**，而是"能帮我们弥合用户体验缺口的那组特征"，并列了四条容易踩的性质：

1. **不同用户对同一问题有不同需求**
2. **需求之间可能互相矛盾**
3. **需求的价值并不相等**
4. **需求的种类也不相同**

**做法**：**先全部列出，再做归类**；需求获取既可由自己完成，也可让目标人群参与。

> 这条与本库 [SLP系统布置设计-专题补充.md](../02-空间搭建/SLP系统布置设计-专题补充.md) 的"P-Q-R-S-T 输入"、以及 [设备落位与3D表达方法论](../02-空间搭建/AI空间方案工作流-九阶段端到端方法论.md) 里"先定口径再落位"的纪律同构：**都是先把需求/输入结构化，再动手**。

## 八、对创客空间的可迁移结论（6 条）

1. **把"工艺族"而不是"机器名"作为空间规划的单位**：一间空间的功能区若按"加法区/减法区/二维区"划分，比按"3D 打印房/CNC 房"划分更容易被非专业读者理解，也更经得起设备换代。
2. **三条软件链要作为教学主线显式讲**：用户最容易卡住的不是"不会建模"，而是**不知道 STL 之后还有切片、DXF 之后还有 CAM、SVG 之前还有路径化**。把这三次"转换"讲清，比教快捷键有用。
3. **给每台设备写"材料白名单 + 禁入清单"**：该书给出的材料与厚度范围可直接作为初版白名单骨架（激光的可加工材料清单、3D 打印的 ABS/PLA/PVA 特性与储存条件）。
4. **通风与储存是设备配置的一部分，不是附属品**：ABS 需通风/排风；PLA 与 PVA 需**避湿避高温**（>90%RH 或 >60°C 会开始降解）。这两条应直接写进设备房的工程条件清单。
5. **"定位精度 ≠ 成形分辨率"要写进选型说明**：3D 打印机的丝杆精度是微米级，但层厚是 100–350μm 量级——**销售参数与可交付质量之间的差距，是用户期望管理的关键点**。
6. **建立"该外包吗"的判断节点**：贵重、低频、有专业服务商代劳的工艺（激光切割尤其典型），**先外包、后购置**；把预算优先给"高频 + 教学必需"的设备。
