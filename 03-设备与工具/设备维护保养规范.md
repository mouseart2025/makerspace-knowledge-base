# 设备维护保养规范

> 激光 / 3D 打印 / CNC / 木工四大类设备的日、周、月、年维保周期表 + 缺陷诊断 + 维保记录管理
> 调研时间：2026-08 ｜ 主要来源：激光切割机维保指南（2026 版/四级维保体系/光纤机冬季保护/1000-2000h 保养）、3D 打印保养周期（Orange）、曼彻斯特大学 CHEF 设备管理案例 + 柴火《创客空间搭建及运营指南》第 3 章维护保养（p97）

## 一、维保总表（日 / 周 / 月 / 年 × 四类设备）

> 维护哲学：**"预防性维护"优于"故障性维修"**——正循环里设备被频繁使用，问题早发现早维修（见 [设备清单与选型.md](设备清单与选型.md) 第四节）。下表为通用基线，具体以设备厂商手册为准。

### 1.1 激光切割机

| 周期 | 时间投入 | 项目 |
|------|---------|------|
| **日**（每次使用后）| 15–20 分钟 | ① 台面气枪清理残渣 ② 导轨/丝杆擦拭 ③ 气压/水位检查 ④ 保护镜片目检（有无污点）⑤ 急停/安全门功能测试 ⑥ 排风系统运行确认 |
| **周** | 1–2 小时 | ① 除尘箱滤芯清理/更换 ② 运动部件润滑 ③ 光学系统深度清洁（保护镜片用**高纯异丙醇**）④ 光路检查 |
| **月** | 半天 | ① 精度试切校准 ② 冷机散热器除尘 ③ 冷却液/去离子水检查（**3–6 个月更换**）④ 聚焦镜/反射镜检查 |
| **年** | 1 天（或外请）| ① **激光功率波动校准 ≤±3%** ② **定位精度校准 ≤±0.03mm/m** ③ 固件更新 ④ 核心部件（激光管/导轨/风扇）按运行小时评估寿命 ⑤ 整机电气检查 |

**按运行小时的关键保养**（累计）：

| 运行小时 | 项目 |
|----------|------|
| 1000h | 进水滤芯、防尘罩、气柜滤芯更换 |
| 2000h | 真空泵油更换、冷机循环水整体更换 |

**冬季保护**：环境温度 **≥10℃**（低温致冷却液结冰损坏）；长期停用需排空冷却液。

### 1.2 3D 打印机

| 周期 | 项目 |
|------|------|
| **周** | ① 打印平台深度清洁 ② 皮带张力检查 ③ 机身除尘（防粉尘进入导轨）|
| **月** | ① 喷嘴清洗/疏通 ② 平台调平（热床）③ 紧固件检查（螺丝是否松动）|
| **季** | ① 轴轨润滑（轻质润滑油）② 风扇清洁与检查 ③ 电子部分检查 ④ 全机重新校准（XYZ 轴）|

**常见打印缺陷 = 症状诊断表**（Orange 方法论——把缺陷当症状，反推维护项）：

| 症状 | 可能原因 | 对应维护 |
|------|---------|---------|
| 首层不粘 | 平台未调平 / Z 偏移 / 平台脏 | 月维护① + 平台深清 |
| 拉丝 | 喷头温度偏高 / 回抽设置不当 | 喷嘴清洁 + 参数排查 |
| 错层 | 皮带松动 / 电机丢步 / 散热不足 | 周维护② + 季维护 |
| 堵头 | 喷嘴碳化残留 / 耗材杂质 | 月维护① 喷嘴清洗 |
| 层纹粗糙 | 导轨阻力 / 平台晃动 | 季维护① 轴轨润滑 |

### 1.3 CNC / 木工 Router

| 周期 | 项目 |
|------|------|
| **日** | 台面清理、夹具清理、刀具检查（磨损/崩刃）、除尘袋清空 |
| **周** | 导轨润滑、主轴冷却检查（水冷/风冷）、防尘罩密封检查、安全联锁测试 |
| **月** | 主轴轴承异响检查、丝杆间隙校准、切削液（金属）液位与浓度、接地检查 |
| **年** | 主轴皮带/轴承更换评估、电气柜除尘、精度重新校验（定位精度）|

### 1.4 木工设备（台锯/曲线锯/砂磨机等）

| 周期 | 项目 |
|------|------|
| **日** | 锯片/钻头检查、集尘清空、工作台面清理 |
| **周** | 锯片清洁（树脂清洗剂）、皮带张力、导轨润滑 |
| **月** | 电机轴承异响、护罩/推杆（PUSH STICK）完好、急停测试 |
| **年** | 锯片更换评估、电气安全检查 |

## 二、维保记录管理（与设备管理系统联动）

曼彻斯特大学 CHEF 案例（2000 件设备集中管理）实证：**维护与校准记录 + 利用率数据 → 反哺采购与淘汰决策**。

### 2.1 每台设备一张维保卡（或系统记录）

| 字段 | 说明 |
|------|------|
| 设备编号 | 与 [设备清单与选型.md](设备清单与选型.md) 台账一致（一机一档）|
| 维保周期 | 按上文周期表 |
| 历次维保记录 | 日期、项目、执行人、耗材更换 |
| 运行小时数 | 激光/CNC 重点记录（1000h/2000h 节点）|
| 故障记录 | 日期、现象、处置、是否反复出现 |
| 校准证书 | 年校结果存档（功率波动、定位精度）|

> 数字化建议：选用支持**维护记录 + 校准提醒**的系统（如 MakerMatrix，见 [设备管理系统选型.md](设备管理系统选型.md)），到期自动提醒，避免"忘了保养"。

### 2.2 巡检日历（合并社区活动）

- **每月设备巡检日**（安全与规范管理既有制度）：社区清洁日合并举办，按维保总表把当月「周/月」级项目分配到人
- 季度深度保养：专人负责，耗材更换记录入库
- 年度校准：激光功率/精度年校，建议**外请厂商或认证工程师**执行并出具记录

### 2.3 故障响应

- 故障设备**立即挂"维修中/停用"状态牌**（见安全与规范管理标识系统），防他人误用
- **24 小时内故障响应**（教育场景制度范本标准）；简单故障按 SOP 常见故障表处理
- 反复故障（同故障 ≥3 次）→ 升级评估：更换部件 / 淘汰 / 换型

## 三、保养耗材与备件库存

| 类别 | 常备清单 |
|------|---------|
| 激光 | 保护镜片、聚焦镜、滤芯（除尘箱）、冷却液/去离子水、导轨油 |
| 3D 打印 | 喷头组件、PTFE 管、平台贴纸/玻璃、润滑油、各类耗材 |
| CNC/木工 | 刀具/锯片、切削液、皮带、轴承备件 |
| 通用 | 异丙醇（高纯）、无尘布、气枪、万用表、接地测试仪 |

> 备件库存纳入设备管理系统的耗材模块（Kanban 补货思路见 [设备管理系统选型.md](设备管理系统选型.md)），避免"保养时才发现没备件"。

## 四、责任与执行

| 角色 | 职责 |
|------|------|
| 设备舵主（每台设备指定负责人）| 周期维保执行、维保卡更新、问题上报（合肥工业大学制度范本）|
| 空间管理员 | 巡检日历排期、季度/年度保养组织、备件库存 |
| 使用者 | 日清（用后即清）、故障上报、SOP 常见故障自查 |
| 外部工程师 | 年度校准、大修 |

**损坏责任**：操作不当损坏 → 按空间制度担责（维修费分担或暂停使用资格，见高校制度范本）；正常磨损 → 空间运维成本，不做追责（保护"敢用"氛围，见 [设备清单与选型.md](设备清单与选型.md) 正反循环）。
