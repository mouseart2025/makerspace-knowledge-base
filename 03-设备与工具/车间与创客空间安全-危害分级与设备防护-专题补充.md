## 一、这份规范管什么

### 1.1 「Shop 或 Makerspace」的界定

原文给出的定义很宽：**使用手动或动力工具、机器、数字制造工具或其他设备，对材料进行物理加工与制造的专用区域**；作业范围包含但不限于机加工、切割、钻孔、磨削、砂磨、表面处理、材料沉积。

**这个定义的启发**：它靠**「物理加工 / 制造行为」**而非「房间名称」划界。按此界定，许多挂着「实训室」「创新中心」「开放实验室」牌子的房间，实质上就是 shop，**应适用同一套条款**。反过来，纯计算/纯软件/纯讨论空间不适用。

**适用范围**覆盖**学生、教职工、校友、访客、承包商**——即所有进入者，不区分身份。

### 1.2 责任三角：三个角色，三条权限线

原文用了三个角色，**关键在权限差异**，不在层级名称：

| 角色 | 身份来源 | 核心职责 | **授权权限（关键差异）** |
|------|---------|---------|------------------------|
| **Shop Manager** | 由所属院系/单位指定 | 空间的**总体权限与责任**：培训与发证、维修维护、日常安全运行、**以及该空间产生的危险废物的合规管理** | **可授权任意等级**（含 Class 4）——**唯一的全集权限** |
| **Shop Supervisor** | 员工 / 教师 / 其他**具备专业级经验**的职员 | 由 Manager 指派，协助日常运行、用户监督、特定工具培训 | **可授权任意等级**（含 Class 4） |
| **Shop Monitor** | **有经验的研究生 / 本科生 / 博士后 / 职员**（Class 4 设备另需**书面的**丰富经验证明） | 日常运行、用户监督、特定工具培训；在其空间内**具有完整的运行权限** | **最高只能授权到 Class 3**；**Class 4 只能由 Manager 或 Supervisor 授权** |

**三条可迁移的判断**：

1. **「管人的人」和「发证的人」是同一批人**——原文把培训/发证权直接绑在角色上，而不是设一个独立的「培训部」。小空间里这是唯一不空转的做法。
2. **存在一条硬性的权限天花板**：学生层级的 Monitor 无论多熟练，都**不能给最高危设备发证**。这条把「熟练度」和「授权资格」解耦了——**熟练不等于有权发证**。
3. **Monitor 在运行层面反而是全权**（原文明确 "Monitors otherwise have full authority over operations in their space"）。即：**运行权下放，发证权上收**。这是这套角色设计里最值得抄的一条结构。

### 1.3 空间准入：默认关闭

原文对入口的要求是**默认上锁**：除非空间内的工具**可以被可靠地切断动力（lock-out）到无害状态**，否则入口门必须上锁或采用刷卡门禁。

**推理链是**：上锁的意义不在于挡人，而在于**当无人监督时，把「设备可被启动」这件事本身消除掉**。所以「能不能不上锁」取决于「能不能可靠断电」，而不是「来的人是不是自己人」。

**本库对照**：这条与 [创客实验室运营管理手册](../04-运营与管理/创客实验室运营管理手册.md) 的「分级开放」、[数据驱动的智慧运营](../04-运营与管理/数据驱动的智慧运营.md) 的门禁方案是同一件事的**合规判据侧**——前者讲怎么做分级，本条给出**什么时候必须锁**。

## 二、★ 设备危害四级分级（Appendix A）

这是整份文档迁移价值最高的一张表——**它把「这台设备该给谁用」从经验判断变成了可查表的分类**。

### 2.1 四级定义

| 等级 | 定义 | 特征词 |
|:---:|------|--------|
| **Class 1** | 低功率**手持**与**台式**工具 | 手动为主、功率低、多数可单手控制 |
| **Class 2** | 中功率手持与小台式工具 | 工位级、有动力但规模小 |
| **Class 3** | 中功率**工业级与建筑级**工具 | 需要场地、有显著动能 |
| **Class 4** | **强功率**便携与工业级设备 | 最高危：可致重伤、开放式作业区 |

**注意分级的两个维度**：不只看功率，还看**"便携式 vs 台式 vs 工业级"的形态**。同一类设备（如台锯）会因**安全配置不同**而落在不同等级——见 §2.2。

### 2.2 逐设备归类（可判定条目）

> ⚠️ **提取局限声明**：原表 p11–p12 为**四列矩阵**（行=设备族，列=等级），PDF 转文本时列位丢失，部分条目无法无歧义判定归属。下表**只保留可确证的条目**，并给出判定依据；带「—」的表示本地提取无法确认，须查原档。这是诚实标注，不是省略。

| 设备族 | 分级情况 | 判定依据 |
|--------|---------|---------|
| **手动工具** | Class 1 | 原文列于最低级 |
| **Dremel 类旋转工具** | Class 1 | 同上 |
| **无绳电钻** | **≤½ hp → Class 1**；**>½ hp → Class 2** | **以 ½ hp 为界**，这是全表最清晰的一条分界线 |
| **掌砂机 / 电烙铁** | Class 1 | 同列 |
| **小功率有绳手工具**（3/8″ 夹头手电钻、手电刨、曲线锯、带式砂磨机、角磨） | Class 1（**< 1/3 hp**） | 以功率划界 |
| **气动工具、火药驱动工具** | Class 2（火药驱动属高危，见注） | 同列；**火药驱动工具虽列 Class 2，实际危害等级接近 Class 4，原文以"便携"归类，实操中不应据此放松** |
| **建筑级便携电动工具**（圆锯、往复锯、½″ 夹头手钻、手持铣） | Class 2 | 同列 |
| **★ 台锯** | **带感知防护（SawStop 或等效）→ Class 3**；**其余所有台锯 → Class 4** | **全表最有价值的一条**：分级不按机型按**防护技术**。同尺寸同功率，加不加自动制动，差一个等级 |
| **3D 打印机** | **FDM（ABS/PLA）→ Class 1**；**光固化树脂 → Class 2**；**粉末金属打印 → Class 4** | 三列可按描述对应 |
| **激光切割机** | **小型台式 → Class 1**；**大幅面 → Class 3** | 两列可按描述对应 |
| **机器人设备** | **小型台式（互锁）→ Class 1**；**中型 → Class 2**；**大型开放式 → Class 4** | 三列可按描述对应 |
| **水刀** | **小型独立式 → Class 2**；**大型工业 → Class 4** | 两列可按描述对应 |
| **液压机** | **小型台式 → Class 1**；**小型独立式 → Class 2**；**大型工业 → Class 4** | 三列可按描述对应 |
| **焊接与火炬** | **电阻点焊 → Class 1**；**电弧焊 → Class 3**；**氧乙炔炬 → Class 4** | 三列可按描述对应；**氧乙炔属全文档最高危项之一** |
| **吹玻璃 / 锻造** | **小规模（灯工）→ Class 1**；**大件 → Class 4** | 两列 |
| **印刷机** | **小型手动台式 → Class 1**；**独立手动 → Class 2**；**较大动力式 → Class 3** | 三列 |
| **喷漆房** | **小型台式 → Class 1**；**大型/走入式 → Class 3** | 两列 |
| 木工机床 / 金工车床 / 钻床 / 带锯 / 砂带砂盘机 / 砂轮机抛光机 / 液压剪板折弯 / 卷板机 / 铣床 / 立式锯 / 裁断锯 / 斜切锯 / 径向臂锯 / 成型机 / 乙烯基刻字机 / 缝纫机 / 泡沫切割机 / 金属锯 / 冲剪机 | **—**（列位需查原档） | 原表按「小型台式 / 独立式 / 大型工业」三档排布，但缩进丢失 |

**读这张表的正确方式**：它的核心不是"记下每台设备是几级"，而是**学会「按防护配置分级」这个方法**——台锯那条把方法论讲透了。

### 2.3 ★ 监督强度矩阵（谁能单独作业）

这张表比分级表更直接可用——**它把"有人在场"从口号变成了按等级分档的规则**：

| 使用者类型 | Class 1 | Class 2 | Class 3 | Class 4 |
|-----------|---------|---------|---------|---------|
| **新用户 / 受训者** | 由 Manager / Supervisor / Monitor 监督 | 同左 | 同左 | 同左（四级无例外） |
| **已认证的有经验学生** | **可单独作业** | **建议搭伴**（buddy recommended） | **必须搭伴**（buddy required） | **须 Manager/Supervisor/Monitor 在场**；经 Manager 许可可改为同伴搭伴 |
| **专业人员** | 全等级可单独作业；**高等级建议搭伴** | | | |

**三级递进的解读**：

- **单独 → 建议搭伴 → 强制搭伴 → 必须监督者在场**，这是一个**"注意力冗余"随危害升高的梯度**，而不是"能不能做"的许可梯度。
- **新用户四级一律需要监督，没有例外**——包括 Class 1 的手动工具。这条最容易被忽略：**入门级设备也是设备**。
- **「搭伴」被当作一种可替代的监督形式**——它在 Class 3 是强制的，在 Class 4 可在 Manager 许可下替代监督者。这给了空间在人力有限时一条合规的折中路径。
- **「专业人员」全等级可单独作业**——因为监督的目的（识别与制止不当操作）对专业人员已失去边际价值。**这一条是整套矩阵能落地的前提：它承认"人本身也是防护装置"。**

### 2.4 ★ 授权权限矩阵

| 授权对象 | Monitor 可授权到 | Manager / Supervisor 可授权到 |
|---------|----------------|---------------------------|
| 新用户 | **Class 3 及以下**（须 Manager 明确许可 Monitor 发证） | 全部等级 |
| 有经验用户的熟练度核验 | 按 Manager 裁量 | 全部 |

**要点**：Monitor 的**发证权**（Class ≤3）与**运行权**（空间内全权）是**分开的**；Class 4 是硬性上收到 Manager/Supervisor 的那一条线。**如果把这条搬到实训室，等价于：学生助教可以带入门设备，但最高危设备的准入必须由教师签字。**

### 2.5 培训三档差异

| 档位 | 内容 |
|------|------|
| **通用车间安全培训**（进店必过） | ① 基本安全：着装、PPE 使用、**安全设备位置**（洗眼器、灭火器）② 损坏/缺陷工具的**报告与停用**流程 ③ 应急、疏散、事故、发现不安全状况时的动作 |
| **工具专项培训** | ① 该工具的正确选择、使用、调整、清洁 ② **使用前检查程序** ③ **护罩、挡板、专用夹具、远程取件、急停及其他安全部件的使用与功能** |
| **Class 4 额外档** | 培训要求升为**"延长的"**上手练习与熟练度演示（其余等级为常规"上手练习 + 熟练度演示"） |

**三条可迁移的设计**：

1. **通用培训里必须包含"安全设备在哪"**——不是"须知"，是**空间导览**。人在慌乱中找洗眼器的时间是以秒计的。
2. **培训内容明确写进「护罩怎么用」——不是「护罩必须装」**。这是一条实操导向：把人培训到会用护罩，比反复下禁令有效。
3. **培训量的差异不靠"课时数"靠"练习强度"**——最高危设备的区别是**延长练习 + 更严的演示验收**。

**另有两条硬纪律**：培训**必须留档**（记录至少含：空间、讲师、日期、受训者身份标识、覆盖的工具/科目）；**有既往经验者可凭其他可信空间的培训证明，经 Manager 裁量后"演示熟练度"免修**——即**认能力不认工龄**。

**焊接特例**：原文把焊接单独拎出来，要求**由 Manager 指定的合格焊工执行培训**；焊工充足的空间可指定有经验的学生担任培训者，不足的则**外送其他热工作业区培训**。培训要点：禁用材料、PPE、消防安全、通风。

## 三、机器防护五要素

原文对"机器防护"给了五条并列要求，构成一个**最小完备集**——**五条缺一，防护就不成立**：

| # | 要素 | 说明 |
|:-:|------|------|
| **a** | **工作点防护** | 护罩 / 挡板（shields / covers）——直接隔离操作者与切削/加工点 |
| **b** | **危险旋转件防护** | 护罩 / 围挡（guards / enclosures）——传动皮带、轴、飞轮等 |
| **c** | **急停（E-stops）** | 见 §3.2 的可见性规定 |
| **d** | **防意外重启** | 防再启动装置（anti-restart）——**原文标注：OSHA 对木工机械为强制，对其他"可能致伤"的设备为最佳实践** |
| **e** | **粉尘 / 蒸气 / 烟雾的控制、捕获、过滤或排出** | **把"排风除尘"正式列为机器防护的一环**，而不是环境工程 |

**e 条尤其值得注意**：中文语境里"排风除尘"常被当作配套工程或环保项，此处明确**它是防护要素**——因为它防的是**长期健康损害**（原文另在通用指引中指出木材粉尘的健康危害，并把**局部排风列为主控手段**）。这意味着它和护罩、急停是同一优先级。

**另有独立条款**：**噪声**须通过听力保护或工程控制应对（原文另引 MIT 的听力保护专项规范）。

### 3.1 急停的可见性规定

| 要求 | 内容 |
|------|------|
| 配置门槛 | **Class 2 及以上须配急停** |
| 颜色 | 所有急停控制须**醒目红色**；**新装急停须有黄色底** |
| 位置 | 后加装的急停与其他控制须在**标准身高的操作者可及范围内** |

**"红 + 黄底"是双通道识别**：颜色在低照度或色觉差异下失效时，黄底提供对比度冗余。

### 3.2 ★ 防护与使用冲突的处置原则

这是原文里**最能解决实操死结**的一条。

**问题**：某些工艺（原文举例：台锯的**斜切（bevel）**、**开榫（tenoning）**、**开槽/开槽口（slotting / dadoing）**）**传统护罩会妨碍作业**。此时操作者的自然倾向是——把护罩拆掉。

**原文给出的正解**（三步，不可跳步）：

1. **识别**：承认该工艺与标准护罩存在物理冲突——**不假装冲突不存在**；
2. **不擅自处理**：**必须先与 Manager / Supervisor / Monitor 讨论**，不得自行拆卸；
3. **替代防护**：改用 **jigs（工装）/ sleds（滑座）/ templates（模板）/ fixtures（夹具）** 等**替代防护方案**完成作业。

**为什么这条重要**：它给"护罩被拆掉"这个普遍现象提供了一个**合规出口**。把"禁止拆护罩"改成"要拆必须先问、然后用工装解决"——**从禁令变成了流程**。禁令会被绕过，流程不会。

**★ 本条可迁移的中文表述**：「凡工艺需要而无法使用标准护罩时，**不得自行拆卸**，须经管理人评估后，采用专用工装／滑座／模板／夹具等替代防护完成作业，并记录该工艺的替代防护方案。」

### 3.3 设备本体的固定与调平（布局侧新增参数）

原文有两条**直接影响平面布局**的要求，本库既有布局类文档未覆盖：

| 要求 | 内容 | 对布局的含义 |
|------|------|------------|
| **调平与固定** | **动力设备与大型手动工具须调平，并固定于地面或工作台面** | **落地设备须有固定点**（地脚/预埋/底板），不能只"放在那儿" |
| **台式机固定** | 台式机型须用**螺栓或夹具固定于工作台**；**立式/落地式须固定于地面** | 工作台的**抗倾覆**成为选型参数 |
| **防倾覆** | 通用指引另要求固定工具以防倾倒、位移、振动 | 高重心设备（带锯、立式砂轮机）须独立固定 |
| **照明** | 工具照明须有**罩、安全镀膜灯泡或低压照明** | 设备照明属防护件，不是便利件 |
| **警示标签** | **所有台式与独立工具/机器均须警示标签** | 交付验收项 |

## 四、逐设备安全规则（硬数值速查）

> 这是最"贴地"的一节：**全是可直接验收的数字**。下表按"设备 → 关键数值/要求 → 背后的判据"组织。

| 设备 | 关键数值 / 要求 | 判据（为什么是这个数） |
|------|---------------|---------------------|
| **砂轮机（Bench Grinder）** | **工具托架与砂轮的间隙 < 1/8″（3.2mm）** | 工件被卷入间隙 → 手指被带向砂轮。间隙是最直接的防护尺寸 |
| | 砂轮不得有缺陷/不平衡/裂纹；**启动时人站到侧面** | 砂轮爆裂是径向飞散 |
| | **频繁小量修整**（而非一次大修）；平面磨磁力吸盘须放稳；**不得磨铝** | 铝屑堵塞砂轮孔隙 → 受热膨胀破裂 |
| **带锯（Band Saw）** | **上导板与护罩须贴近工件，间距 ¼″（6.4mm）** | 锯条裸露段越短，暴露的刃口越少 |
| | 铝材**至少 2 齿**、钢材**至少 3 齿**在切 | 齿数不足 → 卡齿、崩齿、工件弹跳 |
| **盘砂机 / 砂带机（Disc & Belt Sander）** | **盘砂机必须使用「向下运动侧」** | **用向上侧会把工件抛向操作者**——这是唯一一条纯方向性判据 |
| | 砂带/砂盘磨损、撕裂**不得继续使用**；小件用夹具/钳/夹持工具 | 磨料失效 → 工件突然被带飞 |
| **台锯（Table Saw）** | **锯片高出工件 1/8″（3.2mm）** | 露出量越小，反冲与接触面积越小 |
| | 建议新购/更换采用**感知防护技术（SawStop 类）**，但 **★ 它不防反冲（kickback）** | **必须显式说明其局限，否则会催生虚假安全感**（呼应 §2.2 的分级） |
| | 窄料须用**推杆（push stick）**；大幅面板材须用**进出料支撑**、或请店里人员协助、或用**板材锯（panel saw）** | 大幅面板材在台面上失稳是主要事故源 |
| | **不得同时使用角尺与靠山做横切** | 两点同时定位 → 工件被夹住 → 反冲 |
| | **须在锯缝下方设集尘** | 锯末堆积在锯下方既是火险也是吸入源 |
| **平刨（Jointer）** | **刀头须为自动自封护罩**；**刀刃突出刀头 ≤ 1/8″** | 刀刃露出量直接决定刨伤深度 |
| | **窄于 3″（76mm）的材料须用压推块** | 手与刀头的距离不足 |
| | **材料宽度不得小于台面开口宽度的 4 倍** | 开口过宽 + 材料过窄 → 工件翻转/坠落 |
| **成型机 / 路由机（Shaper / Router）** | **靠山须在主轴两侧各延伸 ≥ 18″（457mm）** | 保证进料与出料全程有基准面 |
| | 须用**模板/夹具把手挡在工作点外**；路由机须配**渐进介入的主轴制动系统** | 手不入危险区 + 停机时间可控 |
| | **切削刀具与夹头须标注最大允许切削速度** | 超速 → 刀具解体 |
| **钻床（Drill Press）** | 工件须**夹持**，**永不手持**；选最优转速；钻头须锋利无裂 | 手持工件 → 钻头咬入时工件旋转伤人 |
| | 钻透须垫**背板（backing）**；**卡钻须停机后手动反向释放**；深孔须退屑 | 从"别硬拽"到"别硬拧" |
| | **侧护安全眼镜为最低要求**（透明材料另需培训） | 眼面防护的底线 |
| **车床（Lathe）** | 卡盘须紧固；**不得用机器动力上/卸卡盘**；刀具短夹 | 卡盘钥匙被遗忘在卡盘上 = 飞射物 |
| | **必须停机后用钩具清屑，永不徒手** | 切屑刃口锋利且带热 |
| | **须穿重型安全鞋**（除非能证明该危害不存在或极小）；须用挡屑罩/卡盘护罩/丝杠罩 | 落物 + 切屑 + 旋转件三重 |
| **压缩空气** | **用于清洁的气站 ≤ 30 psig**，或装 **OSHA 合规安全嘴** | 高压气流可致气栓与机械损伤 |
| **电动工具接地** | 须**双绝缘**或**三脚接地**；**线套不得有胶带修补、破损、裂开、切断** | **"胶带修补过的线"被明确列为不合格状态** |
| **电源隔离** | 除可插拔电源外，须装**可锁闭断开开关**以支持 **LOTO（上锁挂牌）** | 检修时不能被他人误启 |
| **气动工具** | 须装**接头防脱（retainer）** | 软管脱开 → 甩击 |
| **★ 通用反冲（Kickback）** | 对策：**分料刀（spreader/splitter）、防反冲齿片（anti-kickback fingers）、自动进料器（power feeder）、定位靠山或纵切靠山（gauge / rip fence）** | 反冲是木工机械最常见致伤模式，五种对策可叠加 |
| **换刀片/刀具前** | **必须断电** | 最基础也最常被跳过的一条 |

**通用指引中的另两条**：

- **厂商操作手册须留存，或在店铺网站上公开可取**——"资料在手边"是操作前提，不是文档归档。
- **厂商说明是设备检查的基准**（与 §五 的检查制度配套）。

## 五、四档检查制度

原文把"检查"拆成**四个不同周期、不同执行人**的动作——**这是本库维保类文档没有的层次**（既有文档讲"多久保养一次"，这里讲"谁在什么时候看什么"）：

| 档位 | 周期 / 触发 | 执行人 | 范围 |
|------|-----------|--------|------|
| **① 每日概览** | 每日 | 管理者/值守 | 空间整体状态 |
| **② 定期正式记录检查** | 定期，**须记录** | **联合空间管理方与上级 EHS 代表** | 空间 + 设备整体；有示例清单（Appendix E） |
| **③ 设备检查** | 按**厂商说明**的频率 | 维护人 | 逐台设备 |
| **④ 事后检查** | **发生事故 / 伤害 / 不安全状况报告后** | 管理者 | 针对事件相关范围 |

**第 ④ 档的设计最值得抄**：把**"报了就查"写成制度**。这条同时解决两个问题——它让"上报"变成一个**能带来改变的动作**（而不是打小报告），也让同类隐患在再发前被清除。

### 5.1 ★ 使用者每次使用前检查（最实用的一档）

原文要求**使用者在每次使用前检查工位与工具**，明确列出的重点项：

| 检查项 | 判据 |
|--------|------|
| **电线与连接** | 完好、无破损 |
| **插头** | **有接地脚** |
| **线套（cord jacket）** | **不得有胶带修补、破损、裂开或切断** |
| **机械护罩** | **须在位且调整正确** |

**"胶带修补的线"被单列**，说明它是一个高频、高隐蔽性的不合格状态——**看起来"还能用"，实际绝缘已失效**。

### 5.2 损坏工具的处置

原文的处置是**两步且不能省第二步**：**立即停用** ＋ **使其不可接近/不可操作**（配上锁挂牌与标识）。

**"停用"与"隔离"是两件事**：只贴一张"故障"纸条，工具仍在原位、仍可被启动；**必须物理上做到"够不着、开不了"**。这与 §3 的 LOTO、§5.1 的检查构成闭环。

**LOTO 的适用边界**（原文给了判据）：须做 LOTO 判定并建立**能量控制程序**；但**例行的、重复性的微小调整**一般不需要 LOTO。

### 5.3 ★ 自检清单（Appendix E，四段 29 项）

原文给了一份**可直接照抄的自我检查表**——四段结构，全部 Yes/No 勾选：

**A. 空间条件（7 项）**
准入是否受控且仅限授权人员 ▸ 房间许可证是否有效（**MIT 特有，不迁移**）▸ 照明是否充足 ▸ **所有出口是否标识清晰且畅通** ▸ 地面是否无障碍与杂物 ▸ 整体内务（含存放物）是否良好 ▸ 是否有需要跟进的条件或问题

**B. 安全设施（14 项）**
**Class 2 及以上空间：使用时是否有 Manager/Supervisor/Monitor 在场**（呼应 §2.3）▸ 是否张贴通用安全信息 ▸ **是否至少有一个便携式灭火器** ▸ **是否有固定电话且张贴紧急联系信息** ▸ **是否至少有一个急救箱且状态良好** ▸ 化学品是否按**全名 + 危害类别**标注 ▸ 化学品是否妥当存放（**易燃品须在合格易燃品柜内**）▸ 化学品存在时 **SDS 与物料清单是否齐全、最新、可取** ▸ **PPE 是否与危害匹配、状态良好** ▸ **工具与机器使用者是否佩戴了规定 PPE** ▸ **使用者是否遵守头发、饰品、着装要求** ▸ **电线是否管理良好并受保护** ▸ **有应急用水的空间：洗眼器/安全淋浴是否定期测试并按测试日期标注** ▸ 是否有需跟进的安全问题

**C. 工具与机器（6 项）**
工具是否受保护以防未授权使用 ▸ **使用者是否经过适当培训** ▸ **是否留存了新用户的书面培训记录**，或以何种方式核验（应用 / 通行证或培训卡 / 共享表格）▸ **损坏或维修中的工具是否已上锁隔离并标识** ▸ 所有工具是否已适当防护 ▸ 是否有需跟进的工具或机器问题

**D. 废物管理（2 项）**
废物与可回收物是否定期收集清运 ▸ **若产生下列特定废物，是否按其制度管理**：切割液 ▸ 金属切屑/细屑/边角料 ▸ 脱脂剂 ▸ 涂层/涂料/密封胶/胶粘剂 ▸ **溶剂型或油污抹布**

**清单的三条使用说明**（原文给出）：① 作为**起点**使用，各空间应**增补自己的条目**；② 发现的**差异与问题须分优先级处理**；③ 可请上级 EHS 协助审计。

**★ 这份清单可迁移的结构是**：**空间条件 → 安全设施 → 工具机器 → 废物**四段。它把"安全检查"从"看一圈"变成了**四个互不重叠的检查域**，且**每段都以"是否有需跟进项"收尾**——强制产出行动项，而不是打勾了事。

## 六、房间与基础设施最低配置

原文 §3.4 给了**六项最低配置**——注意它叫**最低**，即"达不到就不该开放"：

| # | 项 | 内容 |
|:-:|----|------|
| **a** | **物理限制** | 仅授权用户可进入（与 §1.3 门禁配套） |
| **b** | **固定电话 + 张贴紧急联系信息** | ★ **见下方判断** |
| **c** | **至少一个便携式 ABC 灭火器** | 明确"便携式"与"ABC 型" |
| **d** | **张贴基本安全规则 + 备齐设备与工具的操作手册** | 规则上墙 + 手册在手 |
| **e** | **免费提供适当 PPE** | ★ **"免费"与"适当"是两个独立要求** |
| **f** | **配套** | 专用废物容器 ▸ 泄漏处置物资 ▸ **若有腐蚀性化学品，须配管道式洗眼站** |

**从 a–f 读出的体积**：**这是一个"可开放的底线"，不是"理想的配置"**。任何新建或改建的制造空间若缺其中一项，应当视为**不具备开放条件**，而非"待完善"。

**★ 关于 b（固定电话）的判断**：

这条在 2008 年制定、2021 年复核时仍保留，但**与今天的现实存在张力**（移动电话普及）。它的立法意图是**"紧急联络不能依赖个人设备"**——包括设备没电、没带、信号差、外来访客无本地号、双手受伤无法操作手机等情形。

**处置建议**：不必机械照搬"固定电话"，但须满足其**功能等价**——即**空间内存在一处不依赖个人设备、任何人可立即使用的紧急呼叫手段，且紧急联系信息就地可见**。这条应作为**替代方案的验收判据**，而不是取消该条的理由。

**★ 关于 e（免费 PPE）的判断**：

"免费提供"是**独立要求**，不因"使用者自己也能买到"而免除。理由是**防护有效性取决于佩戴率**：任何增加摩擦的环节（自购、押金、领取手续）都会降低佩戴率。这条对**高校/职业院校空间尤其重要**——学生自备 PPE 的实际覆盖率极低。参照本库 [PPE安全防护采购清单](PPE安全防护采购清单.md)。

**另有两项空间侧要求**：新建、改建、**以及新设备安装**的设计**须经 EHS/协调人/设施管理部门 review**；动力设备与大型手动工具须调平固定（见 §3.3）。

## 七、危废管理最佳实践（全库空白项）

> **说明**：本库既有文档对"废弃物"的覆盖停留在"分类垃圾桶"，**从未涉及制造过程产生的化学废物**。原文的 Appendix D 正好补上这块——且与智造类专业实训（金工车削、铣削、磨削）**直接相关**。

### 7.1 制度层

| 要求 | 内容 |
|------|------|
| **卫星累积区（SAA）** | **常态化产生危险废物的机加工空间须设专用卫星累积区**；区域须**规范标识并每周检查** |
| **人员资质** | 产生、处理、储存危险废物的人员**须接受"危险废物管理"培训，至少每年一次** |
| **存量清理** | 建议**定期清出过期化学品**——避免积压，并把存储空间释放出来 |

### 7.2 六类废物流

| 废物流 | 关键判断与最佳实践 |
|--------|------------------|
| **★ 切削液 / 磨削液** | 分**水溶性**与**非水溶性（石油基）**；**两者均须按危险废物收集**。**最佳实践：尽量使用水溶性切削液**。★ **避免使用含氯攻丝液，并防止其与切削液混合**（混合即污染整批） |
| **★ 金属切屑 / 细屑** | 被传统油基冷却液浸润后**必须按危险废物收集**。**减量化最佳实践**：① 回收前用**筛网 / 穿孔容器 / 甩干机 / 离心机**彻底沥出多余冷却液（沥出的冷却液可回用或按危废处置）② **按金属种类分选**以提高回收价值 ③ 寻找切屑、细屑、污泥的**金属价值回收**出路 |
| **涂料 / 油漆 / 密封胶 / 胶粘剂** | **常是车间最大的危险废物来源**；多具易燃性——**易燃品须存于易燃品柜**；**最佳实践：定期申请清库统一处置** |
| **脱脂剂** | 机加工空间常用**矿物油精（mineral spirits）**去除油污，**日常清洁即会产生大量危废**；**废脱脂剂须按危险废物处置** |
| **★ 抹布 / 擦拭布** | **被非水液体浸透的抹布与擦拭布，必须收集并按危险废物管理**。**最佳实践：用最少量的清洁剂，避免把抹布浸透**——**未被危险液体浸透的抹布可按普通垃圾处理** |
| **粉末 / 粉尘**（由"金属打印 = Class 4"与通用排风要求推出） | 粉末金属打印属最高危等级；粉尘控制须纳入防护五要素的 e 条 |

**读这张表的两个关键判据**：

1. **"沥干"和"少用清洁剂"是同一个思路**——**减量优先于处置**。切屑先沥干、抹布少蘸，都在源头把危废变成一般废物。这是最省钱也最容易被忽略的一步。
2. **"分金属种类"既是环保也是经济**——分类回收价值更高，这条把合规变成了收益。

### 7.3 ★ 3D 打印支撑去除（化学风险条款）

原文对 3D 打印的支撑去除给了**独立的安全条款**，值得单独摘出（本库 [3D打印工艺与入门-专题补充.md](3D打印工艺与入门-专题补充.md) 讲工艺，未讲这条）：

**首选方案**：**机械式断裂去除，或使用非危化方案**——即**优先避免使用腐蚀性溶液**。

**若必须使用碱性腐蚀液去支撑**，原文给出**九条并列约束**：

| # | 约束 |
|:-:|------|
| 1 | **限定为受过培训的人员**操作 |
| 2 | **房间必须配紧急洗眼器** |
| 3 | **全套 PPE**：安全眼镜**之外再戴全面屏** + 耐化学手套 + 实验服或橡胶围裙 |
| 4 | 槽体须**耐腐蚀**；置于**低人流区域**；**固定于不可移动表面** |
| 5 | **须有二次围堵（secondary containment）** |
| 6 | **不用时须加盖** |
| 7 | **须带排液阀** |
| 8 | **按 OSHA 危害沟通要求标注**：**全化学名 + "Danger"警示词 + 腐蚀性象形图** |
| 9 | **优先采购预配好的溶液**；废液**按危险废物收集** |

**三条可迁移的判断**：

- **第 3 条的"之外再戴"是加法不是替换**——安全眼镜 + 全面屏，不是二选一。这是同类条款里最容易写错的地方（写成"佩戴防护面罩"就等于允许只戴面罩）。
- **第 9 条的"优先买预配溶液"是典型的"用采购替代操作"**——把现场配制的风险，转成供应商的质量控制。这个思路可以直接推广到所有需要现场配液的工艺。
- **第 5、6、7 条（二次围堵 + 加盖 + 排液阀）是"容器三件套"**——泄漏、挥发、废液处置三个风险点各有一件对口措施。**凡是槽体/液槽，这三件应作为标配。**

| 上锁挂牌（LOTO） | **GB/T 33579**（机械安全 危险能量控制方法 上锁/挂牌） |

**换算纪律三条**：

1. **不要逐字翻译美标条款再套 GB**——两者**结构不同**（OSHA 是法规条文，GB 多为产品/设计标准）。正确做法是：**取原文的"要防什么"（风险点），再用 GB 对应的"怎么防"（技术措施）落地**。
2. **数值不可直接沿用**——原文的 1/8″、¼″、3″、18″ 是英制惯用值，对应公制见 §四 表内括注；**中方是否采同等数值须由设备厂商说明书与 GB 专项规程确定**（**厂商说明优先于任何通用表**——原文本身也是这么定的，见 §五 第 ③ 档）。
3. **"最好实践（Best Practice）"与"强制"要分开**——原文明确标注了哪些是 OSHA 强制（如木工机械防意外重启）、哪些是建议（如感知防护台锯）。**换算时不要把建议写成强制**，反之亦然。

## 九、可迁移清单

按"**现成可用 / 需改造 / 仅供参考**"三档给出结论：

### 9.1 现成可用（结构完整、可直接改成自己的条款）

| 项 | 用法 |
|----|----|
| **★ 设备危害四级分级表** | 改为自己的「**设备准入分级表**」：逐台设备定级，等级决定培训要求、在场要求、授权层级。**这是本文最高价值产出** |
| **★ 监督强度矩阵** | 改为「**分等级在场规则**」：新用户 → 已认证 → 专业人员在四级设备上分别适用什么监督形式（单独/搭伴/强制搭伴/须在场） |
| **★ 授权权限矩阵** | 改为「**谁能给谁发证**」：明确"学生助教/管理员的发证上限"与"最高危设备必须由谁签字" |
| **★ 自检清单四段 29 项** | 直接作为巡检表起点，删掉标志性行政项（Greencard、Kerberos、MIT EHS 联系），按自己的空间增补条目 |
| **机器防护五要素** | 作为设备采购与验收的**五项对照检查**（护罩/传动防护/急停/防意外重启/粉尘蒸气控制缺一不可） |
| **防护与使用冲突处置三步** | 写成自己的一句话条款（见 §3.2 的迁移表述） |
| **危废六类流 + 减量判据** | 直接对应金工实训的切削液、切屑、脱脂剂、抹布；**"先沥干 / 少蘸"两条是最易执行、见效最快的动作** |
| **四档检查制度** | 特别是**"报了必查"的事后检查档**——把上报变成有效动作 |

### 9.2 需改造后使用

| 项 | 改造点 |
|----|-------|
| **分级表的具体归类** | 原文按美式工具谱系编排（大量木工、金属板金机型）。中方实训室的设备构成不同（如数控机床、工业机器人、新能源高压部件占比更高），**须重排并补充原文未覆盖的机型**；且部分条目列位需查原档 |
| **固定电话条款** | 改为**功能等价**表述（不依赖个人设备的紧急呼叫手段 + 就地可见的联系信息） |
| **培训记录 5 年留存** | 改为按自己所在单位的档案制度执行 |
| **§四 的硬数值** | 保留作为**检查提问**（"托架间隙是多少？谁量过？"），不作为**验收标准**——验收以厂商说明书与 GB 专项为准 |
| **焊接培训者资质** | 原文允许"指定有经验的学生当培训者"，在中方院校语境下须核对**特种作业操作证**等资质要求，**不可直接照搬** |
