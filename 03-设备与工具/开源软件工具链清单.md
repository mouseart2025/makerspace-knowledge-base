# 开源软件工具链清单

> 调研时间：2026-08-30 ｜ 定位：覆盖数字制造全链条的**开源软件工具链**，构成创客空间"零软件成本"方案。从 CAD 建模到 CAM 加工、切片打印、电路设计、3D 建模动画，全部可用开源软件完成。
> 核心参考：GitHub **Awesome FOSS for Decentralised Manufacturing**（全链开源清单）、FreeCAD 官方。

---

## 一、数字制造全链条工具链

### 1.1 CAD（计算机辅助设计）

| 工具 | 许可 | 定位 | 教学价值 |
|------|------|------|---------|
| **FreeCAD** | LGPL-2.1 | 参数化 3D CAD，FEM/BIM/CAM 工作台，商业可用（2026-07 发布 1.1.1） | 数字制造主线 CAD 教学 |
| **SolveSpace** | GPL | 轻量参数化 CAD，约束求解 | 入门快、资源占用低 |
| **CadQuery** | Apache-2.0 | 代码驱动 CAD（Python） | 编程与 CAD 结合 |

### 1.2 CAM / 切片 / 加工路径

| 工具 | 许可 | 定位 | 适用 |
|------|------|------|------|
| **Cura** | LGPL | 开源切片，3D 打印 | 主流 FDM 打印机 |
| **PrusaSlicer** | AGPL | 高级切片，多材料 | Prusa 及兼容机 |
| **Slic3r** | AGPL | 老牌开源切片 | 通用 |
| **FreeCAD CAM/Path** | LGPL | 内置 CAM 工作台，CNC/激光路径 | CNC 铣削、激光切割 2D 路径 |
| **Inkscape** | GPL | SVG 矢量，激光切割/CNC 2D 路径 | 激光/CNC 图形准备 |

### 1.3 固件（3D 打印机 / CNC / 激光）

| 工具 | 许可 | 定位 |
|------|------|------|
| **Marlin** | GPL | 3D 打印机固件（最主流） |
| **Klipper** | GPL | 高性能 3D 打印固件 |
| **GRBL** | GPL | CNC/激光控制器固件（Arduino 生态） |

### 1.4 EDA（电子设计自动化）

| 工具 | 许可 | 定位 |
|------|------|------|
| **KiCad** | GPL | 开源 EDA，原理图+PCB 全流程 |
| **Fritzing** | GPL | 面包板/原理图可视化，教学友好 |

### 1.5 3D 建模 / 动画 / 视觉

| 工具 | 许可 | 定位 |
|------|------|------|
| **Blender** | GPL | 3D 建模/雕刻/动画/渲染全流程 |
| **Inkscape** | GPL | 2D 矢量（前述） |
| **GIMP** | GPL | 图像处理（替代 Photoshop） |

### 1.6 CAE（工程仿真）

| 工具 | 许可 | 定位 |
|------|------|------|
| FreeCAD FEM 工作台 | LGPL | 结构/热有限元分析 |
| **OpenFOAM** | GPL | 计算流体力学（CFD） |
| **CalculiX** | GPL | 有限元求解器 |

### 1.7 编程 / 电子 / 嵌入式

| 工具 | 许可 | 定位 |
|------|------|------|
| **Arduino IDE** | LGPL | 嵌入式开发（创客标配） |
| **VS Code + PlatformIO** | MIT | 现代嵌入式开发 |
| **Python / MicroPython** | PSF/MIT | 编程教学、AI 入门 |
| **Node-RED** | Apache-2.0 | 低代码物联网/自动化编排 |
| **Home Assistant** | Apache-2.0 | 智能空间中枢（开源） |

### 1.8 AI / 机器学习制造

| 工具 | 许可 | 定位 |
|------|------|------|
| **Ultralytics YOLO** | AGPL | 视觉检测模型训练部署 |
| **Edge Impulse** | 部分开源 | 边缘 TinyML 工作流 |
| **SenseCraft AI** | 免费平台 | Seeed 无代码 AI 部署（配套硬件） |

## 二、典型工作流（全开源）

### 2.1 3D 打印全流程

```text
FreeCAD（建模）→ Cura（切片）→ Marlin/Klipper（固件打印）
```

### 2.2 激光切割/CNC 流程

```text
Inkscape/FreeCAD（图形）→ FreeCAD CAM/路径（加工路径）→ GRBL（控制）
```

### 2.3 电子原型流程

```text
KiCad（原理图/PCB）→ Arduino IDE/PlatformIO（固件）→ 制作测试
```

### 2.4 智能空间（IoT）流程

```text
Home Assistant（中枢）→ ESPHome/Arduino（节点）→ Node-RED（编排）
```

## 三、教学价值与落地

1. **零软件成本**：全链开源，省去商业软件授权费（一套商业 CAD/EDA 年费可达数千至数万）
2. **教学友好**：Fritzing/KiCad 面向教学；FreeCAD 社区教程丰富
3. **与硬件闭环**：开源软件与 [开源硬件与AI开发套件选型.md](开源硬件与AI开发套件选型.md) 无缝衔接（Arduino/ESP32/XIAO）
4. **学生可带走**：开源软件学生可安装到个人电脑持续学习
5. **长期可持续**：不依赖厂商续费，符合开源创客文化

**落地建议**：实训室电脑统一预装"开源工具链镜像"（FreeCAD + KiCad + Blender + Inkscape + Cura + Arduino IDE + VS Code），形成标准化教学环境。
