# 40人班制创客空间配置标准

> 40人班制创客空间配置标准：工位密度、设备套数、动线宽度、排课机制、单班并发使用模型
> 调研时间：2026-08 ｜ 主要来源：教育部新能源汽车/机器人专业实训条件建设标准、MIT K-12 Makerspace Design Guide、广东省中小学创客教育空间建设指南、CMU IDeATe教学空间案例、肯创客空间方案
> 定位：本文是 [创客空间规划与设计.md](创客空间规划与设计.md) 的班制细化篇——针对单班40人、三专业共享的L型434㎡空间的并发使用模型。

---

## 一、适用场景

- **空间规模**：L型434㎡，硬装已完成
- **服务专业**：智能制造、人工智能技术应用、新能源汽车技术
- **班制**：单班40人，可能同时有1–2个班使用
- **使用模式**：课程教学 + 项目制作 + 竞赛训练 + 开放使用
- **约束**：楼上为宿舍（噪音/振动限制）、硬装不可大改

## 二、面积与工位密度标准

### 2.1 面积标准参考

| 来源 | 面积指标 | 适用场景 |
|------|---------|---------|
| **MIT K-12 Makerspace** | 25 ft²/人（约2.3㎡/人） | 中小学创客空间，24–28人班需600–700ft²（56–65㎡） |
| **教育部新能源汽车标准** | 240㎡/实训室（40人班） | 专业实训室，含设备+操作+通道 |
| **教育部机器人标准** | 90–170㎡/实训室（8–35台设备） | 机器人各方向实训室 |
| **广东省创客教育指南** | 创作桌≥60×80cm/人 | 中小学创客教室 |
| **肯创客空间方案** | 150–200㎡/40人大课 | 创客教育整体方案 |
| **教育场景通用** | 生均≥0.15㎡（最低）；功能区占比：教学40–50%/加工20–25%/仓储15–20%/展示10–15% | 通用教育空间 |

### 2.2 本项目面积分配建议（434㎡ L型）

| 功能区 | 面积占比 | 面积（㎡） | 说明 |
|--------|---------|-----------|------|
| **教学/共创区** | 30% | ~130㎡ | 可容纳40人，六角桌/长条桌，可变换布局 |
| **数字制造区** | 15% | ~65㎡ | 激光切割、3D打印、桌面CNC |
| **机器人实训区** | 20% | ~87㎡ | 机械臂、四足机器狗、桌面机器人、竞赛场地 |
| **新能源汽车区** | 15% | ~65㎡ | 动力电池、混动发动机、驱动电机台架 |
| **电子/手工区** | 8% | ~35㎡ | 焊接、电子制作、手工工具 |
| **存储/材料区** | 7% | ~30㎡ | 材料、半成品、工具、PPE |
| **展示/接待/通道** | 5% | ~22㎡ | 展示墙、前台、主通道 |

> ⚠️ 以上为参考分配，实际需根据L型空间的具体形状和门窗位置调整。核心原则：**噪音/粉尘区（CNC、激光、新能源）集中在离宿舍最远的一侧**。

### 2.3 工位密度

| 区域 | 工位类型 | 单工位占地 | 40人同时使用工位密度 |
|------|---------|-----------|-------------------|
| 教学共创区 | 六角桌（6人/桌）或长条桌（4人/桌） | 1.5–2.0㎡/人 | 2.0–2.5㎡/人（含通道） |
| 电子工位 | 焊台+万用表+防静电垫 | 1.2–1.5㎡/工位 | 2人/工位（轮换），10–12个工位 |
| 数字制造 | 设备+操作位 | 2–5㎡/台 | 设备共用，3–5人/台轮换 |
| 机器人操作 | 工作站+围栏 | 4–16㎡/台 | 3–5人/台，6–8台 |
| 新能源台架 | 台架+操作位 | 3–6㎡/台 | 4–6人/台，6–8台 |

## 三、设备套数配置

### 3.1 配置原则

1. **按分组配置**：40人分8组，每组5人；或分10组，每组4人
2. **核心设备每组1套**：保证每组都能动手操作
3. **贵重设备共享轮换**：激光切割、工业机器人等按2–3组共用1台
4. **工具按人配置**：基础手工工具、安全防护每人/每组1套

### 3.2 设备套数建议（40人班）

#### 3.2.1 通用创客设备

| 设备 | 数量 | 分组方式 | 备注 |
|------|------|---------|------|
| 3D打印机 | 6–8台 | 5–6人/台 | FDM为主，1–2台树脂 |
| 激光切割机 | 2台 | 20人/台，轮换 | 桌面级40–60W，带排风 |
| 桌面CNC（带盖） | 3–4台 | 10–13人/台，轮换 | 全封闭，配吸尘器 |
| 电子焊台 | 10–12个 | 3–4人/个 | 含万用表、防静电垫 |
| 台式电脑/笔记本 | 20–30台 | 1–2人/台 | 设计+编程+控制 |
| 大屏/投影 | 2–3个 | 全班共用 | 教学演示 |
| 基础工具套装 | 8–10套 | 4–5人/套 | 手工工具、量具 |

#### 3.2.2 智能制造/机器人专业设备

| 设备 | 数量 | 分组方式 | 备注 |
|------|------|---------|------|
| 工业机械臂（桌面/小型） | 4–6台 | 6–10人/台 | 带安全围栏，3–5人/台同时 |
| 协作机械臂 | 4–6台 | 6–10人/台 | 桌面型，无需围栏 |
| 四足机器狗 | 4–6台 | 6–10人/台 | 教育版，分组调试 |
| 移动机器人/AGV | 2–4台 | 10–20人/台 | 导航测试 |
| PLC实训台 | 6–8台 | 5–7人/台 | 电气控制基础 |
| 机器人竞赛场地 | 1套 | 全班轮换 | 可收纳，VEX/RM兼容 |

#### 3.2.3 新能源汽车专业设备

| 设备 | 数量 | 分组方式 | 备注 |
|------|------|---------|------|
| 动力电池实训台 | 2–3台 | 13–20人/台 | 解剖展示+BMS+拆装 |
| 混动发动机实训台 | 1–2台 | 20–40人/台 | 演示为主，分组观摩 |
| 驱动电机实训台 | 2–3台 | 13–20人/台 | 解剖+拆装+测试 |
| 充电桩实训台 | 1–2台 | 20–40人/台 | 交直流各1 |
| 高压安全实训台 | 2台 | 20人/台 | 绝缘测试、安全操作 |
| 绝缘工具/PPE | 8–10套 | 4–5人/套 | 绝缘手套、靴、垫 |

### 3.3 设备并发使用模型

```
40人班 → 分8组（5人/组）

时段1（0-45min）：
  组1-2：机器人实训（4台机械臂，2组共用）
  组3-4：新能源实训（3台台架，轮换）
  组5-6：数字制造（激光+CNC+3D打印，轮换）
  组7-8：电子制作（焊台+电脑）

时段2（45-90min）：轮换
  组1-2 → 电子制作
  组3-4 → 机器人实训
  组5-6 → 新能源实训
  组7-8 → 数字制造

时段3（90-135min）：再轮换
...
```

**关键指标**：
- 每生每节课动手操作时间≥30分钟
- 设备利用率≥60%
- 教师/助教比：1:20（主讲1+助教1–2）

## 四、动线宽度标准

### 4.1 通道宽度

| 通道类型 | 最小宽度 | 推荐宽度 | 说明 |
|---------|---------|---------|------|
| **主通道** | 1.2m | 1.5–1.8m | 双人错肩+设备搬运+消防 |
| **次通道** | 0.9m | 1.0–1.2m | 工位间通行 |
| **设备检修通道** | 0.6m | 0.8m | 设备后方维护 |
| **紧急疏散通道** | 1.2m | 1.4m | 保持畅通，无堆放 |
| **设备搬运通道** | 1.5m | 2.0m | 大型设备进出 |

### 4.2 动线设计原则

1. **动静分离**：教学区（静）与加工区（动）分开，减少交叉
2. **材料流**：材料入库→存储→加工→成品，动线顺畅不回头
3. **人流**：入口→接待/展示→教学区→各功能区，避免穿越危险区
4. **安全疏散**：至少2个出口，疏散距离≤30m
5. **L型空间利用**：L型的转角处设展示/休息区，两个长边分别布置不同功能带

### 4.3 L型空间动线示意

```
┌─────────────────────────────┐
│  入口/展示/接待             │
│  ┌─────────────────────┐    │
│  │   教学共创区（静）   │    │
│  │   40人，六角桌       │    │
│  └─────────────────────┘    │
│         主通道 1.5m          │
│  ┌──────────┐ ┌──────────┐ │
│  │电子/手工 │ │ 机器人区  │ │
│  │  区      │ │ （中噪）  │ │
│  └──────────┘ └──────────┘ │
│         主通道 1.5m          │
│  ┌──────────┐ ┌──────────┐ │
│  │数字制造区│ │新能源区  │ │
│  │（高噪高尘│ │（中噪）  │ │
│  │ 靠外墙） │ │          │ │
│  └──────────┘ └──────────┘ │
│  存储/材料/PPE区（靠角落）  │
└─────────────────────────────┘
         ← 离宿舍最远侧 →
```

## 五、排课机制

### 5.1 排课原则

| 原则 | 说明 |
|------|------|
| **分区排课** | 不同专业可同时使用不同区域，避免冲突 |
| **错峰使用** | 高噪音设备（CNC、激光）安排在白天非休息时段 |
| **轮换制** | 40人分小组，在不同功能区间轮换 |
| **预约制** | 贵重设备（激光、工业机器人）需提前预约 |
| **开放时段** | 非上课时间对学生开放，需管理员值守 |

### 5.2 典型周排课模型

| 时段 | 周一 | 周二 | 周三 | 周四 | 周五 |
|------|------|------|------|------|------|
| 1-2节 | 智能制造班（机器人区+数字制造） | 人工智能班（机器人+电子） | 新能源班（新能源区+电子） | 智能制造班 | 人工智能班 |
| 3-4节 | 新能源班 | 智能制造班 | 人工智能班 | 新能源班 | 智能制造班 |
| 5-6节 | 开放使用/项目 | 开放使用/项目 | 开放使用/项目 | 竞赛训练 | 开放使用/维护 |
| 7-8节 | 竞赛训练 | 选修课 | 竞赛训练 | 选修课 | 设备维护日 |

> 三个专业可**同时使用不同区域**，实现空间共享。例如：智能制造班用机器人区，新能源班用新能源区，人工智能班用电子+电脑区，三者互不干扰。

### 5.3 单节课排课模板（90分钟）

| 时间 | 内容 | 区域 |
|------|------|------|
| 0–10min | 教师讲解+安全提示 | 教学共创区 |
| 10–25min | 演示 | 对应功能区 |
| 25–75min | 分组实操（轮换） | 各功能区 |
| 75–85min | 小组分享+讨论 | 教学共创区 |
| 85–90min | 整理+5S | 全区域 |

## 六、人员配置

### 6.1 教学人员

| 角色 | 数量 | 职责 |
|------|------|------|
| 主讲教师 | 1人/班 | 课程设计、讲授、总体指导 |

| 角色 | 数量 | 职责 |
|------|------|------|
| 空间管理员 | 1人 | 日常运营、设备维护、安全检查、预约管理 |
| 学生助理 | 2–4人 | 开放时段值守、设备基础指导、5S管理 |

## 七、并发使用容量评估

### 7.1 最大并发人数

| 使用模式 | 最大人数 | 说明 |
|---------|---------|------|
| 单班上课 | 40人 | 标准班制 |
| 两班同时（分区） | 60–70人 | 不同专业用不同区域，需2组教师 |
| 开放使用 | 20–30人 | 需管理员值守，设备预约 |
| 活动/工作坊 | 30–40人 | 以教学区为主 |

> ⚠️ 超过40人同时使用时，需确保：每个功能区不超过设计容量、通道畅通、安全监督到位。

### 7.2 设备并发瓶颈

| 设备 | 同时使用人数上限 | 瓶颈原因 |
|------|----------------|---------|
| 激光切割机 | 1人/台（2台=2人） | 操作需专人，排队等待 |
| 工业机械臂 | 3–5人/台（围栏内1人操作） | 安全限制 |
| 桌面CNC | 1人/台（3–4台=3–4人） | 操作需专人 |
| 新能源高压台架 | 2–3人/台（需两人作业制） | 安全限制 |
| 电子工位 | 2人/工位（10–12个=20–24人） | 工位数量 |
| 3D打印机 | 无人值守，提交任务即可 | 非瓶颈 |
