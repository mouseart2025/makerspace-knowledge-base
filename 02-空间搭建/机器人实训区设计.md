# 机器人实训区设计

> 机械臂/四足机器狗/桌面机器人实训区专项设计：安全围栏、地面承重、急停装置、测试空间、维护工位、人机协作安全距离
> 调研时间：2026-08 ｜ 主要来源：T/CAMETA《机器人技术专业实训教学条件建设指南》、GB/T 42627-2023、GB/T 20867.1—2024、ISO 10218-1:2025、ISO 13857、ISO/TS 15066、主流厂商手册（遨博/新松/埃斯顿/宇树等）
> 定位：本文是 [设备摆放与布局规范.md](设备摆放与布局规范.md) 的专业细化篇——针对智能制造与人工智能技术应用专业的机器人实训场景。

## 一、适用场景与设计原则

### 1.1 适用场景

- **工业机械臂实训区**：六轴工业机器人（负载3–10kg级）的编程、操作、维护
- **四足机器狗实训区**：宇树Go2/A1等教育版四足机器人的运动控制、导航、群控
- **桌面机器人实训区**：协作机械臂（如dobot、越疆）、桌面级小型四足的教学开发
- 单班40人，分组教学，空间为L型434㎡的一部分

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **安全分区** | 工业机器人必须有物理围栏隔离；协作/桌面机器人可开放但需安全距离 |
| **急停冗余** | 急停回路独立于主控制系统，多点可达 |
| **地面承重** | 工业机器人需核算楼板承重，必要时做独立基础 |
| **测试空间充足** | 四足/移动机器人需足够的运动测试空间 |
| **维护可达** | 设备周围预留维护空间，工具/备件就近 |

## 二、工业机械臂实训区

### 2.1 安全围栏设计

#### 2.1.1 围栏高度标准

| 标准 | 常规区域 | 高风险区域 | 备注 |
|------|---------|-----------|------|
| **GB/T 42627-2023** | ≥1.4m | ≥2.0m（重型/高空坠物） | 作业面距基准面≥2m时≥1.05m |
| **T/CAMETA实训指南** | ≥1.8m | — | 团体标准，教学场景推荐 |
| **ISO 13857** | ≥1.4m（围栏在最大允许距离时） | — | 距离缩短时高度需增加 |
| **厂商实践** | 1.8–2.2m | 2.0–2.5m | 高于设备最大运动区间 |

> ⚠️ 教学场景建议取**≥1.8m**，兼顾安全与观察需求。围栏整体高度必须高于机器人最大运动区间，杜绝跨越风险。

#### 2.1.2 围栏材质与规格

| 参数 | 标准规格 | 定制范围 |
|------|---------|---------|
| 立柱 | ≥50×50×t5mm，黄色烤漆 | 40×40–80×80mm |
| 网片材质 | 低碳钢丝Q235，镀锌/烤漆 | 不锈钢丝 |
| 丝径 | 4.0–6.0mm | 3.0–6.0mm |
| 网孔 | 高危区30×30mm；精密区≤12mm | 按需 |
| 单扇宽度 | 1.5–3.0m | 1.0–3.5m |
| 表面处理 | 灰色烤漆网格，黄色立柱 | 按需 |

#### 2.1.3 安全门与联锁

- 必须设置**安全门**，配备安全插销开关/电磁锁
- 开门即触发安全停机（安全联锁）
- 检修时人员通过安全门进入，门保持开启状态
- 围栏外设急停按钮，门内也设急停

### 2.2 地面承重与基础

#### 2.2.1 承重要求

| 机器人类型 | 地面承重要求 | 基础厚度 | 备注 |
|-----------|-------------|---------|------|
| 小型桌面机器人（≤3kg负载） | ≥500kg/㎡ | 普通地坪即可 | 可放工作台 |
| 中型工业机器人（3–10kg负载） | ≥2吨/㎡ | ≥150mm混凝土 | 需化学锚栓固定 |
| 大型工业机器人（≥50kg负载） | ≥5–8吨/㎡ | ≥200–300mm钢筋混凝土 | 需独立基础 |

> ⚠️ **楼上场景必须请结构工程师核算楼板载荷**。本项目楼上为宿舍，需特别关注振动传导（见[降噪减振方案.md](降噪减振方案.md)）。

#### 2.2.2 基础设计规范

| 项目 | 要求 |
|------|------|
| 混凝土强度 | ≥C25（25MPa），推荐C30 |
| 基础有效面积 | ≥1000×1000mm（中型机器人） |
| 平整度公差 | ≤0.5mm/m |
| 固定方式 | **化学锚栓**（禁止普通膨胀螺栓，长期振动易松动） |
| 锚栓规格 | 小型：M16 8.8级；中大型：M20/M24 |
| 锚固深度 | h_ef ≥ 8×d（螺栓直径） |
| 边距 | c ≥ 1.5×h_ef |
| 间距 | s ≥ 2.0×h_ef |
| 调平 | 整块钢制调平垫块，禁止多层薄铁皮叠加 |

#### 2.2.3 硬装已完成场景的解决方案

由于本项目硬装已完成，无法做预埋基础：
1. **可选方案A**：使用**加重铸铁底座/焊接钢结构底座**，配化学锚栓固定在现有地坪上
2. **可选方案B**：使用**独立移动式机器人工作站**（围栏+底座一体化），无需固定
3. **可选方案C**：协作机器人（cobot）放在工作台上，无需地面固定（负载≤5kg，速度受限）
4. 必须核算现有地坪厚度和承重，避免在环氧地坪/找平层上直接固定

### 2.3 急停装置

#### 2.3.1 急停设计要求（GB/T 20867.1—2024）

| 项目 | 要求 |
|------|------|
| 急停按钮形式 | 蘑菇头式（手掌/拳头可触及），红色按钮+黄色背景 |
| 停止类别 | 0类（立即切断动力）或1类（可控停止后切断），依风险评估 |
| 优先级 | 急停控制优先于机器人其他控制 |
| 回路独立性 | 急停回路**独立于主控制系统**，紧急时同步切断动力电源、气源、液压 |
| 制动响应 | ≤0.3秒 |
| 冗余制动 | 驱动机构设计有冗余制动装置 |
| 复位方式 | 手动复位，不得自动复位 |

#### 2.3.2 急停按钮布置

- 围栏外：每个安全门旁1个，围栏长边每≤5m设1个
- 围栏内：维护工位旁1个
- 示教器上：必须带急停按钮
- 总控台：1个总急停
- 高度：1.0–1.2m，便于操作

### 2.4 安全距离与测试空间

#### 2.4.1 安全距离计算

| 运动类型 | 最小安全距离 | 计算依据 |
|---------|-------------|---------|
| 直线运动区域 | ≥1.5m | 机器人最大速度≤2m/s时的制动缓冲 |
| 旋转/摆动运动 | 360°防护半径 = 最大臂展 + 制动距离 | 需计算全运动包络 |
| 协作机器人（ISO/TS 15066） | 按力限值计算，29个人体区域各有阈值 | 速度≤250mm/s时可无围栏 |
| 围栏与危险区间距 | ≥500mm（防止人员被挤压） | ISO 13857通道要求 |

#### 2.4.2 入侵检测

- 机器人工作半径内设置**安全光栅或激光扫描仪**
- 检测人员闯入时自动停机
- 安全光栅分辨率：≤30mm（检测手指）
- 响应时间：≤10ms

#### 2.4.3 单工作站最小空间

| 机器人臂展 | 工作站最小占地（含围栏） | 操作位 | 维护位 |
|-----------|----------------------|--------|--------|
| ≤600mm（桌面型） | 2.0×2.0m | 围栏外 | 围栏内 |
| 800–1000mm | 3.0×3.0m | 围栏外 | 围栏内 |
| 1200–1500mm | 4.0×4.0m | 围栏外 | 围栏内 |
| ≥1800mm | 5.0×5.0m | 围栏外 | 围栏内 |

### 2.5 维护工位

| 项目 | 要求 |
|------|------|
| 位置 | 围栏内或紧邻围栏，方便工具取用 |
| 面积 | ≥2㎡/工作站 |
| 配置 | 工具台、备件柜、润滑用品、清洁工具 |
| 电源 | 220V插座+气源接口 |
| 照明 | ≥500lux（维护需精细操作） |
| 文档 | 机器人手册、维护记录表、SOP上墙 |

## 三、四足机器狗实训区

### 3.1 空间需求

| 场景 | 最小空间 | 推荐空间 | 说明 |
|------|---------|---------|------|
| 单台基础调试 | 2×2m | 3×3m | 站立、行走、基础动作 |
| 单台特技动作（跳跃/后空翻） | 3×3m | 4×4m | 需腾空空间，上方≥2.5m净高 |
| 多台群控（2–4台） | 4×4m | 5×5m | 避免碰撞 |
| 导航/SLAM测试 | 5×5m以上 | 按需 | 需障碍物布置空间 |

> 部分教学型机器狗通过毫米波雷达（0.5m安全缓冲区）、碰撞力阈值（>45kPa自动停机）、红外光幕等设计，可在3×3m标准教室内部署。

### 3.2 地面要求

| 项目 | 要求 |
|------|------|
| 地面材质 | 平整、防滑、硬质地面（环氧地坪/瓷砖/木地板均可） |
| 平整度 | ≤3mm/2m，避免绊倒 |
| 坡度 | ≤2°（平地测试） |
| 障碍物 | 测试时清除场地内尖锐/易碎物品 |
| 边界 | 建议设低矮围栏（≥300mm）或地标线，防止机器人冲出 |

### 3.3 安全规范

- 操作前检查电池电量、关节紧固、传感器状态
- 特技动作测试时，人员保持≥1m安全距离
- 禁止在机器人运动时伸手触碰
- 多台同时运行时，设置群控急停（总急停可同时停止所有机器人）
- 电池充电使用专用充电器，禁止过充
- 机器狗运行时上方禁止悬挂物品

### 3.4 典型配置（40人班参考）

| 设备 | 数量 | 用途 | 占地 |
|------|------|------|------|
| 四足机器人（教育版） | 4–6台 | 分组教学，2–3人/台 | 每台3×3m测试位 |
| 充电柜 | 1个 | 集中充电+管理 | 1㎡ |
| 调试电脑 | 4–6台 | 编程+数据采集 | 调试工位 |
| 障碍物套件 | 1套 | 导航测试 | 按需布置 |

## 四、桌面机器人实训区

### 4.1 协作机械臂

| 项目 | 要求 |
|------|------|
| 典型负载 | 3–5kg（教学级协作机器人） |
| 安全标准 | ISO/TS 15066，力/功率限制模式 |
| 安全距离 | 速度≤250mm/s且力≤限值时可无围栏人机协作 |
| 工作台 | 稳固工作台，承重≥机器人重量×5 |
| 固定方式 | 桌面夹具或螺栓固定，禁止仅靠自重 |
| 急停 | 示教器急停+工作台急停 |
| 人员PPE | 安全鞋、防护眼镜、紧身工装，长发束起 |

### 4.2 桌面级小型四足机器人

- 整机尺寸适配桌面/实验室操作台
- 低功率驱动，轻量化工程塑料+铝合金结构
- 无高压、大扭矩部件，安全性高
- 适合零基础入门教学
- 桌面操作即可，无需专用场地

## 五、实训室面积配置标准（T/CAMETA）

| 实训室 | 设备对应实训人数 | 建议设备数量 | 占地面积 | 支持课程 |
|--------|----------------|-------------|---------|---------|
| 电气控制技术实训室 | 4–5人/台 | 8–10台 | ≥170㎡ | PLC、电机控制、工业网络 |
| 机器人操作运维实训室 | 4–5人/台 | 8–10台 | ≥120㎡ | 机器人技术基础、维护维修 |
| 机器视觉技术实训室 | 4–5人/台 | 8–10台 | ≥120㎡ | 机器视觉技术 |
| 机器人系统集成综合实训室 | 5–6人/套 | 6套 | ≥150㎡ | 工业机器人系统集成 |
| 机器人仿真实训室 | 1–2人/台 | 35台 | ≥90㎡ | 离线编程、虚拟仿真 |
| 移动机器人实训室 | 4–5人/台 | 8–10台 | ≥150㎡ | 移动机器人、导航 |

> 注：以上为独立实训室标准。在创客空间共享场景下，按**分区复用+模块化**配置，面积可压缩30–50%。

### 5.1 师生比与设备使用比

| 项目 | 标准 |
|------|------|
| 基础实训师生比 | ≤1:15 |
| 高危操作师生比 | ≤1:8 |
| 工业机器人使用 | ≤3人/台 |
| 工作站使用 | ≤5人/套 |
| 单次实训时长 | ≤4学时，高风险项目分时段 |

## 六、工程条件要求

| 系统 | 要求 |
|------|------|
| **电源** | AC380V三相+AC220V单相；过流保护+剩余电流动作保护器；可插拔线缆双重绝缘 |
| **接地** | 接地电阻≤1Ω（GB/T 16895.3-2024），导电连续性 |
| **气源** | 气动工具/夹爪需压缩空气接口，0.5–0.7MPa |
| **通风** | 考虑设备散热，空调通风设计保障机器人精度和控制系统稳定 |
| **照明** | 操作区≥300lux，维护区≥500lux，机器视觉区需光控分区 |
| **温度** | 18–28℃（机器人最佳工作温度） |
| **湿度** | 35–80%RH，无凝露 |
| **网络** | 千兆以太网，支持EtherCAT/ProfiNET等工业总线 |
