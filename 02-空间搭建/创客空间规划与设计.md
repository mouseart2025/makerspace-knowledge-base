# 创客空间规划与设计

> 分区原则、动线设计、透明化策略与安全细节
> 主要来源：科普场馆创客空间项目档案（柴火出品）+ Fab Foundation 空间指导 + 德国 maker-space 案例

## 一、空间规划的底层逻辑

> "所有的设备和空间的安排，都是为日后运营目标而服务。"——柴火《创客空间搭建及运营指南》前言

规划前先回答三个问题：
1. **运营目标是什么**？以授课培训为主 / 纯粹为创客服务 / 兼而有之？
2. **服务对象是谁**？学生 / 访客散客 / 会员创客 / 企业客户？
3. **用哪个层级对标**？Full Fab Lab（$120K）→ Mini Lab → Fab-in-a-Box（$10K）？

## 二、功能分区参考（科普场馆方案实例）

科普场馆创客空间（柴火设计）的分区构成：

```
┌─────────────────────────────────┐
│ 主入口（引流+接待）              │
│ 开放共享区（展示+交流）           │
│ 创新教室1（培训+数字制造服务）    │
│ 创新教室2（工作区+专业工作台）    │
│ 手造区（激光切割+重加工）        │
│ 整备间（备料+仓储+维护）         │
│ 走廊（存包+交通）                │
└─────────────────────────────────┘
```

### 2.1 创新教室 1 —— 培训主力空间

- **16 张 1.2m×1.2m 创客桌**，可灵活组合，支持三种布局：
  - **高容量模式**（48 人，讲座式）
  - **创客马拉松模式**（小组围合，通宵开发）
  - **团队项目模式**（4–6 人/组协作）
- 教师侧整面墙装**白板墙**（人所能及高度），板书 + 创意讨论
- 靠墙一字排开**服务设备**：3D 打印工作区、桌面数字切割与 3D 扫描工作区
- 右侧墙**壁柜储物组**（透明柜门，可视化管理）

### 2.2 创新教室 2 —— 专业工作台矩阵

一半为工作区，一半为小规模培训/项目区，配 8 张 1.2m×1.2m 创客桌。专业工作台包括：

| 工作台 | 配置 |
|--------|------|
| **电子工作台** | 处理电路板问题、电子产品设计与原型制作 |
| **打印/数字成型与雕刻工作台** | 兼教师办公位 |
| **可穿戴设计工作台** | 缝纫机、印花机 |
| **陶艺区** | 陶瓷 3D 打印机 + 电窑（地面需防水处理）+ 过滤池 |

### 2.3 手造区 —— 重型加工区

- 工业级激光切割机（1500×1100×1030mm），配电脑桌，需**玻璃隔断隔绝气味**（隔断在设备进场后再安装），**必须设计排气系统**
- 激光切割工作台（1157×772×900mm 加工桌面）
- 小工作台：木材、塑料简单加工
- **锂电池充电防爆箱**：创客项目大量使用锂电池，防爆箱让充电在受控环境进行，万一爆燃范围限于箱内

### 2.4 整备间 —— 后勤心脏

清理留空、保留水槽与钢制桌面，用于：存储小推车、培训装备准备、物料临时存放。

## 三、"透明化"设计策略（科普场馆方案的精华）

让路过的人**看见里面在发生什么**，是最便宜也最有效的引流设计：

| 编号 | 改造 | 目的 |
|------|------|------|
| 透明化 1 | 门厅墙体拆除一段 | 从入口可直接瞥见创新教室 1 的活动情境，吸引观众"一探究竟" |
| 透明化 2/3 | 教室 1/2 用半高玻璃窗 | 走廊人群对教室活动一目了然；半高设计又不会对室内用户形成太多干扰 |
| 透明化 4 + 拆墙 | 手造区拆门+临走廊墙体改透明墙 | 手造区获得更大空间，走廊可见内部状况 |

> 关键平衡：**全透明吸引外部流量，半高度保护内部专注**。

## 五、空间类型学（Fab / Make Your Way 综合）

典型 100–200㎡ Fab Lab 的空间构成：

**必备大中央空间**
- 低噪/低危机器区
- 计算机终端
- 大工作台（可兼作会议桌、容纳多台笔记本）
- 休息角（咖啡机、零食、冰箱、沙发——"知识转移的社交胶水"在咖啡机旁发生）

**可选扩展区**
- 设计与学习专用工作室
- 独立电子间
- 建造/混合使用/脏乱区（木工、油漆、铸造）
- 材料存储区（⚠️ 实际需求永远比预估大）
- 接待区
- 展览区（作品陈列 = 社区自豪感 + 招新利器）

**分区维度**（欧洲实践总结）：安静区 / 噪音区 / 潮湿区 / 数字区——用明确分区减少冲突、加速工作流。配套要求：机械通风、消防、PPE 库存。

## 六、德国 maker-space：设备管理的标杆

**maker-space.de**（慕尼黑，会员制，柴火运营文档中认证的"更高级和豪华"的典范）：

1. **全设备可视预约**：网站按平面图分区域（焊接车间、木工车间、金属车间、机器车间、培训室、3D 打印区、激光区、电子车间、纺织区、水刀区……），点选区域看到设备列表
2. **每台设备独立主页**：图片、介绍、可预约日程表、使用文档链接、价格（昂贵设备按时计费，如水刀切割机）
3. **轻量设备明示"无需预约"**：台钻等即到即用
4. 预约周期上限管理（如单次最长 6 小时），保障资源公平

**对柴火式空间的启示**：让用户**对所有设备一目了然**，并能获取有效信息规划自己的使用计划——"创客对创客空间的最基本要求，就是可以方便地使用那些个人难以拥有的设备。"

柴火的现行做法：新会员申请大型设备时，管理员询问基本问题确认能力，或给予必要指导——**开放优先、管理在后**。

## 七、布局反模式（避坑清单）

来自柴火运营文档对国内失败空间的总结：

| 反模式 | 后果 | 破解 |
|--------|------|------|
| 设备展厅化（只可远观） | 用户流失，负循环："不让用→不好用→没法用" | 在安全培训框架下最大自由开放 |
| 全封闭无透明度 | 路过的人不知道里面有什么 | 透明化设计（半高窗 + 透明墙）|
| 只有大设备没有工位 | 无法停留创作 | 工作台 + 电源 + 储物三件套 |
| 忽视存储 | 材料堆积挤占工作区 | 预留 15–20% 面积做仓储（宁可高估）|
| 没有社交空间 | 社区无法形成 | 咖啡角/休息区是刚需 |
| 排气通风后装 | 激光切割无法使用 | 装修阶段预埋排气管道 |
