# 机器人竞赛场地搭建规范

> 机器人竞赛场地搭建专项规范：场地尺寸、地面要求、安全隔离、可收纳/可变换设计、RoboMaster/VEX等主流赛事参考

## 一、设计原则

### 1.1 核心需求

创客空间中的竞赛场地需同时满足：
1. **日常教学**：机器人基础操作、编程调试
2. **竞赛训练**：主流赛事（VEX/RoboMaster/青少年机器人竞赛）的场地复刻
3. **空间复用**：非赛季可收纳，释放空间用于其他教学活动
4. **安全隔离**：竞赛机器人速度快、有飞射物，需有效隔离

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **模块化可拼装** | 场地由标准模块组成，快速搭建/拆卸 |
| **可收纳** | 非赛季场地组件可堆叠存放，占地≤2㎡ |
| **多赛事兼容** | 基础框架支持不同赛事的场地元素更换 |
| **安全第一** | 围栏高度、观众距离、飞射物防护达标 |
| **地面保护** | 不破坏硬装已完成的地面 |

## 二、主流赛事场地尺寸

### 2.1 VEX V5RC（V5机器人挑战赛）

| 项目 | 参数 |
|------|------|
| 场地尺寸 | **12'×12'（约3.66m×3.66m）** 正方形 |
| 围栏高度 | 约1英尺（约305mm） |
| 围栏材质 | 标准VEX场地围栏（塑料/金属框架） |
| 场地表面 | 灰色泡沫塑料场地垫 |
| 周边操作空间 | 每边≥2英尺（约610mm），供选手站立操作 |
| 最小总占地 | 约**4.9m×4.9m**（含操作空间） |
| 推荐总占地 | 约**5.5m×5.5m**（含裁判/观众空间） |

> VEX官方建议：场地四周预留2英尺以上开放空间，方便学生和伸出的机器人操作。必要时可放在角落，但两侧都需有操作空间。

## 三、地面要求

### 3.1 场地地面基础

| 项目 | 要求 |
|------|------|
| 平整度 | ≤3mm/2m，避免机器人行驶颠簸 |
| 硬度 | 硬质地面（环氧地坪、瓷砖、木地板均可） |
| 清洁度 | 无灰尘、无油污、无杂物 |
| 坡度 | ≤1°（基本水平） |
| 接缝 | 地面接缝需平滑，避免卡轮 |

### 3.2 场地垫/表面层

| 类型 | 材质 | 适用赛事 | 特点 |
|------|------|---------|------|
| 泡沫场地垫 | EVA泡沫，灰色 | VEX、青少年竞赛 | 标准配置，有一定缓冲，保护机器人 |
| PVC地胶 | 商用PVC地胶 | 通用 | 平整、耐磨、可卷起收纳 |
| 地毯 | 短毛地毯 | FLL等乐高赛事 | 摩擦力适中，适合小型机器人 |
| 直接用地坪 | 环氧地坪 | RoboMaster训练 | 硬度高，适合高速行驶 |

### 3.3 地面保护（硬装已完成场景）

- 场地垫直接铺设在现有地面上，**无需打孔/粘贴**
- 场地垫之间用胶带连接（低粘度胶带，不损伤地面）
- 围栏底部加橡胶垫，防止刮花地面
- 收纳时场地垫卷起竖立存放，避免折痕

## 四、安全隔离设计

### 4.1 围栏设计

#### 4.1.1 低矮围栏（VEX类赛事）

| 项目 | 要求 |
|------|------|
| 高度 | 250–310mm |
| 材质 | 塑料/铝合金框架+透明面板 |
| 稳定性 | 自重或配重固定，无需打孔 |
| 透明度 | 透明面板便于观赛和教学演示 |
| 连接方式 | 卡扣/磁吸连接，快速拼装 |

#### 4.1.2 高围栏（RoboMaster/有飞射物赛事）

| 项目 | 要求 |
|------|------|
| 高度 | ≥1.2m（防弹丸飞出） |
| 材质 | 铝合金框架+亚克力/钢丝网 |
| 网孔 | ≤10mm（防止弹丸穿过） |
| 稳定性 | 加重底座或L型支架，防倾倒 |
| 门 | 设检修门，带安全联锁（可选） |

### 4.2 操作区隔离

- 选手操作位与场地之间保持≥600mm距离
- 操作区设地标线，明确站立范围
- 观众区与场地保持≥1m距离
- 高速/飞射物赛事，观众区需有防护屏

### 4.3 应急安全

- 场地外设**总急停按钮**，可同时停止所有机器人
- 配备灭火器（电气火灾用CO₂/干粉）
- 场地周围保持通道畅通，≥1.2m
- 制定竞赛安全规则，赛前宣读

## 五、可收纳/可变换设计

### 5.1 模块化场地系统

#### 5.1.1 设计方案

```
┌─────────────────────────────────────┐
│  模块化场地组件构成：                 │
│                                     │
│  1. 基础框架（铝合金型材）            │
│     - 标准段：1m/0.5m两种长度        │
│     - 角连接件：90°/180°             │
│     - 快速锁紧：旋钮/快拆卡扣         │
│                                     │
│  2. 场地垫（EVA泡沫/PVC）            │
│     - 标准块：1×1m，厚度20–40mm      │
│     - 边缘魔术贴连接                 │
│                                     │
│  3. 赛事元素（可更换）               │
│     - VEX：得分物、桥、导入台        │
│     - RM：障碍物、基地、补给站       │
│     - 通用：地标线、起点区           │
│                                     │
│  4. 围栏（可折叠）                   │
│     - 折叠式：合页连接，折叠后1/4大小 │
│     - 堆叠式：标准段堆叠存放         │
└─────────────────────────────────────┘
```

#### 5.1.2 搭建/收纳时间

| 场地规模 | 搭建时间（2人） | 收纳时间 | 收纳体积 |
|---------|---------------|---------|---------|
| VEX V5RC（3.66m） | 30–45分钟 | 20–30分钟 | ~1.5×0.6×0.8m |
| 4×4m训练场地 | 45–60分钟 | 30分钟 | ~2×0.6×1.0m |
| 小型（2.44m） | 15–20分钟 | 10–15分钟 | ~1×0.5×0.6m |

### 5.2 多赛事兼容方案

**基础框架通用 + 赛事元素可更换**：

| 基础组件 | VEX配置 | RM配置 | 通用教学配置 |
|---------|---------|--------|------------|
| 3.66×3.66m框架 | ✓ | — | ✓ |
| 低矮围栏 | ✓ | — | ✓ |
| 高围栏扩展 | — | ✓ | — |
| 灰色场地垫 | ✓ | ✓ | ✓ |
| VEX得分元素 | ✓ | — | — |
| RM障碍物 | — | ✓ | — |
| 起点地标线 | ✓ | ✓ | ✓ |

### 5.3 收纳方案

| 组件 | 收纳方式 | 存放位置 |
|------|---------|---------|
| 场地垫 | 卷起竖立，直径≤300mm | 靠墙/储物架 |
| 围栏段 | 堆叠，高度≤1.5m | 储物区 |
| 赛事元素 | 分类收纳箱，标注内容 | 储物架 |
| 工具/配件 | 工具箱 | 就近存放 |

> 收纳总占地建议≤2㎡，可放在储物区或走廊侧边。

### 5.4 可变换设计

- **日常教学模式**：撤去赛事元素，场地作为机器人测试区使用
- **竞赛训练模式**：安装对应赛事元素，复刻比赛场地
- **展示模式**：场地作为机器人表演展示区
- **收纳模式**：全部组件收纳，空间释放用于其他活动

## 六、配套设施

### 6.1 操作区

| 项目 | 要求 |
|------|------|
| 操作位 | 每队1个操作位，配桌子（1.2×0.6m） |
| 电源 | 每个操作位配220V插座 |
| 网络 | 有线/无线网络，用于编程下载 |
| 座椅 | 可折叠椅，非赛季收纳 |

### 6.2 维修区

- 场地旁设维修工位（1–2个）
- 配工具台、万用表、烙铁、备件盒
- 配电脑用于编程和调试

### 6.3 观赛/教学区

- 场地一侧设观赛区，可容纳10–20人
- 配白板/大屏，用于战术讲解和回放
- 摄像机位（可选），用于录制比赛和训练
