# 创客空间现场勘察方法论（v1.0）

> 从创客空间建设项目现场勘察全过程提炼，可复用至其他创客空间/实训室建设项目。
>
> **编制**：柴火创客空间
> **日期**：2026-09-17
> **实践来源**：某 400㎡ 级 L 型空间勘察项目（22 项任务，70+ 张照片 + 6 段视频 + 1 个 SKP 模型）

---

## 一、为什么要做现场勘察

### 1.1 核心判断

所有布局方案在**几何层面成立**不等于**工程层面可行**。承重、配电、排烟、消防、照度这五项工程条件，不实测就无法确认。

> **A 组是关键路径。现场勘察不做完，阶段 2/3 的方案都是纸上谈兵。**

### 1.2 勘察能解决什么

| 类型 | 问题 | 不勘察的后果 |
|---|---|---|
| 几何矛盾 | 柱位数量、窗位真伪、层高净高 | 方案与现场冲突，设备无法落位 |
| 工程条件 | 配电容量、给排水、通风排烟、空调 | 设备买回来用不了，二次改造 |
| 安全合规 | 消防设施、疏散距离、接地系统 | 验收不通过，整改成本高 |
| 环境基线 | 照度、噪音、振动 | 非功能需求无验收标准 |
| 结构安全 | 楼板承重、楼上对应关系 | 重型设备压坏楼板，噪音扰民 |

### 1.3 一条纪律

**测不到就写"测不到"，并写明原因和需要谁配合。不要估算、不要凭经验填数、不要把"看起来够"写成"满足要求"。**

勘测数据是后面所有设计的输入源头，这里填错一个数，下游全错。

## 二、勘察前准备

### 2.1 必须带去现场的图纸（打印 A3）

| 图纸 | 现场用途 |
|---|---|
| 总平面图 | 主底图，所有定位以此为准 |
| 门窗详图 | 核对窗的真伪与窗台高度 |
| 立剖面图 | 核对层高、大梁位置与下沿标高 |
| 楼电梯详图 | 核对疏散楼梯位置与宽度 |

> 若现场有 CAD 电子版可调阅，优先用电子版比对；纸质图纸用于手写标注。

### 2.2 工具清单

**必带（缺一项就有任务做不了）**

| 工具 | 用途 | 备注 |
|---|---|---|
| 激光测距仪（量程≥50m，精度±2mm） | 主测量工具 | 电池满格 |
| 5m 钢卷尺 | 门洞、窗洞、柱截面等短距 | |
| 照度计（量程 0–20000 lux） | 照度实测 | 需能读色温更好 |
| 声级计（A 计权，Class 2 以上） | 噪音实测 | **手机 App 不合格，必须真仪器** |
| 手机（拍照+录像） | 全部 | 电量满格，带充电宝，**照片要能看清铭牌小字** |
| 强光手电 | 配电箱内、弱电井、吊顶内查看 | |
| 记号笔（可擦）+ 美纹纸 | 现场贴编号标签 | **严禁用不可擦记号笔在地面/墙面写字** |
| 2m 靠尺/水平尺 | 地面平整度 | |

**选带**

| 工具 | 用途 |
|---|---|
| 红外测温枪 | 空调出风温度、配电箱温度 |
| 相位检测插座 | 插座接地是否正常（**需电工操作**） |
| 测距轮 | 长通道快速测量 |
| 平板（装载平面图） | 现场直接标注 |

### 2.3 提前 1 天必须协调的事

打钩确认，**任何一项没落实就对应任务作废**：

- [ ] 配电箱能打开，且**有电工在场**（非电工不得开箱）
- [ ] 弱电井 / 网络机房能进入
- [ ] 空调机房或室外机能查看，能看到铭牌
- [ ] 消防设施可查（如有消防控制室，能调出本层平面图）
- [ ] **楼上对应楼层可以上去**（核实正上方功能分区）
- [ ] 现场当前是否在施工、是否有其他单位作业（影响噪音测量的基线真实性）
- [ ] 结构设计图纸 / 竣工图能否调阅（楼板承重必须）

### 2.4 安全须知

| 场景 | 规则 |
|---|---|
| **配电箱** | 只看不碰。**开盖、读数、拍照全部由校方电工操作**，我方人员在旁记录 |
| **登高** | 测层高、看吊顶需用梯子，必须有人扶梯；严禁踩踏窗台、管道、桥架 |
| **弱电井/机房** | 只拍照不插拔，严禁触碰任何在运行设备与线缆 |
| **施工现场** | 若现场有其他单位施工，佩戴安全帽，避开作业区 |
| **数据留档** | 所有照片当天双备份（手机 + 电脑/网盘），不依赖单一设备 |

## 三、任务分类法

### 3.1 三类任务，别混为一谈

| 类型 | 含义 | 现场能不能拿到答案 |
|---|---|---|
| **实测型** | 带仪器去量就有数 | ✅ 当场出数 |
| **查档型** | 看铭牌、拍图纸、抄参数 | ✅ 当场能抄，但要有人带你看 |
| **访谈型** | 要问人、问部门、问标准 | ⚠️ 现场只能问到线索，正式答复需会后跟 |

### 3.2 典型任务分类（22 项示例）

| 类型 | 任务编号示例 | 特点 |
|---|---|---|
| 实测型 | 柱位、窗位、层高、门洞、搬运路径、疏散距离、地面平整度、照度、噪音 | 带仪器，当场出数 |
| 查档型 | 配电箱容量、回路清单、空调制冷量、通风管道、接地系统、网络架构、楼板承重 | 看铭牌/图纸，需校方陪同 |
| 访谈型 | 主入口使用状况、气源条件、运营负责人 | 问人，会后跟进正式答复 |

> **特别注意**：楼板承重属于查档型，**现场量不出来**。别指望拿卷尺测出承载力——需要结构图纸或第三方检测。现场能做的是采集给结构工程师做判断的原始数据（梁柱截面、裂缝、渗水痕迹）。

## 四、任务分组与动线

### 4.1 按区域分组，避免来回跑

22 项任务按现场动线分成 7 组，同组任务在同一区域一次做完：

| 组 | 任务 | 区域 | 预计耗时 | 需校方陪同 | 优先级 |
|---|---|---|---|---|---|
| **A 建筑几何复核** | 柱位/窗位/层高/门洞/搬运路径/疏散/地面/主入口 | 全区 | 3.0h | 否 | 🔴 最高 |
| **B 电气** | 配电箱/回路/插座/给排水/接地 | 配电箱+全区 | 1.5h | ✅ 必须（电工） | 🔴 最高 |
| **C 暖通给排水** | 空调/通风/气源 | 空调机位+吊顶 | 1.0h | ✅ 必须 | 🟠 高 |
| **D 消防设施** | 消防栓/灭火器/安全出口 | 全区+消防室 | 1.0h | ✅ 必须 | 🔴 最高 |
| **E 网络弱电** | 网络架构/弱电井 | 弱电井/机房 | 0.5h | ✅ 必须 | 🟠 高 |
| **F 声光环境** | 照度/噪音/楼上对应 | 全区+楼上 | 1.5h | ✅ 必须 | 🔴 最高 |
| **G 结构承重** | 楼板承重/病害普查 | 查档为主 | — | ✅ 必须 | 🔴 最高 |

### 4.2 人力与时间

| 项 | 建议 |
|---|---|
| **时间** | 1 天（约 8.5h）。上午机电消防（需校方陪同与电工在场），下午几何复核与环境实测 |
| **人数** | 2 人：1 人主测 + 1 人记录拍照。**单人无法完成**——配电箱、楼上正下方对应点的垂直对齐验证都需要一人看守一人核对 |
| **校方陪同** | 必须全程 1 人，负责开配电箱、开弱电井、带路到楼上、协助索取结构图纸 |

### 4.3 半天方案（≈5 小时）

只做 🔴 最高优先级 12 项。其余另约半天补做。

> ⚠️ **任何情况下都不允许跳过"楼上功能对应"和"结构查档"**。前者决定噪音分区能否成立，后者决定重型设备能否落位——这两项缺失会让方案推倒重来，比多跑一趟的代价大得多。

## 五、每项任务的标准格式

### 5.1 四要素法

每项任务必须包含：

```
目的 → 方法 → 交付 → 验收标准
```

**示例：柱位复核**

- **目的**：解决模型与图纸的柱数量矛盾
- **方法**：从主入口进入，沿主通道逐根清点；每根测截面宽×深、中心点距墙距离、是否独立；区分独立柱/壁柱/墙垛三类；现场贴编号标签；每根拍 3 张照片
- **交付**：柱位复核表 + 手绘平面图标注 + 结论一句话
- **验收标准**：总数必须自洽，不允许"约 9 根"；每根柱有照片佐证，卷尺读数清晰

### 5.2 照片拍摄标准

| 要求 | 说明 |
|---|---|
| 全景照 | 含编号标签，展示与周边关系 |
| 特写照 | 卷尺入镜显示尺寸，铭牌小字清晰可读 |
| 对照照 | 图纸标注与现场实物同框 |
| 命名规则 | `IMG_日期_序号_任务编号.jpg`，如 `IMG_20260911_001_T01.jpg` |
| 数量底线 | ≥120 张（400㎡ 级空间参考值） |

### 5.3 原始数据留档

**不要只交整理后的结论，原始数据必须留档**：

- 现场手写记录表（扫描或拍照回传）
- 原始照片库（按任务编号分文件夹）
- 视频录像（搬运路径全程、噪音测量过程等）
- 模型文件（如有 SKP/CAD 现场标注版）

## 六、报告编制方法论

### 6.1 从原始数据到报告的五步

```
原始数据 → 数据清洗 → 差异识别 → 判定分级 → 报告输出
```

| 步骤 | 内容 | 关键动作 |
|---|---|---|
| **1. 原始数据** | 照片、记录表、视频、模型 | 按任务编号归档，不丢原始 |
| **2. 数据清洗** | 去重、补全、单位统一、异常值标记 | 照片核实驱动修正（如发现某张照片实为配电箱铭牌而非预期内容） |
| **3. 差异识别** | 实测值 vs 图纸值 vs 需求值 | 列出差异清单，标注影响范围 |
| **4. 判定分级** | 合格 / 有条件通过 / 不合格 | 每项给出判定依据，不做无依据判定 |
| **5. 报告输出** | 执行摘要 + 数据表 + 逐项详情 + 差异清单 + 补勘清单 | 红字标关键结论，补勘项定人定期 |

### 6.2 报告结构模板

```
1. 执行摘要（3 个红字结论 + 验收档位）
2. 关键数据表（Q 编号对应实测值）
3. 逐项详情（T01–T22，每项：实测数据→与图纸差异→结论→现场插图）
4. 差异清单（实测 vs 图纸，逐项列影响）
5. 补勘清单（未完成项 + 原因 + 责任人 + deadline）
6. 变更记录
```

### 6.3 判定分级标准

| 档位 | 条件 | 后续动作 |
|---|---|---|
| ✅ 合格 | 全部任务完成，数据完整，无重大差异 | 直接进入下一阶段 |
| ⚠️ 有条件通过 | 全部任务完成，但有 1–2 项待核实（不影响方案方向） | 标记待核实项，并行推进设计 |
| ❌ 不合格 | 有关键任务未完成（如楼上对应、结构查档），或数据矛盾无法解释 | 补勘后重新判定 |

> **空间未使用时的特殊处理**：若空间尚未投入使用，使用状况类判定（如主入口实际使用频率、人流方向）无依据，应改为"位置属性判定"（如哪个门位置最适合做主入口），不做使用状况判定。

### 6.4 甲方明示可无视的现状

若甲方已明示"电/水/网络按需重排"，则现状容量不构成约束，应转为**设计输入**（按实际需求重新设计），而非现状限制。报告中需明确标注"甲方已明示，现状仅参考"。

## 七、常见坑与应对

### 7.1 执行阶段

| 坑 | 表现 | 应对 |
|---|---|---|
| **单人勘察** | 配电箱、楼上对应验证无法完成 | 必须 2 人，1 主测 1 记录 |
| **校方陪同不到位** | 配电箱打不开、楼上上不去 | 提前 1 天确认；当天不到位当场记录"未完成+原因+找谁"，不自行推测 |
| **噪音基线失真** | 现场有施工/其他单位作业，测出来的不是真实背景噪音 | 记录测量时的现场状况；如有施工标注"施工中测量，基线偏高"；另约安静时段复测 |
| **照片看不清铭牌** | 回去整理时发现铭牌小字模糊，关键数据缺失 | 现场每拍完一张立即回放检查；铭牌拍 2 张（1 全景+1 特写） |
| **楼板承重想现场量** | 拿卷尺测承载力 | 明确这是查档型，现场量不出来；采集梁柱截面、裂缝、渗水痕迹供结构工程师判断 |

### 7.2 报告编制阶段

| 坑 | 表现 | 应对 |
|---|---|---|
| **估算被写成事实** | "看起来够"写成"满足要求" | 严格执行"测不到就写测不到"纪律 |
| **照片与文本不对应** | 读者无法将照片与文字描述对应 | 每张图配图注，说明图中内容与文本哪个数据对应 |
| **版本引用不一致** | 需求规格书引用勘察报告 v1.2，但报告已升到 v1.3 | 版本升级后同步更新所有引用文档的版本号 |
| **含图片的文档同步超时** | 含外部图片 URL 的 markdown 同步到在线文档超时 | 先同步纯文本，再逐张插入图片 |
| **判定无依据** | 空间未使用却判定"主入口使用频率高" | 改为位置属性判定，不做使用状况判定 |

### 7.3 修订阶段

| 坑 | 表现 | 应对 |
|---|---|---|
| **会议纪要未落实到文档** | 会上确认了事项，但报告没改 | 每次会议后 24h 内更新报告，变更记录写明来源 |
| **只改数据不改结论** | 数据更新了，但执行摘要的红字结论还是旧的 | 修订后重新检查执行摘要、判定档位、补勘清单是否同步 |
| **插图缺失** | 报告有数据但无图，读者难以理解 | 从原始勘测文档中精选关键插图，插入对应章节 |

## 十、与后续阶段的衔接

```
现场勘察报告
    ↓
需求规格书（引用实测数据作为约束条件）
    ↓
概念设计（方案叠合实测柱位/门窗/承重墙校验）
    ↓
深化设计（逐设备核对尺寸/承重/水电/排风）
    ↓
采购实施（进场路径验证，避免"设备买进来进不了门"）
```

**关键衔接点**：
- 需求规格书中的"现场实测约束"章节直接引用勘察报告数据
- 概念设计必须做平面图叠合校验（柱位、门窗、承重墙冲突）
