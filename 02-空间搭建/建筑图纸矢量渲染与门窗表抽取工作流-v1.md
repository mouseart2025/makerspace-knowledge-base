# 建筑图纸矢量渲染与门窗表抽取工作流（v1）

> 适用场景：拿到设计院 DWG/PDF 图纸后，要在**没有 CAD 软件**的电脑上产出①可打印、字可读的 A3 现场底图；②结构化的门窗表（Markdown/表格），供现场勘察与方案校核使用。
> 核心原则：**一切以矢量文字层为准，禁止栅格化放大凑数**。栅格图放大只会得到模糊像素，现场纸上不可读就等于没有。

---

## 一、管线总览

```
DWG ──dwg2dxf(libdxfrw)──> DXF(utf-8)
DXF ──dxfmodel.py render --block <图幅块> ──> 矢量 PDF（含真实文字层）
矢量 PDF ──fitz show_pdf_page(clip=…)──> A3 分幅打印包（总览+分幅索引）
矢量 PDF ──fitz get_text("words") 坐标切列──> 门窗表 JSON ──> Markdown / A3 表格
SVG 方位图 ──fitz convert_to_pdf──> 矢量 PDF ──> 同上分幅
```

工具：`dwg2dxf`（libdxfrw）、自研 `dxfmodel.py`（analyze/render，支持 `--block`、`--skip-block`、`--skip-frame`）、PyMuPDF(fitz)。

## 二、五个必踩的坑与对策

| # | 坑 | 对策 |
|---|----|------|
| 1 | 设计院 PDF 的"平面图"页可能**只含总平面**，楼层平面根本没出图 | 先 `get_text` 逐页核对标题文字；缺图就回源 DWG 渲染 |
| 2 | DWG 模型空间里多个图幅并存，块内还嵌套景观/总图底图，直接渲染会混入道路围墙、画布比例失真 | 用 `--block <图幅块名>` 隔离；嵌套底图用 `--skip-block` 正则跳过 |
| 3 | `--skip-block` 是**正则**，块名里的 `$`（嵌套块命名符）会被当行尾锚定而失配 | 用更宽的子串模式（如 `AX-00-LD`）而非全名 |
| 4 | DXF 转出后中文常是 latin-1 mojibake（GB18030 字节被按单字节读） | `moj.encode('gb18030').decode('latin-1')` 逆向修复；渲染脚本内置 recover |
| 5 | fitz `show_pdf_page` 不吃 SVG | 先 `fitz.open(svg).convert_to_pdf()` 得纯矢量 PDF 再拼页 |

## 三、可读性基线（打印件验收标准）

- 纸面可读下限：**字高 ≥ 2mm ≈ 5.7pt**（A3、正常光线下手写标注场景）。
- 验收方法：对源矢量 PDF 统计 `span['size']` 分布，取**中位数**作为"标注字高"，分幅缩放 s 必须满足 `中位字高 × s ≥ 5.7pt`；次要文字（索引符号等）可放宽但要在 README 声明。
- 放不下一整张就**分幅**：总览页画红框索引 + N 个分幅页；分幅源矩形长宽比与纸面可用区一致，避免拉伸变形；相邻分幅留 100–150 源单位重叠，防止标注被切。
- 打印包目录必须带 README：来源、再生成命令、弃用警告（哪些旧文件禁止再打印）。

## 四、门窗表抽取（表格类文字层）

1. 用 `get_text("words")` 取全部词及 bbox；表格按**列 x0 区间**切列，按**行 y 聚簇**切行。
2. 详图标注与表体常在同一页：**先用 x 区间把表体圈出来**，表外标注一律排除。
3. "类别"列是**竖向合并单元格**，标签垂直居中——**不要按 y 邻近归组**（会错行）。正确做法：按**编号前缀映射**归组（如 FM甲/FM乙/FM丙、MC、TC、ZC、BYC、FC、FJM、GC、GM、LM、TM、C、M），并与图面类型标签做 0 失配断言。
4. 组注（合并单元格的备注）回填整组；个别行的行注单独保留。
5. 成果必须带**口径声明**：合计是整栋还是单层、尺寸是洞口还是成品、有无窗台高列。现场只核子集时，写明"只核某层子集"。
6. 设计说明注（"注 1–注 18"）逐条原文抽取存档；其中"尺寸=洞口尺寸""须现场实测后方可加工"这类条款直接决定现场任务口径。

## 五、交付物清单（模板）

| 交付物 | 格式 | 要点 |
|--------|------|------|
| 现场方位/编号图 | SVG→矢量 PDF，总览+分幅 | 门/柱/窗编号可读，可直接打勾 |
| 楼层平面分幅 | 矢量 PDF，总览红框+分幅 | 满足可读性基线 |
| 门窗表 | Markdown + A3 表格 PDF | 前缀归组+断言+口径声明 |
| 层高/标高摘录 | Markdown | 供剖面核对与设备净高校核 |
| README | Markdown | 来源、再生成命令、弃用警告 |
