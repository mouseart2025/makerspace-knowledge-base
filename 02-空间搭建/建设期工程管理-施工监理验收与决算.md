# 创客空间建设期工程管理：施工、监理、验收与决算

> **本文是什么**：一份面向创客空间/实训室**建设期**（也就是"平面图定了、钱批了，开始动土/动电/装设备"到"正式交付"这一段）的工程管理规范——覆盖施工组织、监理、进度款、变更与签证、隐蔽工程、竣工验收、资料归档与竣工决算。
> **为什么需要**：本库此前在**规划层**（怎么设计）与**运营层**（怎么用）之间，缺了最烧钱、最容易扯皮的一段——**建设期**。实践中的典型问题是：图纸漂亮但施工做不出来；隐蔽工程（管线、防水、承重加固）封进去之后才发现问题；变更口头说完没签证，结算时各说各话；验收走过场，开学第一周设备就因电容量不足集体跳闸。**建设期的管理质量，直接决定规划成果能不能落地。**
> **口径说明（重要）**：本文的法规名称与一般程序来自公开规则；但**监理强制范围、竣工验收的具体备案要求、变更签证的审批权限、工程结算与决算的地方规定**差异很大，**必须由建设单位基建/财务部门与当地主管部门人工复核**。本文不构成工程或法律意见。
> **脱敏声明**：本文不含真实项目名称、真实金额、真实合同编号、真实供应商名称或本地路径；示例一律以"某职业院校""某科普场馆"表述。

## 一、建设期的四个角色与三条线

### 1.1 角色分工

| 角色 | 代表谁的利益 | 核心职责 | 不该做的事 |
|------|-------------|---------|-----------|
| **建设单位（甲方）** | 使用方 / 出资方 | 需求确认、预算与合同、变更审批、验收组织、决算 | 直接指挥施工班组（越过监理/总包） |
| **设计单位** | 受甲方委托 | 施工图设计、设计交底、设计变更、参与验收 | 只在开工前出现，施工期失联 |
| **监理单位** | 受甲方委托，独立监督 | 质量、进度、投资、安全四控；隐蔽工程验收；签证审核 | 与施工方利益绑定，形同虚设 |
| **施工单位（总包）** | 承包方 | 按图施工、质量自控、资料编制、安全责任 | 无签证擅自变更；资料事后补做 |

> ⚠️ **关键原则**：**甲方不要越过监理直接指挥工人。** 一旦形成"甲方口头指令 → 工人照做 → 无书面记录"的链条，出现质量或造价争议时，责任无法认定。**所有指令走书面（含工作联系单、会议纪要、签证单）。**

### 1.2 三条并行主线

| 线 | 内容 | 失控后果 |
|----|------|---------|
| **质量线** | 材料进场检验 → 工序验收 → 隐蔽工程验收 → 分部工程验收 → 竣工验收 | 返工、安全隐患 |
| **造价线** | 合同价 → 变更/签证 → 进度款 → 结算 → 决算 | 超预算、结算纠纷 |
| **资料线** | 图纸、变更、签证、验收记录、材料合格证、检测报告、影像资料 | 无法验收、无法审计、无法追责 |

> ★ **核心结论**：**资料线是最容易被忽视、却最决定性的一条。** 竣工验收和竣工决算看的不是"活干得好不好"，而是**"资料能不能证明活干得合格、钱花得合理"**。资料从开工第一天就要同步做，**不能等完工再补**。

## 二、建设期全过程：八个阶段

| 阶段 | 主要工作 | 关键产出 | 甲方必做的检查 |
|------|---------|---------|--------------|
| **1 开工准备** | 施工图审查、施工组织设计审批、场地移交、临水临电、报建手续 | 开工报告、场地移交单 | 施工组织设计是否经监理审批 |
| **2 设计交底与图纸会审** | 设计单位交底，各方提出图纸问题并形成会审纪要 | 图纸会审纪要 | **会审纪要是否覆盖了设备用电/承重/排风等专业需求** |
| **3 材料与设备进场** | 报验、抽检、见证取样、封样 | 材料报验单、检测报告、封样记录 | 是否与设计/合同要求一致；有无以次充好 |
| **4 施工过程** | 各工序施工、旁站监理、工序验收 | 工序验收记录、监理日志 | 隐蔽工程是否在覆盖前验收 |
| **5 变更与签证** | 设计变更、现场签证、价款调整 | 变更单、签证单 | **先审批后施工**；签证内容是否量化 |
| **6 专项验收** | 消防、电气、防雷、环保、特种设备、无障碍等按需专项验收 | 专项验收意见 | 是否达到使用条件 |
| **7 竣工验收** | 预验收、整改、正式验收、移交 | 竣工验收报告、移交清单 | 功能实测（不只"看外观"） |
| **8 资料归档与决算** | 竣工资料整理、结算审核、决算编制、资产入账 | 竣工资料、结算书、决算表、资产台账 | 资料与实体是否一致；资产是否入账 |

## 三、施工管理与监理：怎么用、别白请

### 3.1 施工进度控制

| 工具 | 用途 | 要点 |
|------|------|------|
| **总进度计划** | 明确里程碑与关键线路 | 与开学/交付日期倒排，预留整改期 |
| **月度/周计划** | 分解执行 | 每周例会对照 |
| **进度偏差分析** | 判断是否影响交付 | 偏差 > 1 周即预警，分析原因与补救 |
| **关键路径识别** | 找出不能延误的工序 | 通常包含：结构加固 → 水电管线 → 隐蔽验收 → 装修 → 设备安装调试 |

**进度计划必须包含的"隐形工序"**（最常被漏）：

| 工序 | 为什么关键 |
|------|-----------|
| **结构加固/承重处理** | 重型设备上楼的前提；做完才能铺装 |
| **电力增容/配电改造** | 审批与施工周期长，常成为关键路径 |
| **排风/除尘管道** | 与吊顶、消防冲突，需协调 |
| **消防改造与验收** | 专项验收周期不可压缩 |
| **网络与弱电** | 与装修同步，事后补线代价高 |
| **设备进场与调试** | 需在装修完成后、且电力可用时进行 |

### 3.2 监理：五个必到场的节点

| 节点 | 监理动作 |
|------|---------|
| **材料进场** | 见证取样、核对规格与合格证 |
| **隐蔽工程覆盖前** | 逐项验收并留存影像，**未验收不得覆盖** |
| **关键工序施工** | 旁站监理（如结构加固、防水、电气压接） |
| **变更实施前** | 审核变更的必要性与工程量 |
| **竣工验收** | 参与验收、出具监理意见 |

> ⚠️ **判断监理是否形同虚设的三个信号**：① 监理日志长期空白或千篇一律；② 隐蔽工程验收单在覆盖后才补签；③ 签证单上监理意见一律"同意"而无工程量核算。**发现任一信号，甲方应书面要求整改。**

## 四、变更与签证：造价失控的头号原因

### 4.1 变更 vs 签证

| 项 | 变更 | 签证 |
|----|------|------|
| **定义** | 对设计/合同内容的修改（设计变更、工程变更） | 对现场实际发生的、合同外的工作量/费用的确认 |
| **触发方** | 甲方需求变化、设计原因、现场条件 | 现场条件与图纸不符、增加的零星工作 |
| **典型载体** | 设计变更通知单、工程变更单 | 现场签证单 |
| **审批** | 依权限逐级审批（可能涉及原设计单位、原审批部门） | 监理 + 甲方现场代表 + 造价人员 |
| **共同要求** | **书面、先审批、量化、有依据** | 同左 |

### 4.2 变更签证五条铁律

| # | 铁律 | 说明 |
|---|------|------|
| 1 | **先审批后施工** | 除紧急抢险外，未经审批不得施工；否则事后无法认定 |
| 2 | **口头无效** | 任何口头指令必须转化为书面文件并经签认 |
| 3 | **量化到可计价** | 不能只写"增加管线改造"，要写清材质、规格、数量、位置、单价依据 |
| 4 | **影像留证** | 变更前后拍照/录像，标注日期与位置 |
| 5 | **及时办结** | 变更发生后尽快办结，**不要攒到结算前集中补签** |

### 4.3 签证单要素模板

```text
签证编号：__________        日期：____
工程名称：____________________
签证事由：□现场条件与图纸不符 □甲方指令 □设计原因 □其他____

一、变更/增加内容
  部位：__________  工序：__________
  材质/规格：__________
  数量：__________（附计算式与简图）

二、发生原因与责任判定
  ____________________

三、影像与旁证
  □照片____张 □录像 □监理日志第__页 □会议纪要第__号

四、费用估算
  单价依据：□合同单价 □信息价 □市场询价（附证明）
  金额：__________（最终以结算审核为准）

施工方：____  监理：____  甲方现场代表：____  造价：____
```

### 4.4 工程造价失控的五个典型信号

| 信号 | 风险 |
|------|------|
| 签证数量在结算前突然暴增 | 可能存在事后补签、虚增工程量 |
| 大量变更无设计变更通知单 | 程序不合规 |
| 变更单价远高于合同单价且无依据 | 造价虚高 |
| 甲方现场人员在签证上"只签字不核对" | 失控 |
| 变更累计金额接近或超过合同价的一定比例 | 可能已触发重新审批要求，需复核 |

## 五、隐蔽工程：封进去就再也看不见

隐蔽工程指**被后续工序覆盖后无法直接检查**的部分，是本阶段**风险最高、返工代价最大**的环节。

| 类别 | 典型内容 | 覆盖后若出问题的后果 |
|------|---------|-------------------|
| **结构类** | 钢筋、预埋件、结构加固 | 承重不足，需破拆 |
| **防水类** | 卫生间、屋面、设备间防水 | 渗漏、损坏设备 |
| **电气类** | 线管敷设、接线、接地、防雷 | 火灾、触电、容量不足 |
| **给排水类** | 管道敷设、试压 | 漏水 |
| **通风类** | 排风/除尘管道、防火阀 | 排风无效、消防隐患 |
| **弱电类** | 网络、监控、门禁预埋 | 事后明线、影响美观与信号 |

### 5.1 隐蔽工程验收流程

| 步骤 | 动作 | 记录 |
|------|------|------|
| 1 | 施工方自检合格后报验 | 报验单 |
| 2 | 监理组织验收（甲方、设计按需参加） | 验收记录 |
| 3 | 现场核查（尺寸、材质、工艺、坡度、接地电阻等） | 实测数据 |
| 4 | **影像留存**（同角度拍"过程—完成—标注位置"） | 影像资料 |
| 5 | 验收合格签认 | 隐蔽工程验收单 |
| 6 | 方可覆盖，进入下一工序 | 施工记录 |

> ★ **不可妥协的一条**：**未经隐蔽验收，不得覆盖。** 一旦施工方"先封后报"，应书面要求开孔复验或采取其他可验证手段，并追究违约责任——**妥协一次，后续所有隐蔽工程都会失去约束。**

### 5.2 创客空间隐蔽工程的重点核对项

| 项 | 核对内容 |
|----|---------|
| **电力容量** | 进线容量、配电箱回路数、每回路额定电流、是否为大功率设备独立回路、是否预留余量 |
| **插座点位** | 数量、位置、高度、类型（普通/工业/防溅）、是否与设备布局图一致 |
| **接地与等电位** | 接地电阻实测值、等电位连接、防静电措施 |
| **排水** | 设备间/洗手区排水、地漏、防返溢 |
| **排风** | 管道走向、风机风量、防火阀、与消防联动 |
| **消防** | 喷淋/烟感点位、疏散指示、防火分隔、与装修的冲突处理 |
| **网络** | 弱电箱位置、交换机容量、AP 点位、机柜散热 |
| **承重** | 加固方式、预埋件、重型设备固定点 |

## 六、竣工验收：不是"看一眼"，是"逐项测"

### 6.1 验收三阶段

| 阶段 | 谁组织 | 内容 |
|------|--------|------|
| **预验收** | 监理/甲方 | 查找问题、形成整改清单，施工单位限期整改 |
| **专项验收** | 相关主管部门/专业机构 | 消防、电气、防雷、环保、特种设备、无障碍等（按项目需要） |
| **竣工验收** | 甲方组织（设计、监理、施工、使用方参加） | 全面核查功能、质量、资料，形成验收报告 |

### 6.2 功能实测清单（创客空间专属）

| 类别 | 实测项 | 判据 |
|------|--------|------|
| 电力 | 各回路负荷测试、大功率设备同时启动 | 不跳闸、压降在允许范围 |
| 电力 | 接地电阻、漏电保护动作 | 符合设计要求 |
| 排风 | 风机风量、噪声、负压效果 | 达到设计要求；激光/焊接区排风有效 |
| 消防 | 烟感/喷淋联动、疏散指示灯、灭火器配置 | 通过专项验收 |
| 网络 | 各点位测速、AP 覆盖与漫游 | 满足教学与设备联网 |
| 弱电 | 门禁、监控、广播联动 | 功能正常 |
| 装修 | 地面承载力、防静电、耐磨、防滑 | 与设备需求匹配 |
| 环境 | 照明照度、噪声、温湿度 | 满足教学与设备要求 |
| 无障碍 | 通道净宽、坡道、扶手、无障碍卫生间 | 与 [人体尺度与消防无障碍硬约束-现行国标校验清单.md](人体尺度与消防无障碍硬约束-现行国标校验清单.md) 对照 |
| 设备 | 安装水平度、固定、间距、安全距离、急停 | 与 [设备摆放与布局规范.md](设备摆放与布局规范.md) 对照 |

### 6.3 验收必备资料清单

| 类别 | 资料 |
|------|------|
| 程序类 | 开工报告、图纸会审纪要、施工组织设计审批 |
| 质量类 | 材料合格证与检测报告、工序验收记录、隐蔽工程验收单、专项验收意见 |
| 变更类 | 设计变更通知单、工程变更单、现场签证单、会议纪要 |
| 检测类 | 电气/防雷/消防/环保等检测报告、设备调试记录 |
| 影像类 | 施工过程影像、隐蔽工程影像、竣工影像 |
| 竣工图 | 与实际一致的竣工图纸（**必须按变更修正**） |
| 设备类 | 设备清单、说明书、合格证、保修卡、培训记录 |
| 验收类 | 预验收整改记录、竣工验收报告、移交清单 |

> ⚠️ **最常被忽略的一项**：**竣工图必须是"实际建成"的样子，而不是原设计图。** 若施工中有变更但竣工图未更新，后续维修、改造、二次装修将失去依据。

## 七、竣工结算与决算：两个不同的东西

| 项 | 竣工结算 | 竣工决算 |
|----|---------|---------|
| **对象** | 与施工单位结清工程款 | 整个建设项目的全部资金来源与运用 |
| **编制方** | 施工单位编制，甲方/造价咨询审核 | 建设单位（甲方）财务与基建部门 |
| **内容** | 合同价 + 变更 + 签证 − 违约扣款 | 全部支出（工程、设备、设计、监理、其他）+ 资金来源 + 资产形成 |
| **用途** | 支付尾款、了结合同 | 核定资产价值、办理资产入账、绩效评价、审计 |
| **时间** | 竣工验收后 | 结算完成后（通常更晚） |

### 7.1 结算审核要点

| 要点 | 说明 |
|------|------|
| 合同范围核对 | 结算内容是否超出合同范围 |
| 工程量核对 | 与竣工图、签证、实测核对 |
| 单价核对 | 合同单价 / 信息价 / 市场价的适用 |
| 变更签证核对 | 手续是否齐全、是否重复计价 |
| 违约与扣款 | 工期延误、质量问题的扣款 |
| 甲供材料 | 是否从结算中扣除 |
| 争议处理 | 争议项单独列出，不影响无争议部分支付 |

### 7.2 决算与资产入账

| 步骤 | 动作 |
|------|------|
| 1 | 汇总全部建设支出（工程、设备、设计、监理、其他费用） |
| 2 | 核对资金来源与支出是否匹配 |
| 3 | 形成资产价值（固定资产、无形资产按规则分摊） |
| 4 | 录入资产台账、建卡编号（与 [../04-运营与管理/财务预算与资产管理.md](../04-运营与管理/财务预算与资产管理.md) 一致） |
| 5 | 编制竣工决算表与说明 |
| 6 | 归档，作为审计与绩效评价依据 |

> ★ **衔接提醒**：**建设期的竣工决算，是运营期资产管理的起点。** 决算形成的资产清单、价值与编号，必须**无缝交接**给资产管理员与设备管理系统——否则会出现"建好就丢账"的经典问题。

## 八、资料归档：一册定生死

### 8.1 归档目录建议

| 卷册 | 内容 |
|------|------|
| 第一卷 程序文件 | 立项、批复、开工、会审、施工组织设计 |
| 第二卷 合同与造价 | 合同、中标文件、预算、变更、签证、结算 |
| 第三卷 质量记录 | 材料报验、检测报告、工序验收、隐蔽验收 |
| 第四卷 专项验收 | 消防、电气、防雷、环保、特种设备、无障碍 |
| 第五卷 竣工图 | 全套竣工图纸（含变更标注） |
| 第六卷 设备资料 | 设备清单、说明书、保修、调试与培训记录 |
| 第七卷 竣工验收 | 预验收整改、验收报告、移交清单 |
| 第八卷 决算与资产 | 决算表、资产入账凭证、台账 |
| 第九卷 影像资料 | 过程影像、隐蔽影像、竣工影像 |

### 8.2 归档三条纪律

1. **同步归档**：资料随工序同步收集，竣工验收后 1–3 个月内完成整理归档；
2. **一份正本 + 异地/云端备份**：纸质与电子双套，电子件命名规范；
3. **可检索**：目录清晰、编号连续、与资产编号对应。

## 十一、常见坑

| # | 坑 | 后果 | 纠正 |
|---|----|------|------|
| 1 | 甲方越过监理直接指挥施工 | 责任无法认定 | 指令全部书面化 |
| 2 | 隐蔽工程先封后报 | 隐患无法检查 | 未验收不得覆盖 |
| 3 | 变更口头说、事后补签 | 结算纠纷 | 先审批后施工、及时办结 |
| 4 | 只审结算不做决算 | 资产不入账 | 结算 → 决算 → 入账闭环 |
| 5 | 竣工图沿用设计图 | 后续维修改造失去依据 | 按变更修正竣工图 |
| 6 | 验收只看外观不测功能 | 开学即暴露问题 | 功能实测清单 |
| 7 | 资料完工后集中补做 | 真实性受质疑 | 同步归档 |
| 8 | 忘记"养设备"的配套 | 设备到位但无法用 | 建设期同步完成水电/排风/网络配套 |
