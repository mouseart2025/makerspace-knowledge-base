## 二、方法论核心验证结论

### 2.1 方法论有效的部分

1. **两层规划法（部门级→空间级）**非常有效——先定功能块和邻接关系，再下钻设备，避免了一开始就陷入细节
2. **输入三分（场地/约束/设备目录）**让AI输出更可控，不会凭空编造
3. **3方案对比**强制AI发散，避免单一方案偏见
4. **硬约束清单**在校验阶段发挥了关键作用（面积、安全、通道）
5. **"面积紧张"这个核心问题是AI在需求解析阶段主动发现的**——AI做数据汇总的价值：把分散的设备占地清单汇总成总账，暴露出人工容易忽略的面积冲突

### 2.2 方法论的局限（需要工具补强）

1. **文字描述无法替代可视化**——AI能描述布局，但无法生成精确平面图。需要接入酷家乐AI布局/Snaptrude/Planner 5D做可视化
2. **空间几何判断弱**——L型的转角、柱子、门窗位置对布局的影响，AI仅凭文字描述无法准确判断，必须看平面图
3. **设备精确尺寸需要确定性工具**——AI知道"每台12㎡"，但不知道12㎡在L型转角处如何摆放
4. **规范细节可能幻觉**——AI引用安全规范时需对照知识库原文核验

### 2.3 方法论优化建议（已纳入工作流）

| 优化项 | 原方法 | 优化后 |
|--------|--------|--------|
| 步骤③后增加**平面图可视化校验** | AI出泡泡图文字描述 | 用酷家乐AI布局/Snaptrude把泡泡图变成实际平面图，验证空间可行性 |
| 步骤④明确**AI概念→CAD精确**分工 | 要求AI出设备布局 | AI出概念布局（位置/邻接/面积），精确几何交给CAD工具 |
| 步骤①强制输出**面积总账** | 分类列设备 | 必须先算设备直接占地合计，再判断面积是否紧张 |
| 步骤②增加**现场踏勘确认项** | 仅列约束 | 增加"出入口/承重/水电/排烟点位"等AI无法获取的待确认清单 |
| 步骤⑤增加**平面图叠合校验** | 文字校验 | 将AI布局与真实平面图叠合，检查柱子/门窗/承重墙冲突 |

## 三、关键决策方法（可直接复用）

### 3.1 面积总账法（步骤①强制输出）

> 需求解析第一步必须先算设备直接占地合计，与总面积对比，暴露面积是否紧张。这是本项目最重要的发现手段。

```
设备直接占地 = Σ（每类设备数量 × 单台含操作占地）
剩余面积 = 总面积 - 设备直接占地
需覆盖：通道 + 储物 + 管理 + 公共教学 + 展示
```

- 通道估算：主通道约 35m 长 × 1.5m 宽 ≈ 50-53㎡（L型空间）
- 若剩余面积 < 通道+配套需求 → **面积紧张，必须用"可收纳/可变换/分时复用"策略解决**
- 本项目结果：设备占地 344.7㎡，剩余 89.3㎡，通道需 60-80㎡ → 高度紧张，倒逼竞赛场地可收纳设计

### 3.2 三方案对比法（步骤③强制发散）

> 强制AI生成3种**逻辑不同**的分区方案，避免单一偏见。推荐从三个角度切入：

| 方案角度 | 逻辑 | 适用 |
|---------|------|------|
| 专业集群 | 按专业相对独立，管理方便 | 专业差异大、需独立管理 |
| 噪音梯度 | 按噪音/振动强度分层 | 有噪音敏感区域（楼上宿舍、办公室） |
| 共享核心 | 中央公共区+周边专业环绕 | 面积紧张、需跨专业协作、平面图有"相通可共用"意图 |

**三方案对比维度**：面积可行性、噪音治理、专业独立性、跨专业协作、呼应平面图意图、管理复杂度。

### 3.3 硬约束清单法（步骤②）

> 硬约束（不可违反）与软约束（尽量满足）分离，校验阶段逐条对照。

**硬约束常见来源**：
- 场地：总面积上限、形状限制
- 环境：噪音/振动/采光敏感区方向
- 安全：机器人围栏、高压电池隔离、激光排烟、疏散出口
- 设备：固定占地（如竞赛场地）、独立排烟管道
- 改造约束：硬装已完成→免打孔/可移动/铝型材隔断

**软约束常见来源**：自然采光优先、专业区相对独立、成果展示靠近入口、储物靠近制造区、焊接与精密区隔离。

### 3.4 四维校验法（步骤⑤）

| 维度 | 检查内容 |
|------|---------|
| 面积 | 每区设备占地 vs 分配面积，是否超支 |
| 动线 | 学生/参观/物料三条动线是否交叉 |
| 安全 | 逐条对照硬约束 |
| 班制 | 单班人数能否同时操作（或分两组轮换） |

## 四、可复用提示词模板

### 4.1 需求解析提示词

```
你是创客空间规划顾问。基于以下真实输入，输出结构化空间需求清单：
场地：[场地描述，如L型434㎡，硬装完成，楼上宿舍]
设备清单：[粘贴设备清单]
课程需求：[粘贴课程方案]
要求：
1. 按功能区分类，每区标注服务专业、核心设备、建议面积、优先级
2. 先算设备直接占地总账，再判断面积是否紧张
3. 标注不确定项和需要现场确认的内容
```

### 4.2 分区方案生成提示词

```
基于以下约束，生成3种功能分区方案（部门级泡泡图）：
总面积：[X㎡ L型]
功能区需求：[粘贴步骤①结果]
硬约束：[粘贴步骤②结果]
每种方案用文字描述：
- 各功能块在空间中的位置（横向臂/纵向臂/转角）
- 邻接关系（必须相邻/必须隔离）
- 动线逻辑
- 优缺点
最后做三方案对比表并推荐一个。
```

### 4.3 校验提示词

```
对以下布局方案做四维校验：
1. 面积校验：每区设备占地 vs 分配面积，是否超支
2. 动线校验：学生/参观/物料三条动线是否交叉
3. 安全校验：逐条对照硬约束
4. 班制校验：[N]人能否同时操作
输出：通过/不通过/待确认，以及修正建议。
```

### 4.4 结构化输出提示词

```
把上面的布局方案输出为JSON规格：
{ 假设, 功能区(面积/位置/邻接), 设备摆放(坐标/朝向/依据),
  未满足约束, 动线, 需要现场确认项 }
```

## 五、实战关键决策记录（方法论应用示范）

> 以下为方法论在实际项目中的关键决策示例，展示"方法论→决策"的转化逻辑，可供其他项目参照。

| 决策 | 原因 | 依据 |
|------|------|------|
| 推荐"共享核心"方案而非"专业集群/噪音梯度" | 面积紧张+呼应平面图共享意图+跨专业协作 | 三方案对比 |
| 竞赛场地可收纳 | 固定占用会导致总面积超支 | 面积总账 |
| 高噪音区集中 | 楼上宿舍约束+降噪治理效率 | 硬约束 |
| 高压区独立 | 安全隔离 | 硬约束 |
| AI区与机器人区相邻 | 机械臂/机器狗项目需协作 | 课程方案 |

**本项目最关键的创新点（可复用思路）**：
1. **竞赛场地可收纳复用**：60㎡竞赛场地与公共教学区分时复用，解决面积紧张——这是AI在3方案对比中提出的，人工确认可行
2. **高噪音区集中治理**：制造+机器人集中在空间一侧，铝型材+亚克力围合，适配楼上宿舍约束
3. **中央共享核心**：呼应平面图"相通部分可共用"，三专业围绕共享核心布局

> 📌 注：以上为方法论应用示范。具体项目的完整数据（设备清单、图纸坐标、现场踏勘）属于项目内部档案，不随本知识库开源；其他项目可参照本方法论自行代入本项目的场地与需求数据。
