# 设备摆放与布局规范

> 设备级摆放工程细节：分区方法论、关键尺寸、单类设备场地要求、工程条件与验收流程

> 定位：本文是 [创客空间规划与设计.md](创客空间规划与设计.md) 的工程细化篇——前者解决「分区原则与动线」，本文解决「每台设备放哪、留多少距离、要什么工程条件」。

## 一、布局方法论：按危险等级分区（核心原则）

**不要按设备类型分区，按「噪音 / 粉尘 / 湿度」三要素的危险等级分区**（CADBlockDWG 方法论）。

### 1.1 三带分区法

| 地带 | 特征 | 典型设备 |
|------|------|----------|
| **A 带：安静清洁带** | 无尘、低噪、干燥 | 3D 打印、电子工作台、电脑区、设计工位、办公/接待 |
| **B 带：中等干燥带** | 轻度粉尘与噪音 | 小型木工（台锯、曲线锯）、金工台、手工制作 |
| **C 带：大声多尘湿带** | 高噪音、粉尘/湿气 | CNC 铣床、木工 Router、激光切割（另需独立排风）、涂装/危化品（须独立房间）|

> 分区目的：让「安静创作的人」和「大力出奇迹的人」互不干扰，也让粉尘不跨区污染精密设备（3D 打印与电子件最怕粉尘）。配套分区维度见 [创客空间规划与设计.md](创客空间规划与设计.md) 第五节（安静区/噪音区/潮湿区/数字区）。

### 1.2 OMT4Make 十工位区（功能完整模板）

开源电子书《Layout and Equipping》给出的完整空间拆解，可作为分区清单核对表：

| 区 | 建议工位/规模 |
|----|--------------|
| 接待区 | 1 前台 + 展示墙 |
| 共创/培训区 | 按班级规模（如 16 张 1.2×1.2m 创客桌）|
| 电子/机器人区 | **3–5 个电子工位**（每个配焊台 + 万用表 + 静电垫）|
| 数字制造区 | **按机器数配置**，激光/3D 打印/CNC 各留独立位 |
| 木工区 | 2–4 台主力机位 + 手动工具墙 |
| 金工区 | 2–3 机位（台钻、砂轮机）|
| 纺织区 | **2–4 个缝纫位** |
| 存储区 | 材料 + 半成品 + 耗材（面积宁可高估，见反模式）|
| 安全区 | PPE 墙 + 灭火器 + 急救箱 |
| 休息区 | 咖啡角/沙发（社区形成的刚需）|

### 1.3 布局四步法（Milwaukee Makerspace）

```
① 列需求（先不管位置）→ 把每个功能区需要的设备、电源、水、通风全写出来
② 画关联图 → 共享资源的功能区相邻（如：激光区⇄材料库、电子区⇄电脑区、CNC⇄木工区）
③ 分组排列 → 形成「簇」，簇间留通道
④ 映射到建筑 → 考虑门窗、承重柱、排水、已有电源点
```

### 1.4 网格纸手绘验证法（The Makerspace Workbench）

正式 CAD 之前先做物理推演：

1. 用 1ft×1ft（约 30cm）网格纸画出建筑轮廓
2. 标注**不可移动约束**：门窗、插座、承重柱、地漏、照明位置
3. 按设备实际占地剪纸片（1:1 比例），在网格纸上摆放验证
4. 检查三项：通道宽度、开门半径、上料/装卸空间
5. 用 CAD 图块（如 CADBlockDWG 提供的 DWG 图块）做**货车上料验证**——设备能否进门、过走廊、转弯

## 二、关键尺寸标准（通用）

| 部位 | 尺寸要求 | 来源 |
|------|---------|------|
| 工作台深度 | **750–900mm**（标准操作面）| #8 |
| 主通道宽度 | ≥1.2m（双人错肩）；设备后方检修通道 ≥600mm | 通用 + #8 |
| 台锯后方安全退让 | **1.2–1.5m**（长料加工退让区）| #8 |
| 激光 / 3D 打印离墙 | **150–300mm** + 检修空间（排风管、维护位）| #8 |
| CNC 上料区 | 机身外**额外 1.2–1.5m**（板材装卸区）| #8 |
| 涂装 / 危化品 | **独立房间 + 独立排风**（不可与开放区混放）| #8 |
| 防火分区 | 明火/高温作业与存储区隔离；危化品柜独立 | 安全与规范管理 |
| 教育场景面积基准 | 1200–2400 人校 ≥240㎡；>2400 人校 ≥360㎡；生均 ≥0.15㎡ | 教育指南 #5 |
| 功能区面积占比 | 教学区 40–50% / 加工区 20–25% / 创作仓储 15–20% / 展示 10–15% | 教育指南 #5 |

> ⚠️ 全部尺寸为**最小值**。实际落地时以设备厂商安装手册的「净空要求」为准，两者取大值。

## 三、单类设备摆放规范

### 3.1 激光切割机（重点专项）

**占地公式**（JK Lasers）：总占地 = 机身 + 前方 1m 开盖区 + 操作位 600–900mm + 材料暂存区 + 排风系统 + 电脑操作台。

| 床面尺寸 | 最小占地（整机+操作+材料）|
|----------|--------------------------|
| 60×40cm | **≥5㎡** |
| 90×60cm | **≥7–8㎡** |
| 1.5×3m（工业级）| 需独立房间（参考科普场馆手造区方案）|

**场地工程条件**：

| 项目 | 要求 | 来源 |
|------|------|------|
| 位置 | **靠外墙**优先（排风管道短、负压好维持）| #16 |
| 排风管 | 6"（约 152mm）**刚性金属管**；排风机近室外端安装保持**负压**；刚性优于柔性 | #16 / #14 |
| 弯头损失 | 每 90° 弯头显著降效——管道尽量直出；长度越短越好 | #14 |
| 换气次数 | 激光区整体换气 **≥6 次/小时**；排风首选室外直排 | #13 |
| 风量 | 400×300mm 床 → 200–300 CFM；1200×900mm 床 → 600–800 CFM；1.5×3m 床 → 2000–6000 m³/h | #14 / #15 |
| 电源 | 40–60W CO₂ → 标准 13A/220V 插座即可；**130W+ 需 20A 或三相**；总容量留 20% 裕量 | #14 / #15 |
| 冷却 | 带冷机（水冷）时核对**冷机容量**；预留冷机位 | #15 |
| 楼板承重 | 工业级大床需核对楼板承重（设备+材料+人）| #15 |
| 防火 | 激光区**防火垃圾桶**（符合 FM 6921 / UL 1315 / UL 242）；燃烧报警；加工材料须经制造商批准 | #13 |
| 烟感/灭火 | 激光区必配烟雾报警 + CO₂/干粉灭火器（见安全与规范管理）| — |

**开盖/操作面方向**：前方预留 ≥1m 开盖距离 + 600–900mm 操作位，操作位旁放电脑台；排风口在设备背面/侧面，避开人流方向。

### 3.2 3D 打印机

| 项目 | 要求 | 来源 |
|------|------|------|
| 离墙 | 150–300mm + 检修空间（换料、维护）| #8 |
| 环境 | 避免阳光直射与气流直吹（影响打印质量）；FDM 与树脂机分开放置 |
| 树脂机 | 需独立通风（树脂气味 + VOC）；放 A 带边缘，配小排风扇 |
| 电源 | 独立插座，勿与大功率设备共回路（加热床启动电流大）|

### 3.3 CNC / 木工 Router

| 项目 | 要求 | 来源 |
|------|------|------|
| 上料区 | 机身外额外 **1.2–1.5m** 板材装卸区 | #8 |
| 安全 | 机器人/数控设备参考 **RIA/ANSI R15 系列**安全标准；维护时 **LOTO 上锁挂牌** | #13 |
| 防尘 | 工业吸尘（木工区 Festool CTL 级）；CNC 配防尘罩/围挡 | 安全与规范管理 |
| 金属 CNC | 切削液需防漏盘 + 地面防滑处理 | #13（金工通用）|
| 基础 | 楼板承重核对；地脚螺栓固定大机 |

### 3.4 木工 / 金工区

- 台锯后方 1.2–1.5m 退让区**禁放任何东西**（长料加工甩尾空间）
- 金工台（台钻、砂轮机）下方放**防滑地垫**（油污地面防滑）| #13
- 木工区配工业吸尘 + 防爆灯；锯屑桶与机器联动
- 手动工具集中在工具墙（见 [工具组织与现场管理](../03-设备与工具/工具组织与现场管理.md)）

### 3.5 电子工作台

- 3–5 个工位成排布置，每个工位：焊台 + 万用表 + 防静电垫 + 台灯 + 独立电源
- 靠近电脑区（设计→打样闭环），远离木工/CNC 粉尘带
- 锂电池充电集中到**防爆充电箱**（创客空间强制标准件，见安全与规范管理）

### 3.6 陶艺 / 纺织等专业区

- 陶艺：陶瓷 3D 打印机 + 电窑，**地面防水处理** + 过滤池（科普场馆方案标配）
- 纺织：缝纫机 2–4 台成排，配熨烫台；布料存储防潮防尘

## 四、工程条件总表（装修阶段预埋，不可后补）

| 系统 | 要求 | 备注 |
|------|------|------|
| **通风排风** | 激光/焊接/喷涂/树脂区机械通风；激光区换气 ≥6 次/h；室外直排优先 | **装修阶段预埋排风管道**（反模式：排气后装 → 激光机无法使用）|
| **电源** | 设备分区独立回路 + 急停；大功率设备单独供电；下垂式电源（教学区）；接地 <4Ω | 电源容量留 20% 裕量 |
| **给排水** | 陶艺/水槽区防水地面 + 过滤池；整备间保留水槽 | — |
| **消防** | 激光区防火垃圾桶（FM 6921/UL 1315/UL 242）；烟雾报警；干粉/CO₂ 分区配置 | — |
| **承重** | 工业激光/大 CNC 核对楼板承重 | — |
| **照明** | 加工区高照度 + 防爆（木工粉尘区）| — |

## 五、落地工作流（从需求到验收）

```
需求清单（所有设备/功能）
   ↓
三带分区（A/B/C 带归类）
   ↓
十区核对表 + 关联图（四步法）
   ↓
网格纸/纸片验证 + CAD 图块货车上料验证
   ↓
单类设备专项核对（激光 3.1 / 3D 3.2 / CNC 3.3 / 木工金工 3.4 / 电子 3.5 / 专业区 3.6）
   ↓
工程条件核对（第四节总表）→ 装修预埋
   ↓
设备进场验收：安装检查清单（电源/排风/负压/承重/联锁）→ 试运行 → SOP 上墙
```

**设备进场前验收清单**（采购前即做场地核对，Laser Spechub "PO Gate" 思路）：

- [ ] 电源容量核对（+20% 裕量）
- [ ] 排风管径/走向/负压方案
- [ ] 冷机容量（水冷设备）
- [ ] 楼板承重确认
- [ ] 联锁/急停/安全标识到位
- [ ] 护目镜等 PPE 到位
- [ ] 上料/装卸动线验证（货车上料）
