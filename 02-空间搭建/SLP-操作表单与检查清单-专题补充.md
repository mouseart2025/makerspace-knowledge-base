# SLP 操作表单与检查清单（专题补充）

> 书目：Richard Muther & Lee Hales, **《Systematic Layout Planning》**, 4th Edition, 2015（本地 PDF，416 页）
> 定位：**[SLP系统布置设计-专题补充.md](SLP系统布置设计-专题补充.md) 的配套实操篇**——前者讲"为什么"，本篇给"**照着填的表格与照着勾的清单**"。
> 用法：直接复制下方表格到项目工作表；清单按阶段逐条勾选。所有条目均可溯源到原书页码（格式「书页 章-页」）。
> ⚠️ 数值口径提示：书中示例为美制（英寸/英尺），本表已换算标注；**落地须以国标与项目实测为准**。

## 二、关系图（气泡图）绘制检查清单

**绘制顺序**（书 p6-8～6-11）

- [ ] 第 1 步：画全部 **A** 关系（4 线 / 红）
- [ ] 第 2 步：重排 → 加 **E**（3 线 / 橙黄），间距约为 A 的 **1.5–2 倍**
- [ ] 第 3 步：重排 → 加 **I**（2 线 / 绿），间距约为 A 的 **2–3 倍**
- [ ] 第 4 步：重排 → 加 **O**（1 线 / 蓝），间距 **≥4 倍**
- [ ] 第 5 步：加 **X / XX**（波浪线）。**XX 约等于 −3，与 E 等强，故应与 I 同时加入**
- [ ] 迭代轮次已记录（正常需 **3–8 轮**，少于 3 轮要怀疑是否草率）

**分离度自检**（书 Figure 6-7）

| 评级 | 实践间距（相对 A 的倍数） | 本项目自检 |
|------|------------------------|-----------|
| A | 1（最短） | |
| E | 1.5 – 2 | |
| I | 2 – 3 | |
| O | ≥4 | |
| X / XX | 若表示"需距离"则更长 | |

**★ X 的语义分诊**（书 p6-11）——**这一条最容易被做错**

- [ ] 逐条确认每个 X 属于哪一类：
  - **需距离型**（噪声、振动、危险）→ 画**长波浪线**，在图上体现距离
  - **需围合型**（洁净、通风、私密、安保、隔声）→ **不画距离**，改记为该区域的**物理特征/性能要求**（墙、门、局部排风、隔声 dB）
- [ ] 没有把"需围合型"错误地画成距离

**图面规范**（书 p6-6、p6-11）

- [ ] 符号类型与活动类型对应（圆＝作业/办公或实验；转向箭头＝建筑特征或办公区；旋转 D＝服务与辅助区）
- [ ] 编号写在符号内
- [ ] 颜色只用 5–7 种且承载含义
- [ ] 电子绘制时关闭吸附，符号填白并置于顶层
- [ ] 完成判据：**每一格都画进了图**，且 4 线短、波浪线长、中间级长度合理

## 三、空间测定方法选择决策树（书 p7-3）

```
问 1：能列出设备清单与台数吗？
  ├─ 能 → 用【计算法】（最精确、最常用）
  │        并另用一种方法交叉校核（不同方法互相验证，结论更可信）
  └─ 不能/太粗 → 问 2

问 2：是否需要赶时间，或只做总量估算，或工作内容太杂（维保、收发）？
  ├─ 是 → 用【换算法】：现状面积 → "本应面积" → 按区增减 → 需要面积 → 对比可用 → 计划面积
  └─ 否 → 问 3

问 3：自己是否已有可复用的空间标准？
  ├─ 有 → 用【空间标准】，并定期复核标准的前提是否仍成立
  │        ⚠️ 别人的标准只能当参考（车型、法规、气候都会让标准失效）
  └─ 无 → 问 4

问 4：是否存在高投资、关键、或必须成线的区域？
  ├─ 是 → 用【粗排布局】：比例图 + 模板，允许"钻下去"做局部详细
  └─ 否 → 用【比率趋势与外推】（最不准，仅适合总量与长周期）
```

**★ 无论选哪种，都要做**

- [ ] 同时问：所需空间 **vs** 可用空间，并把**差额**显式写出
- [ ] 用两种方法交叉校核（书 p7-3：不同方法互为检验）
- [ ] 记录**活动区与特征汇总**：面积（数量）+ 物理特征（种类）+ **形状/构型**
- [ ] 若空间缩减依赖管理方式改变 → **先确信能落地再写进需求**（书 p7-3）

区域估算面积 = Σ(各设备最小面积 × 台数) × 集中-分散因子

该系数覆盖：存放料区、取用通道、区内服务面积、作业净空共享

|----|--------------|--------|------------|---------|------|
| | | | | | |

**★ 通道记账纪律**（书 p7-2）——**先声明口径，再全程一致**

- [ ] 已声明采用哪种口径：
  - **① 净面积法**：干道单独测量、单独记账；各区量到自身边界
  - **② 中线法**：干道分给所服务的区；各区量到通道中心线

## 五、方案评估表（加权因子法，书 p10-6）

### 5.1 字母→数值映射（**必须先用字母评分，再转数字**）

| 码 | 描述 | 值 | 级差 |
|----|------|----|------|
| A | 几乎完美（优） | 4 | — |
| E | 特别好（很好） | 3 | 25% |
| I | 得到重要结果（好） | 2 | 25% |
| O | 提供一般结果（中） | 1 | 25% |
| U | 不重要（差） | 0 | 25% |
| X | 不可接受 | 否决 | — |
| 带减号半级（A–/E–/I–/O–） | 低半度 | −0.5 | 12.5% |

> ★ **为什么用字母而不是直接打数字**（书 p10-6）：
> ① 数字带"隐含精度"的误导；② **太容易在评分还没做完时就把数字加起来、提前看出高下**。用字母能防止这种自我污染。

### 5.2 评估表（示例因子，按项目替换）

| 因子 | 权重 | 方案 A | 方案 B | 方案 C |
|------|------|--------|--------|--------|
| 物流/人流效率 | | 　/　 | 　/　 | 　/　 |
| 空间利用率 | | 　/　 | 　/　 | 　/　 |
| 通行与安全 | | 　/　 | 　/　 | 　/　 |
| 教学组织适配（班次并发、时分复用） | | 　/　 | 　/　 | 　/　 |
| 弹性与可重排（四态切换成本） | | 　/　 | 　/　 | 　/　 |
| 实施成本与工期 | | 　/　 | 　/　 | 　/　 |
| 规范合规（消防/无障碍） | | 　/　 | 　/　 | 　/　 |
| 使用者接受度 | | 　/　 | 　/　 | 　/　 |
| **加权合计** | 100% | | | |
| **含 X 否决？** | — | | | |

**评分规则**

1. 优点用正字母，**缺点用负字母**（如 E– → −2.5）
2. **任一因子为 X → 该方案标记"不可接受"，不参与加权比较**
3. 权重之和 = 100%
4. 先淘汰含 X 者，再比加权总分
5. 若两方案总分差距**在 12%–15% 以内，应视为并列**，需补充依据再判（本书把该阈值用于选址方案比较，可类推用于布局）

## 七、机器设计 17 条原则（书 Figure 12-2）

**用途**：不自己造机器，而是**影响采购与台架设计要求**。用于向供应商/甲方提出"性能要求"。

**缩宽度（直接影响设备密度）**
- [ ] 1 最小化机器宽度，尤其**操作者位置的工作区宽度**（书目标 **24 in ≈ 600 mm**，或工件长度，取大者）
- [ ] 2 采用**垂直（上翻）开门**而非侧向开门
- [ ] 3 最小化控制柜与面板尺寸
- [ ] 4 显示器置于上方并贴近机身

**减干扰**
- [ ] 5 采用低成本、行业标准化的控制元件（电气/电子/气动/液压）
- [ ] 6 消除多余的凸出物、检修口、门扇摆动
- [ ] 7 **消除伸入操作者步行路径的任何结构**

**省动作**
- [ ] 8 手动上料 + 自动弹出回操作者（配合"机器节拍 < 人节拍"可消除等待）
- [ ] 9 最小化上料时的伸手距离
- [ ] 10 一指/一触启动

**保安全**
- [ ] 11 简单防护，确保循环启动前操作者已离开危险区
- [ ] 12 静音设计或隔声罩

**利换型**
- [ ] 13 适配快换工装与可互换夹具
- [ ] 14 换型时间以秒/分钟计
- [ ] 15 内置循环计数，到时提醒并停机换刀
- [ ] 16 内置检具与检测装置

**★ 利重排（对会反复调整的空间最关键）**
- [ ] 17 预计会重排时，选用**便携、易于移动**的设备，并具备：
- [ ] a 整体式机架
- [ ] b 简易调平系统
- [ ] c **所有关断点集中布置**
- [ ] d 柔性公用管线接口 + **快换接头**
- [ ] e 冷却液、切屑等采用**地面自包含系统**
- [ ] f **避免基础，改用重型地板垫板**

## 八、Phase III 详细布局前的准备清单（书 p11-1～11-2）

- [ ] 已给**每一个区域**评定「规划力度」A/E/I/O/U（**U 的区域明示不排规划时间**，保持原样或交由使用方决定）
- [ ] 已按区域制定**排期**，并协调相邻区域的时序（它们的相互影响需一并解决）
- [ ] 已确认可用空间、柱距/柱网、楼板荷载、跨区搬运系统、排班政策**均已锁定**
- [ ] 已明确**参与人层级**：总体布局由部门负责人级参与；详细布局由**主管、作业者、服务组长**参与
- [ ] ★ 未遗漏"**实际参与其中且切身相关的人**"（书 p11-1 明确：遗漏会导致不可用的布局）
- [ ] 区域内已重新做**活动拆分**（Phase III 的"活动"＝机器/设备/工位或其组合）
- [ ] 如涉及多工位协作，已做**线平衡**分析并与布局迭代（走行时间取决于布局）

**★ 何时值得为单个工位做正式规划（书 p12-1，7 条触发）**

任一项成立即值得：

- [ ] 该工位会被**大量复制**，其累计影响显著
- [ ] 工位**新且不熟悉**，安装后**难以修改且代价高**
- [ ] 涉及**定制设备**（由外部供应商/集成商按工艺制造）
- [ ] **空间昂贵或有限**，需要挤出浪费
- [ ] 现有工位**不标准**，影响生产率、节拍、监督或绩效评价
- [ ] 现有工位是**危害或伤害的来源**
- [ ] **操作者抵制**该区域布局（看不到工位、或认为需求未被考虑）

> ★ 成本提示（书 p12-1）：**规划工时 ≈ 需要放置的对象数量**。所以规划单个工位的耗时，可能与规划整个空间相当——**必须先用上表筛一遍再投入**。

## 九、方案呈现自查清单（书 p10-1～10-3）
