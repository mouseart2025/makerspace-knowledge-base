## 〇、先读这条：SHA 补的是 SLP 的两个空白

SLP 的关系表要求：**关系的评级（A/E/I/O/U/X）要按"理由码"判定**，其中**理由码 1 = 物料搬运量与体量**。

但 SLP **只给了理由码，没给算法**：
- 搬运"量与体量"量到什么程度算 **A**、什么程度算 **E**？——不明
- 一条"长距离但低强度"的搬运，算不算布局缺陷？——不明

**SHA 把这两处补上了**：

| SLP 的空白 | SHA 的补位 | 出处 |
|---|---|---|
| 强度到什么程度算 A/E/I/O/U | **强度校准表**：算数值 → 排序 → 切等级 | FIG. 3-13（本文 §七） |
| 长距离算不算问题 | **距离-强度二维判据**：只有「**长距离 × 高强度**」才是布局问题 | FIG. 5-2（本文 §五） |
| 搬运量怎么算 | **I = n/t；TW = I × D** | RMA-1253-K（本文 §三） |
| 物料搬起来多费劲 | **Mag Count** 标量 | 附录 I（本文 §十） |

## 一、结构同构：三大基础一一对应

SHA 全貌图（**RMA-1253-K「SHA Capsule Summary」**，版式与 SLP 的 RMA-1154K 完全相同）给出：

```
MATERIALS HANDLING ANALYSIS  =  1. MATERIALS  →  2. MOVES  →  3. METHODS
```

**与 SLP 的三基础逐一对应：**

| SLP | SHA | 关注对象 |
|---|---|---|
| 1. **RELATIONSHIPS** 关系 | 1. **MATERIALS** 物料 | 先搞清楚"是谁" |
| 2. **SPACE** 空间 | 2. **MOVES** 移动 | 再搞清楚"去哪、多远、多频繁" |
| 3. **ADJUSTMENT** 调整 | 3. **METHODS** 方法 | 最后决定"用什么手段实现" |

**阶段也是四阶段**（与 SLP 同名同序）：

| 阶段 | SHA 名称 |
|---|---|
| **I** | **EXTERNAL INTEGRATION** 外部衔接（进厂/出厂物料的衔接） |
| **II** | **OVERALL HANDLING PLAN** 总体搬运方案 |
| **III** | **DETAILED HANDLING PLANS** 详细搬运方案 |
| **IV** | **INSTALLATION** 安装 |

同样有一条贯穿始终的 **Application**（应用）—— 与 SLP 一样，**不是第 5 个阶段**。

## 三、★★★ 三个公式：把"搬运"变成可算的量

SHA 全貌图右侧的 **Formulas and Explanations** 给出三个核心量：

```
Intensity  (I)  = n / t            按"流量线的宽度"设计
Distance   (D)                     按"流量线的长度"设计
Transport Work (TW) = I × D        按"流量线所围的面积"设计
```

★★★ **这是一个极优雅的可视化规则**：

| 图形属性 | 承载的量 |
|---|---|
| **线的宽度** | **强度 I**（单位时间移动量） |
| **线的长度** | **距离 D** |
| **线所围的面积** | **运输功 TW = I × D** |

→ **一眼就能看出运输功堆在哪里**（又宽又长的线 = 大运输功 = 改进的重点）。
→ 这也解释了 SLP 关系图里"线数 = 等级"的**量化来源**：线数就是强度的分档。

★ 与 SLP 的关系表对接：**两书共用同一套字母码与颜色（A/E/I/O/U/X、4/3/2/1/0、红橙绿蓝）**，
**因此 SHA 算出的强度等级可以直接填进 SLP 关系表的上半格。**

## 四、★★★ 三种搬运系统与选型判据（FIG. 5-1）

SHA 把搬运系统分为 **Direct 直接** 与 **Indirect 间接**，后者再分两支，共三种：

| 系统 | 定义 | **原文选型判据** |
|---|---|---|
| **D — DIRECT** | 物料从起点到终点走**最短可行路径** | **流量强度高 ＋ 距离短或中等**时最经济；**尤其当物料本身有特殊性、且时间紧迫时** |
| **K — KANAL (CHANNEL) 通道** | 物料沿**预定路线**移动，并**与其他物料的移动合流** | **流量强度中等或低 ＋ 距离中等或长**时经济；**尤其当布局不规则或分散时** |
| **C — CENTRAL 集中** | 物料沿预定路线先到**集中分拣/调度区**，再送达目的地 | **流量强度低 ＋ 距离中等或长**时常常经济；**尤其当区域基本为方形且管控重要时** |

★ 用词说明：**Kanal**（而非 Channel）是原文用词（德/北欧语源的"渠道"），SLP 书中同样如此。

## 五、★★★★★ 距离-强度图：一个"布局好不好"的判据（FIG. 5-2）

**X 轴 = Distance（短 → 长）；Y 轴 = Intensity of Flow（低 → 高）；每个点 = 一条路线。**

图上被划成**三个区域**：

```
Intensity                       ┌──────────────┐
  High          ┌────────────┐  │  ★ POOR      │
                │  DIRECT    │  │     LAYOUT   │
                │  SYSTEM    │  │              │
  Low           └────────────┘  │  INDIRECT    │
                                │  SYSTEM      │
                                │ (Kanal or    │
                                │  Central)    │
                                └──────────────┘
                 Short ────────── Distance ────────── Long
```

**原文判读规则（逐字）**：

> - **Direct system for short distance, high intensity**
> - **Indirect system for long distance, low intensity**
> - **"Moves with long distance and high intensity indicate that the layout is poor from a materials handling viewpoint. If there are many plotted points in this area, the major problem may well be to improve the layout rather than the handling."**
> - ★ **例外**："where an operation is tied-in with the move, as when access of air to the material (cooling of castings) is required and the cooling operation is combined with the move, **a long distance for a high intensity may very well be justified**."（当作业与移动本身绑定时 —— 如铸件需在移动中冷却 —— **高强度 + 长距离是正当的**）

★★★ **判读必须是二维的**：

| | 短距离 | 长距离 |
|---|---|---|
| **高强度（A/E）** | ✅ **Direct System，正确** | ★ **Poor Layout —— 问题在这里** |
| **低强度（O/U）** | 无妨 | ✅ **Indirect System，正常，不必改** |

★★ **这一条与 SLP 的「关系叠加诊断法」是同一条思想的两层**：

| 来源 | 内容 | 作用 |
|---|---|---|
| **SLP FIG. 8-4** | 只画 A、E 关系线到布局上，看**长线** | 给出**画法**（一维：线长） |
| **SHA FIG. 5-2** | 长距离 **×** 高强度 = Poor Layout | 给出**判据**（二维：距离 × 强度） |

→ 合读即得完整规则：**"画 A/E 短名单 → 看长线 → 但只有长线 × 高强度才是布局问题；长线 × 低强度属正常，该走间接系统。"**

## 六、★★★ 设备四象限（FIG. 5-5）

**按成本数据分，搬运设备有四类，各自在距离-强度图上占一个象限：**

| 象限 | 类别 | 原文给出的卡车类典型例 |
|---|---|---|
| 短距离 + 低强度 | **Simple Handling Equipment** | 两轮手推车 |
| 短距离 + 高强度 | **Complex Handling Equipment** | 窄通道叉车 ＋ 抓具 |
| 长距离 + 低强度 | **Simple Travel Equipment** | 电动平台车 |
| 长距离 + 高强度 | **Complex Travel Equipment** | 电子控制无人驾驶拖车-挂车 |

★★ **用法**：**搬运设备选型可以按"距离 × 频率"四象限定档**，而不是凭习惯采购。
（★ 1969 年的设备举例是重工业语境，当代对应物应替换 —— 见 §十六 局限。）

## 七、★★★ 强度校准：把"吨/天"切成 A/E/I/O/U（FIG. 3-13）

SHA 的 **CALIBRATION OF INTENSITIES — NUMBERS TO RATING** 表单给出做法：

1. 列出**每条路线**（物料类 ＋ 起讫点）的强度值（如**吨/天**）；
2. **按数值从大到小排序**；
3. 在刻度尺上**划出等级分界**，逐组标注 **A（红）／A−（红）／E（橙黄）／I（绿）／O（蓝）**。

★ 该案例（Nordic Mixtures Ltd）的实际切分大致为：
**≥50 → A；25–50 → A−；10–25 → E；5–10 → I；＜5 → O**。

★★ **这不是通用阈值** —— 图上的分界线是**打在该项目自身的强度分布上**的，不是绝对刻度。这与 SLP 的精神一致：**阈值随项目而定**。
（参见 SLP Capsule Summary 脚注：**点划线表示"半个线数"，可用元音字母后加减号记录**。）

★★★ **这条补上了 SLP 的一个空白**：SLP 说关系强度按"物料搬运量与体量"判 A 还是 E，但**没说量到什么程度算 A**；SHA 给了这张校准表。

## 八、★★ 影响搬运成本的五要素（P-Q-R-S-T 的搬运版）

| 要素 | 原文要点 |
|---|---|
| **P PRODUCT** | 物料的**可搬运性**（transportability）取决于**物品与容器**的特性；且每个场所里有些物品**更习惯被搬运**（Special / Normal / Uniform Items） |
| **Q QUANTITY** | 数量有**两个不同含义**：① **单位时间的数量 = 流量强度**；② **每次的数量 = 载货量（payload）**。**数量越大，单位搬运成本越低** |
| **R ROUTING** | 每次移动含**固定的终端成本** ＋ **可变的旅行成本**；要留意路线的物理状况与**成本台阶**（室内/室外切换、方向改变） |
| **S SERVICES** | 调度程序、维保人员、订单处理文书等 —— 搬运系统要依赖的服务 |
| **T TIME** | 时序、紧迫性、规律性 |

★★ **R 的"终端成本 + 旅行成本"结构**值得单独记住：

```
单次搬运成本 = 终端成本（固定） + 距离 × 单位旅行成本
```

→ **高频小件的终端成本占比高 → 应当就近**；**低频大件的旅行成本占比高 → 可以走集中系统**。
**这为"哪些物该在近处、哪些物可以放远"提供了一条可算的判据。**

## 九、★★ 物料分类：五个维度（p24）

| 维度 | 内容 |
|---|---|
| **Physical Characteristics** | 物理特性（**原文：通常是最重要的分类依据**） |
| **Risk of damage** | 易碎、易爆、易污染、有毒、腐蚀性… |
| **Condition** | 不稳、发粘、热、湿、脏、成对… |
| **Quantity** | 相对受欢迎程度或体量（总量 ＋ 批次/批量） |
| **Timing** | 规律性、紧迫性、季节性 |
| **Special control** | 政府法规、厂内标准、运营政策 |

★ 三条要点：
1. **物理特性通常决定归入哪一类**；
2. **同一种物品，大量与小量会以不同方式搬运**（fast movers 高量快流 vs 特别订货）；
3. **紧急移动成本更高，且要求的搬运方法与不急的完全不同**；**季节性变化也会影响类别**。

## 十、★★ Mag Count：一个"可搬运性"的单一数值（附录 I）

**Mag Count 给物料一个"搬起来有多费劲"的标量**：

```
Mag Count = 尺寸基准值（查图，按立方英寸对数刻度）
          × [ 1 + 1/4 × (B + C + D + E + F) ]
  其中 B/C/D/E/F 为各维度的"度数"（degrees）
  ★ 每一个 degree 相当于基准值的 ±25%
```

五个修正维度（附录 I 图 3）：

| 维度 | 含义 | 示例锚点 |
|---|---|---|
| **B** | 体积 / 密度 | −2 Very light and empty（大而空的钣金件）／−1 Light and bulky（拆平的瓦楞纸箱）／0 Reasonably solid（干木块）／+1 Fairly heavy and dense |
| **C** | **形状** | **−3 极平可堆叠 / 可完全套叠**（纸、金属薄板）／−2 易堆叠或可套叠（纸垫、汤碗）／−1 尚可堆叠或略可套叠（书、茶杯）／0 大致方正、有一定堆叠性（木块）／+1 细长、圆或略不规则 |
| **D** | 损坏风险 | −2 完全不惧损坏（废铁）／−1 几乎不惧损坏（紧凑铸件）／0 略怕损坏（按尺寸切好的木料）／+1 易压坏、折断、刮伤 |
| **E** | 状态 | 0 洁净、坚实、稳定（木块）／+1 油污、易变形、不稳或不好下手 |

★★ **用法**：把各类物料**算 Mag 值排序**，即得到一个**客观的"搬运难度序"**，用于决定
**哪些物必须就近、哪些可以放远、哪些必须配专用容器**。

## 十一、★★★ 搬运 11 条原则（附录 III）

| # | 原则 | 一句话 |
|---|---|---|
| 1 | **Planning** | 规划**全部**搬运与储存活动，以获得**最大的整体运营效果** |
| 2 | **Standardization** | 标准化搬运方法，以及搬运设备的**类型与尺寸** |
| 3 | **Adaptibility** | **专用设备不合理的地方，使用方法与设备能最好地完成多种任务** |
| 4 | **Dead Weight** | 降低移动式搬运设备**自重与载荷之比** |
| 5 | **Utilization** | 规划搬运设备与人的**最优利用** |
| 6 | **Maintenance** | 规划**预防性维护与计划修理** |
| 7 | **Obsolescence** | 有更高效的方法/设备时，**替换过时的** |
| 8 | **Control** | **用搬运活动改善生产、库存、订单处理的控制** |
| 9 | **Capacity** | 用搬运设备帮助达成期望**产能** |
| 10 | **Performance** | 以**每单位搬运量的费用**衡量搬运绩效 |
| 11 | **Safety** | 提供**安全的搬运方法与设备** |

★★ **第 3 条（Adaptibility 适应性原则）**是本组里对本项目最有用的一条：
**"在专用设备不合理的地方，用能完成多种任务的通用设备"** ——
这与 SLP 机器设计 17 条里的"**利重排（预计会重排时选用便携易移动设备）**"互为印证，共同支撑**把"可移动性"写成采购要求**。

## 十二、★★ 布局 / 搬运 / 管控 三者互联（FIG. 7-1、FIG. 7-2）

**原文比喻：工业物料搬运就像公共交通。**
图上有三块：**LAYOUT（含通道 Aisle、调度板 Dispatch Board）／HANDLING／CONTROLS（控制塔面板）** —— 三者相互依赖。

**HOW PLANNING AND SCHEDULING CAN MODIFY THE MOVES** 给出三档组织方式：

| 档 | 含义 |
|---|---|
| **PLANNING BY THE HANDLER (DOER) HIMSELF** | 由搬运者自己计划（生产人员搬自己的物料） |
| **COORDINATED PLANNING** | 协调计划 |
| **PRE-PLANNING WITH MINIMUM OF DAY-TO-DAY PLANNING** | 预计划 ＋ 最少的日常计划（固定排程） |

★★ **直接启示**：**"谁、什么时候、把什么搬到哪"是可以被制度化的** ——
**搬运需求不只靠改空间解决，也可以靠改排课 / 预约 / 借用制度解决**。
这与"四态复用 + 分时复用"的思路同源，但 SHA 给了它一个明确的位置：**它属于 CONTROLS，与 LAYOUT 并列。**

| **ROUTE CHART** | **逐条路线**一行：物料类 / 路线情形 / 距离 / 移动代码 / 流量强度 / 条件 | 第 3 章 |
| **FLOW-IN — FLOW-OUT CHART** | **逐个区域**：进该区的全部移动 ＋ 出该区的全部移动 | 第 3 章 |
| **MOVEMENT SUMMARY** | **全部路线的全部物料汇总到一张表** | 第 3 章 |
| **FROM-TO CHART（从至表）** | 行 = 起点（FROM），列 = 终点（TO），格 = 移动量 | 第 10 章 |

★ **从至表（From-To Chart）的填表纪律（原文"How to use"）**：
1. 填写标识该表的信息；
2. **可做一张含全部移动物的总表，也可按物料类别各做一张** —— 并注明所图为何物；
3. **记录数值所用单位**；
4. **列出全部起点**（每行一个活动/工序区）；
5. **列出全部终点**（用**同样的编号**标识同样的活动/工序区）。

### 13.2 ★★ P-Q 分布决定用哪种分析（FIG. 3-1）

| P-Q 分布 | 分析方法 | 适用表单 |
|---|---|---|
| **少数品种、高数量** | **PROCESS ANALYSIS**（过程分析）—— **每个产品做一份分析** | Process Chart ／ Route Chart |
| **多个品种、低数量** | **ORIGIN-DESTINATION ANALYSES**（起讫点分析）—— **每条路线或每个区域一份分析** | Route Chart ／ Flow-In-Out Chart ／ Movement Summary |

★★ **这条规则的使用价值**：**先判自己属于哪一栏，再选表单** ——
给"多品种低量"的场景硬套"过程分析"（逐产品画过程图），是最常见的浪费。

## 十四、★ 本项目接口：四类物与三条待建规则

本项目的主流量是**人**（学生 / 教师 / 访客），物料量远小于典型制造业 —— 因此 SHA **不铺开到全空间**，只用于四类**真实的物**：

| # | 物料类 | 物理特性（§九） | 时序（§九） | 搬运难度倾向（§十） | 系统倾向（§四） |
|---|---|---|---|---|---|
| **1** | **板材与型材** | 长件、重件 | 规律 | **C 形状极佳（−3，可堆叠）**，但重量推高 B | 直接（区内）＋ 通道（跨区） |
| **2** | **耗材**（丝材、激光耗材、电子元件） | 高频小件 | 持续 | 小、轻 → Mag 低 | **直接**（就近，终端成本占比高） |
| **3** | **竞赛器材与大件设备** | 大件、低频 | **季节性 + 紧急** | 大件、怕损坏 → Mag 高 | **集中**（低频长距，需暂存与管控） |
| **4** | **废弃物与切屑** | 松散、脏、有污染风险 | 与加工同步 | Condition +1（脏/不稳） | **通道**（沿主通道定点收集） |

★★ **由此得到三条待建规则**（对应本文 §四 的三种系统）：

| 规则 | 系统 | 依据 |
|---|---|---|
| **R1 高频小件就近** | 直接系统 | §八 的"终端成本占比高 → 就近"；§七 校准表里这类物料强度最高 |
| **R2 大件低频走集中** | 集中系统 | §四 的"低强度 + 中长距离"判据 |
| **R3 废弃物定点收集** | 通道系统 | §四 的"沿预定路线合流"；且 Condition +1 不宜穿过密集工位 |

★ 已知的结构性事实（本项目）：**全区只有一条纵贯公共通道** ——
这直接导致**跨区搬运被迫走"通道/集中系统"，且绕行系数偏高**。
**SHA 的从至表（§13.1）能把这件事从"感觉远"变成"流量 × 距离"可算。**

## 十六、局限与边界

1. **1969 年版，举例与量纲带时代烙印。**
   - **方法保留**：物料分类维度、强度校准、距离-强度判据、三种搬运系统、11 条原则、Mag Count —— 这些是结构性的。
   - **举例须替换**：设备举例（两轮手推车 / 窄通道叉车 / 无人驾驶拖车 / 桥式起重机 / 铁路车辆）与量纲（**吨/天**）是重工业语境。**当代场景应换成**：手推车 / 平板车 / 料架 / 周转箱 / 电动堆高车；量纲换成"**件·次/天**""**kg/天**""**箱/班**"。
2. **SHA 假定主流量是"物"。** 对于**服务性场所**（教学、办公、维保），物料流可能微不足道 ——
   SLP 书中明确提示"电子/珠宝厂一天只有几公斤物料""纯服务性场所几乎没有物料流"。
   → **本项目只对四类真实的物用 SHA，不能铺开到全空间**；人流的度量应另走通行探针路线。
3. **Mag Count 的原始图需回查原书**：本文给出的是公式与锚点示例，具体尺寸基准值曲线（附录 I 图 1）与完整度数表（图 3 的 B–F 全部档位）须查原书。
4. **数据可得性**：SHA 的强度校准要求"**算得出流量（吨/天）**"。若物料量只能估，则校准表的价值随之下降 —— 应**同时标注数据是实测、计数还是估计**（原书对此有专门提醒）。
