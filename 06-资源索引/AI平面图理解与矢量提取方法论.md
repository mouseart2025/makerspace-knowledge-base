# AI平面图理解与矢量提取方法论

> 核心结论：**不要用生成式图像模型画平面图，不要用纯视觉识别读图纸。建筑PDF是矢量文件，用PyMuPDF提取路径坐标+颜色分类+clipPath裁剪，才能获得精确的墙体/柱子/门窗数据。**
> 本文记录某职业院校创客空间（L型约434㎡）项目的验证过程，作为AI辅助空间规划的方法论基础。
> 验证时间：2026-08 ｜ 验证项目：职业院校创客空间（L型434㎡）

---

## 一、问题背景

AI辅助空间规划的第一步是"理解现有平面图"。如果AI连平面图都理解错了，后续的规划设计就是空中楼阁。

项目验证中，我们尝试了三种方法，发现前两种都不靠谱：

| 方法 | 原理 | 问题 | 结论 |
|------|------|------|------|
| 生成式图像（Seedream/Midjourney） | 文字描述→AI生成平面图 | 不理解真实平面图，L型是"想象"的；墙体/尺寸/门窗全是幻觉；文字乱码 | ❌ 完全不适合 |
| 视觉识别（AI看图+估算坐标） | AI读取图片，目测尺寸后重绘 | 丢失墙体凹凸转折；柱子简化为统一方块；门窗位置估算不准；设备基座完全遗漏 | ⚠️ 细节丢失严重 |
| **矢量解析（PyMuPDF提取路径）** | 从PDF矢量数据提取精确坐标 | 需用户确认规划区边界；尺寸标注数字被转曲时无法直接读取 | ✅ **唯一靠谱方法** |

## 二、矢量解析方法论（五步）

### Step 1：验证PDF是否为矢量PDF

```python
import pymupdf
doc = pymupdf.open("建筑图纸.pdf")
page = doc[0]
drawings = page.get_drawings()  # 矢量路径
images = page.get_images()      # 嵌入图片
text = page.get_text("text")    # 文字层

print(f"矢量路径: {len(drawings)}条")
print(f"嵌入图片: {len(images)}张")
print(f"文字字符: {len(text)}个")
```

**判断标准**：
- 矢量路径 > 1000 条 + 嵌入图片 = 0 → 纯矢量PDF（从CAD导出），可以精确提取
- 嵌入图片 > 0 + 矢量路径少 → 扫描件或图片PDF，需OCR或视觉识别
- 文字字符 = 0 → 尺寸标注数字被"转曲"（变成了矢量路径），无法直接提取数值

**项目实测结果**：2万余条矢量路径，0张嵌入图片，0个文字字符 → 纯矢量PDF，数字被转曲。

### Step 2：按颜色/线宽分类路径

建筑图纸通常用颜色区分元素类型：

```python
from collections import Counter
stroke_colors = Counter()
fill_colors = Counter()
widths = Counter()

for d in drawings:
    if d.get('color'):
        stroke_colors[tuple(round(c,3) for c in d['color'])] += 1
    if d.get('fill'):
        fill_colors[tuple(round(c,3) for c in d['fill'])] += 1
    widths[round(d.get('width',0), 2)] += 1
```

**项目实测的颜色分类**：
| 颜色 | 线宽 | 数量 | 含义 |
|------|------|------|------|
| 黑色 (0,0,0) | 0.12pt | 2万余条 | 墙体、门窗、尺寸标注线 |
| 黑色填充 (0,0,0) | - | 194个 | 柱子（含T型/L型异形柱） |
| 红色 (0.929,0.122,0.141) | 0.72pt | 237条 | 尺寸标注线 |
| 品红色 (1,0,1) | - | 232条 | 区域波浪线（需过滤） |
| 白色 (1,1,1) | - | 104条 | 背景/遮挡 |

### Step 3：定位规划区边界

这一步**必须由用户确认**，AI无法自动判断哪些区域属于规划范围。

方法：
1. 先渲染全图概览（PyMuPDF → PNG）
2. AI根据柱子分布/墙体走向初步推断规划区范围
3. 用红色虚线在SVG中标注边界
4. 用户确认或修正（用红框标注需要剔除的区域）
5. 迭代直到边界正确

**边界修正迭代示例**（过程比精确值更有复用价值）：
- v1：初框范围过大，包含了上部宿舍和左侧实验室
- v2：缩小后剔除了宿舍，但左侧和下侧仍有多余
- v3（定稿）：左侧西墙右移到结构柱右侧，下侧南墙上移，边界与规划区吻合

### Step 4：用clipPath精确裁剪

不要按路径中心点过滤（会丢失跨越边界的墙体线），要用SVG clipPath裁剪：

```python
# L型多边形顶点（顺时针，示例坐标，替换为实际项目坐标）
l_polygon = "0,0 600,0 600,900 350,900 350,300 0,300"

svg = f'''
<defs>
  <clipPath id="lshapeClip">
    <polygon points="{l_polygon}"/>
  </clipPath>
</defs>
<g clip-path="url(#lshapeClip)">
  <!-- 所有路径 -->
</g>
<!-- 边界线（红色虚线，供用户确认） -->
<polygon points="{l_polygon}" fill="none" stroke="#d32f2f" 
         stroke-width="1.5" stroke-dasharray="8,4"/>
'''
```

**关键**：clipPath会正确截断跨越边界的墙体线，不会遗漏边界处的细节（如门的弧线、柱子的一半）。

### Step 5：路径转SVG并验证

将PyMuPDF的path items转换为SVG path命令：

```python
def items_to_path_d(items):
    d = []
    for item in items:
        op = item[0]
        if op == 'l':    # 直线
            p1, p2 = item[1], item[2]
            d.append(f'M{p1.x:.1f},{p1.y:.1f} L{p2.x:.1f},{p2.y:.1f}')
        elif op == 'c':  # 三次贝塞尔（门的弧线）
            p1, p2, p3 = item[1], item[2], item[3]
            d.append(f'C{p1.x:.1f},{p1.y:.1f} {p2.x:.1f},{p2.y:.1f} {p3.x:.1f},{p3.y:.1f}')
        elif op == 'qu': # 四边形
            q = item[1]
            d.append(f'M{q.ul.x:.1f},{q.ul.y:.1f} L{q.ur.x:.1f},{q.ur.y:.1f} L{q.lr.x:.1f},{q.lr.y:.1f} L{q.ll.x:.1f},{q.ll.y:.1f} Z')
        elif op == 're': # 矩形
            r = item[1]
            d.append(f'M{r.x0:.1f},{r.y0:.1f} L{r.x1:.1f},{r.y0:.1f} L{r.x1:.1f},{r.y1:.1f} L{r.x0:.1f},{r.y1:.1f} Z')
    return ' '.join(d)
```

## 三、项目验证记录

### 验证成果参数（项目实例）
> 以下为某职业院校 L 型规划区（约 434㎡）验证的实际参数，用于展示方法论产出形态。项目底图/成果文件属项目档案，不随本知识库分发。
- **产出**：规划区矢量底图 SVG（含规划区裁剪 + 边界虚线标注）
- **规划区坐标**（PDF pt单位）：横向 + 纵向组成的 L 型多边形顶点坐标（见 Step 4 示例）
- **提取路径数**：数千条级（示例项目 4587 条）
- **坐标精度**：0.1pt（0.035mm）
- **尺寸标注单位**：mm（用户确认）

### 验证过程中的关键发现
1. **柱子不是统一方块**：有T型柱、L型柱等异形柱，视觉识别会全部简化为方块
2. **墙体有凹凸转折**：不是简单的直线，视觉识别会丢失细节
3. **南墙有设备基座**：X形图案的设备基座，视觉识别完全遗漏
4. **门的精确位置和开向**：矢量路径中门的弧线精确到0.1pt
5. **尺寸数字被转曲**：PDF文字层为0，无法直接提取数值，但标注线长度可测量

### 方法论有效性
- 矢量提取的墙体/柱子/门窗坐标100%来自原图，无幻觉
- 经过3轮用户确认边界，定稿底图准确反映规划区范围
- 此底图可直接作为后续AI规划设计的精确底图

## 五、局限与注意事项

1. **尺寸标注数字被转曲**：很多建筑PDF把文字转曲（变成矢量路径），无法直接提取数值。解决方法：
   - 向设计方索要原始DWG/DXF文件
   - 或用OCR识别转曲后的数字
   - 或从已知尺寸（如10550mm）对应的标注线长度推算比例尺，再测量其他尺寸

2. **规划区边界需人工确认**：AI无法自动判断哪些区域属于规划范围，必须用户确认。建议用红色虚线标注边界，迭代修正。

3. **矢量PDF≠可编辑CAD**：提取的是路径坐标，不是智能对象（墙/门/窗是分离的线段，不是参数化对象）。如需参数化编辑，需原始CAD文件。

4. **品红色区域波浪线需过滤**：很多建筑图用品红色波浪线圈定区域，这些不是建筑构件，提取时需过滤。

5. **坐标单位是PDF pt**：1pt = 1/72 inch = 0.3528mm，但建筑图纸有比例，需结合尺寸标注推算实际比例尺。
