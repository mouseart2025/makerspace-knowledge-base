# 免费 3D 素材源清单：开源库、工程 CAD 与数据集（含商用授权判据）

> **一句话**：**通用物（家具、货架、机柜、工具车）能白嫖；专业设备（机床、机器人、专用实训台）白嫖不到。**
> 比"去哪儿找"更要紧的是"能不能商用" —— 本轮实测两份高频数据集：**HSSD 是 CC BY-NC 4.0（禁商用）**、**Objaverse 80 万件里 CC0 只占约 3.5K**。

## 一、先立判据：什么能白嫖，什么不能

| 对象 | 能否从免费库取到 | 现实路径 |
|---|---|---|
| **通用物**：家具、桌椅、柜体、货架、白板、沙发、灭火器、急救箱、机柜、工具车 | ✅ **可以**，成熟 CC0/CC-BY 库很多 | 直接取 GLB → 归位缩放 → 体检 → 落位 |
| **工程零件**：型材、紧固件、轴承、导轨、齿轮、标准件 | ✅ **可以**，工程 CAD 库很全 | 取 STEP → 转 OBJ/GLB（需多一道转换） |
| **专业设备**：机床、工业机器人、激光/CNC、专用实训台、检测仪器 | ⛔ **基本没有**（有也是低模示意或授权不明） | **自产授权物 > 照片生成 3D > 厂商 CAD** |
| **建筑本体**：墙、柱、门窗、楼板 | ⛔ 不适用 | 一律以**实测重建**为准，不从素材库取 |

## 三、第 2 级：免费但需署名或需登录

| 来源 | 授权 | 注意 |
|---|---|---|
| **Sketchfab** | 逐件（可筛 CC0/CC-BY） | 量大、写实模型多；**必须逐件看许可**，下载需登录 |
| **Poly Pizza** | 约 **69% 为 CC-BY**（须署名），其余 CC0 | 约 10,600 件低模（含 Google Poly 存档），单件自包含 `.glb`、几何轻。★ 已知坑：CDN `static.poly.pizza` 有 **Cloudflare 风控，会拦机房/VPN IP**，脚本批量下载易失败 |

## 四、第 3 级：工程 CAD 库（专业设备与结构件的现实免费来源）

★ 这一级最容易被忽略：专业设备在「3D 素材站」找不到，但在「**工程零件库**」找得到。

| 来源 | 内容 | 格式 | 备注 |
|---|---|---|---|
| **GrabCAD Library** | 社区上传的零件/装配体，含机床、机器人、汽车总成 | STEP/IGES/SLDPRT | 免费需注册；**授权逐件看** |
| **TraceParts / 3D ContentCentral / PARTcommunity** | 厂商标准件与零部件 | STEP/DWG 等 | 免注册居多，格式规范 |
| **McMaster-Carr** | 五金与工业件（紧固件/齿轮/型材…） | STEP | 免费；做**台架、货架、工具柜的结构件**非常省事 |
| **Misumi（米思米）/ igus / RS** | 自动化零部件、型材、拖链 | 可配置尺寸后下载 2D/3D | 参数化选型，适合「骨架类」 |
| **Khronos glTF Sample Assets** | 官方样例（含 Gearbox / Engine / Reciprocating Saw 等机械件） | **glTF 原生，免转换** | 授权清晰、体积极小；适合先试通"机械件进 Blender"这条链路 |

> ⚠️ CAD 来源产出是 **STEP/IGES**，需一次格式转换（Blender 装 STEP 导入插件，或先经 FreeCAD 转 OBJ/GLB）。转完仍是「**尺寸可信、外观简**」的资产 —— 与占位盒是互补关系，不替代。

## 五、第 4 级：3D 数据集（体量最大，但授权要逐个筛）

| 数据集 | 体量 | 授权 | 能否商用 |
|---|---|---|---|
| **Objaverse / Objaverse-XL** | 800K+（XL 10M+） | 整体 **ODC-By v1.0**；逐件：CC-BY 721K／CC-BY-NC 25K／CC-BY-NC-SA 52K／CC-BY-SA 16K／**CC0 仅 3.5K** | △ **只能用 CC0 + CC-BY 子集**；须按 metadata 逐件筛 |
| **HSSD（Habitat Synthetic Scenes）** | 211 场景／**18,656 个模型**，GLB | **CC BY-NC 4.0** | ⛔ **禁商用 → 商业项目排除**（方法论可参考，资产不可用） |
| **3D-FRONT / 3D-FUTURE** | 家具为主 | 需核（多为研究用途 NC） | ⛔ 大概率同类问题，用前必核 |
| **Google Scanned Objects / ABO** | 扫描实物／电商商品 | CC-BY / CC-BY-SA 类 | △ 需核；ABO 偏消费品 |

★ **判据**：数据集一律**先看 `license` 字段能否商用，再看模型好不好看**。**NC 类不进商业交付物**。

## 六、程序化批量取用

| 方式 | 适用 | 说明 |
|---|---|---|
| **`polydown`**（`pip install polydown`，MIT） | Poly Haven 批量 | 用公开 API，`polydown models -mf gltf -s 1k` 直取 **glTF**，可指定类别/尺寸/贴图 |
| **JSON 索引直拉** | ToxSam 991 GLB | `projects.json` → `assets/*.json`，每条含 `model_file_url` + `license` + `format`，可脚本筛选 |
| **API Key** | Poly Pizza | 需 key；注意上文 Cloudflare 坑 |
| **MCP for Blender**（`ahujasid/mcp-for-blender`） | 交互式找素材 | 内置 Poly Haven / Poly Pizza / Sketchfab 三源 + Hyper3D Rodin / 腾讯混元 3D 两生成源；凭据可走**环境变量**，无头/CI 可用。★ 属**可选增强**，非必需 |

## 七、四个坑

1. **授权**：「免费下载」≠ 可商用。**CC0** 免署名；**CC-BY** 须在交付物里署名（图纸角注/汇报附页）；**NC 一律不用**。
2. **尺寸不可信**：库模型比例任意、单位混乱、无几何语义 —— 与图生 3D 同病，**接入前四道体检照跑**（见《设备外观模型获取》§四）。
3. **面数与体量**：写实库模型动辄几十万面，全屋几十件装配后预览卡死。进场前先看三角面数，必要时减面。
4. **风格不一致**：低模与写实混在一张图里非常刺眼。**同一张图只用同一风格档**：低模=方案期，写实=对外汇报。

## 八、落地建议（通用版）

1. **先试一条最短链路**：从 CC0 库各取 1 件（椅 / 柜 / 货架）→ 走完「导入 → 归位缩放 → 体检 → 落位 → 出图」，与图生 3D 链路做对比。
2. **建「素材来源与授权台账」**：每件进场登记**来源 / 授权类型 / 是否需署名 / 原始面数 / 归位缩放系数**；**CC-BY 的署名要求必须能一键导出成清单**。
3. **不做全量替换**：只替换**视觉锚点**（方案图与汇报里最显眼的那几件）；面积账、净空账、越界判据**全部以项目数据源为准**，外观模型不参与任何数字。
4. **专业设备走自产**：自产授权物（甲方/厂商）> 照片生成 3D > 厂商 CAD；**不要把专业设备寄希望于免费素材库**。
