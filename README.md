## 〇、知识库定位与目的

本知识库的初衷很朴素：**让"用 AI 辅助进行创客空间的规划、建设和管理"这件事变得可操作、可复制**。

我们（柴火创客空间 / 深圳矽递科技社区团队）在做空间改造时发现：创客空间的搭建看似随性，实则高度依赖一套可沉淀的方法——从理念认知、空间分区、设备选型，到安全规范、运营模式、课程体系，每一项都有成熟经验与公开标准可循，但这些知识散落在各处，单靠搜索难以系统获取。

因此我们把这套经验整理成结构化、可检索、可喂给 AI 的知识库，目的有三：

1. **给规划者**：拿着现成的分区逻辑、设备清单、工程参数，用 AI 快速生成符合实际需求的改造方案，而不是从零摸索；
2. **给建设者**：提供采购蓝本、摆放规范、安全标准，降低踩坑成本；
3. **给运营者**：沉淀运营模式、社区建设、课程设计方法论，让空间建起来之后"转得起来"。

**如何使用**：先用 [GLOSSARY 检索索引](06-资源索引/GLOSSARY检索索引.md)（术语 → 文档，一对一映射）定位到最相关的文档，再把它们作为上下文喂给 AI（如豆包等支持文档理解的工具），配合 [02-空间搭建/AI辅助创客空间规划-方法与工具库.md](02-空间搭建/AI辅助创客空间规划-方法与工具库.md) 中的工作流与提示词模板，即可获得结构化、带依据的规划建议。所有内容均开源，你可以直接复用、改写，也欢迎回馈改进。

## 四、核心结论速览（TL;DR）

1. **建设一个标准 Fab Lab**：四大准入标准（公众开放、遵守 Fab Charter、共享工具流程、参与全球网络）；资本投入 $25K–65K + 耗材 $15K–40K；标准实验室总投入约 12 万美元，占地 140–177㎡。
2. **最低成本入门**：Fab-in-a-box 套件约 **$10,000**（激光切割 + 3D 打印 + 切纸机 + 通风 + 教学电脑 + 课程），专为教育场景设计，可移动、可当天开课。
3. **国内失败教训**（柴火总结）：① 自上而下缺乏对创客精神的统一认知；② 设备管理封闭化、展厅化；③ 缺少创客社区经营。对应解法分别是"理念先行"、"在安全框架下最大自由开放"、"导师制 + 用户变成员"。
4. **运营收入结构**：Fab Academy 学费 + 付费工作坊/培训 + 机器使用费/订阅 + 产品销售/代工 + 政府资助 + 企业赞助，多元组合才可持续。
5. **教育是最大的应用场景**：从 MAS.863 到 Fab Academy 到 SCOPES-DF，"每周一个项目"的做中学（learning-by-doing）模式是被验证 20 年的创客教育核心方法论。
6. **Fab Academy 实账**（2025 届实测）：学费 $5000（Fab Academy 与本地节点对半）；1 月开课 6 月结课约 20 周；本地导师 + 全球评审 + 学生仪表盘三层支持；**英语门槛可被 AI 工作流降为零**；毕业即得公开作品集。承办节点每学员收 $2500，是空间的重要收入线（Seeed 制度：5 年以上老员工毕业全额报销学费）。
