# 科普场馆创客空间项目档案

> 柴火创客空间团队曾为某国家级科普场馆规划创客空间建设方案。本文为该项目的方法论整理版，将其中可复用的运营思路、空间规划语言与设备配置逻辑沉淀为通用参考，供各类科普场馆 / 教育型创客空间借鉴。
> 归档时间：2026-08

## 项目背景

- **项目类型**：国家级科普场馆 × 创客空间建设
- **乙方**：柴火创客空间 / 柴火创客教育团队
- **痛点诊断**（团队实地参观后的判断）：
  1. 馆内展品与快速发展的科技相比有迟滞
  2. 访客缺少从"知道"到动手"创造"的体验环节
- **核心共识**：创客空间的设计、建设和运营是持续发展过程，**单次设计建设无法达到运作目标**

## 一、运营思路（核心观点提炼）

### 1. 创客的精神特质（引用 Maker Media《Makerspace Playbook School Edition》）

- 只要能想到，就能做到——每个人都是创造者
- 寻求机会学习新事物，尤其动手 DIY
- 让看到项目的人惊讶和高兴（哪怕粗糙、凌乱）
- 社区精神：开放、包容、鼓励、慷慨
- 所作通常不为赚钱——不反对创业，但不作为关注点
- 为其他创客庆祝

### 2. 玩耍的重要性（JPL 案例）

- NASA JPL 发现：最优秀的年长工程师年轻时都拆过钟表、做过肥皂盒赛车/高保真音响
- 善于动手的毕业生解决复杂问题的能力显著更强——动手项目成为 JPL 招聘标准
- **结论**：真正的学习发生在"创造性游戏"中——创客空间要成为爱玩魔力的容器

### 3. 国内创客空间失败三大原因（柴火总结）

| 失败原因 | 解药 |
|----------|------|
| 自上而下缺乏对创客精神/价值/目标的统一认知 | 理念先行，运营者要有"好玩"心态 |
| 设备管理封闭、展厅化 | 安全框架下最大自由开放 |
| 缺少创客社区经营 | 发掘热爱者参与运营，走向正循环 |

### 4. 正面参照

- **德国 maker-space**：设备在线预约系统典范（详见规划文档分析）
- **深圳实验学校**（刘焱锋老师）：3 位专职创客老师、自编系统教材；兴趣小组学生自主摆弄；老师做"GPS 导航仪"——指方向少干预 → 深圳市中学生创客马拉松第一名
- **稚晖君**（自动驾驶自行车网红）：内驱力 = 好玩

### 5. 教育潜力

- 影响领域：灵感（邀请学生参与创意经济）× 创新（草根发明催化剂）× 教育（连接社区与学习者）
- Maker Faire 精神：没有输赢，没有评委，任何酷的东西都是公平游戏

## 二、空间规划方案要点

### 功能分区

| 分区 | 定位 | 要点 |
|------|------|------|
| 主入口 / 走廊 / 开放共享区 | 引流与展示 | 装修公司负责 |
| **创新教室 1** | 培训 + 数字制造服务 | 16 张 1.2m 创客桌，三模式布局（48 人高容量 / 创客马拉松 / 团队项目）；白板墙；3D 打印 + 数字切割 + 3D 扫描工作区沿墙布置 |
| **创新教室 2** | 工作区 + 小型培训 | 8 张创客桌；电子工作台、可穿戴工作台（缝纫/印花）、陶艺区（陶瓷 3D 打印 + 电窑 + 防水地面 + 过滤池）、雕刻工作台 |
| **手造区** | 重型加工 | 工业级激光切割机（玻璃隔断 + 排气）、工作台、**锂电池充电防爆箱** |
| **整备间** | 后勤 | 水槽 + 钢制桌面，存小推车、培训装备准备 |

### 设计策略：透明化四连

1. 门厅墙体拆一段——入口直视教室 1，吸引"一探究竟"
2. 教室 1/2 半高玻璃窗——走廊可见活动，半高不干扰室内
3. 手造区拆门 + 临走廊墙改透明——扩容 + 可视

### 细节设计

- 学生存包处（走廊近教室）
- 下垂式电源（教学区，可收至天花板）
- 激光切割机玻璃隔断在设备进场后安装（尺寸锁定）

## 三、设备配置参考（结构版）

> 以下为教育型创客空间的设备配置逻辑（保留配置思路，具体规格请结合预算与教学定位调整）。

**教室一**（数字制造 + 电子 + AI/机器人方向）：
- 基础设备：大屏、台式/笔记本电脑、桌面激光切割机（40W CO₂，580×380mm 幅面）、3D 打印机、三维扫描仪（0.03mm 精度级）
- 基础工具：手工/电动工具箱、万用表、示波器、焊台、小推车
- 耗材：焊锡丝、彩纸、纸板、椴木板、亚克力、3D 打印耗材
- 电子与开源：游戏编程套装（初级/中级）、创客设计套装（初级/中级 + 拓展包）、Grove × 树莓派 Pico 入门套件
- IOT：Wio Terminal + 4G 物联网
- 人工智能：机器狗、自动驾驶
- 课程资源：双足机器人/自动驾驶/机器学习/仿生四足/Wio LTE 物联网/智能家居/开源板/循迹小车订制资源包

**教室二**（工艺 + 材料方向）：
- 打印机、桌面雕刻机、成型机
- 陶艺：陶瓷 3D 打印机、电窑、彩绘工具、泥料/釉料、过滤池
- 缝纫：缝纫机（JUKI HZL-60HR-B）、缝纫套装、布/乙烯/皮革/毛毡/扣子/线材
- 激光切割机（第二台）
- 木工：Festool TS55F + 导轨、MFT/3 工作台、CTL MIDI 吸尘、曲线锯、砂磨机、手电钻

> 配置原则：教室一面向"数字制造 + 电子 + AI"，教室二面向"工艺 + 材料"，两间互补覆盖完整创客流程。

## 四、作为知识库实战模板的价值

这是**可复用的实战模板**：
1. 运营思路文档 = 给新甲方讲清"为什么与怎么做"的范本（理念先行策略）
2. 空间规划方案 = 透明化 + 分区 + 灵活布局的设计语言
3. 设备需求表 = 教育型创客空间的完整采购蓝本（参数级）
4. "理念 → 规划 → 设备"三件套顺序本身就是方法论
