# Fab I Can Statements 与 SCOPES-DF 教案评估体系（专题补充）

> 调研时间：2026-08 ｜ 来源：Fab Foundation 官网（fabfoundation.org）+ SCOPES-DF 教案社区（scopesdf.org）全站抓取
> 定位：补足《课程与教育项目.md》中 2.3 SCOPES-DF 小节的**评估体系细节**（Fab I Can Statements 六大领域 18 条陈述）与**教案资源库**，并纳入 Fab Foundation 推动的美国政策对标。

---

## 一、Fab I Can Statements：数字制造学习的形成性评估体系

**定位**：由 Fab Foundation 开发并持续维护的一套**形成性评估工具（formative assessment tool）**，用于教师衡量 K-12 课堂中的数字制造学习体验；把技术学习目标"代码化"，可支撑国家、国际与州级标准（对齐 Common Core / NGSS / ITEEA）。已在全球用于校内外学习（有阿拉伯语等多语种版本）。

**结构**：**6 大领域 × 3 级递进**（18 条陈述），等级表达"学生自主程度"与"工作流深度"的递进：

### 1.1 Design 设计

> 设计是 Fab Lab 最基础也最难的技能，陈述从新手到进阶递进，且"质"与"量"共同演进。

| 级别 | 陈述 |
|------|------|
| Design.1 | 我能在导师指导下，在小组内承担设计过程中的各项活动 |
| Design.2 | 我能用准备好的展示材料参与设计评审，并给予/接收同伴反馈 |
| Design.3 | 我能主动发起设计流程，为已界定问题的多个利益相关方生成多套方案 |

### 1.2 Programming 编程

> 计算思维（computational thinking）对跨学科成功至关重要，如用计算工具 + 几何建模 2D/3D 物体；为物体添加逻辑与行为。

| 级别 | 陈述 |
|------|------|
| Programming.1 | 我理解简单程序的基本结构，能修改值、变量或其他参数来改变其输出/功能/行为 |
| Programming.2 | 我能创建含多条指令的程序 |
| Programming.3 | 我能创建含多条指令与分支的程序，并在微控制器板上读写输入/输出 |

### 1.3 Electronics 电子

> 物理计算（physical computing）教学生通过计算机与组件通信，控制机构/系统；需用传感器与微控制器处理模拟数据、控制机电设备。

| 级别 | 陈述 |
|------|------|
| Electronics.1 | 我能按指示用导电材料、基础元件和电源搭建简单电路 |
| Electronics.2 | 我能按原理图创建含微控制器的电路与电子元件 |
| Electronics.3 | 我能自创原理图并用其搭建含微控制器的电子电路 |

### 1.4 Modeling 建模

> 建模陈述既促进通用操作与术语，也反映设计软件不断变化的特性；浏览器软件还引入账号管理、文件共享、协作等技能。

| 级别 | 陈述 |
|------|------|
| Modeling.1 | 我能用多种技术排列与操作简单几何元素、2D 形状和 3D 实体 |
| Modeling.2 | 我能构建复合形状与多部件组件，用多种表示方式为物理生产做好准备 |
| Modeling.3 | 我能用参数化关系建模、生成式/算法/函数表示定义复杂系统 |

### 1.5 Fabrication 制造

> 核心信条：不是孤立地掌握某台机器/软件，而是学习把多台机器、软件、材料链接起来的**工作流（workflows）**。

| 级别 | 陈述 |
|------|------|
| Fabrication.1 | 我能跟随导师指导的步骤，链接软件与机器产出简单实物 |
| Fabrication.2 | 我能跨 4 种以上环节开发工作流（建模软件/编程环境/制造机器/电子元件/材料选择/装配操作）|
| Fabrication.3 | 我能自制应用、机器或电子元件解决新问题，并扩展我所在 Fab Lab 的能力 |

### 1.6 Safety 安全

> 使用实验室设备与材料存在潜在风险，安全是体验的关键部分；各校/各空间须有自己的安全指南与规程，此处为总纲。

| 级别 | 陈述 |
|------|------|
| Safety.1 | 我能在 Fab Lab 中安全行事，并在导师指导下观察操作 |
| Safety.2 | 我能按安全协议操作 Fab Lab 设备 |
| Safety.3 | 我能监督他人在 Fab Lab 中的行为并确保安全协议得到遵守 |

### 1.7 对创客空间（尤其教育型/科普型）的用法

- **作为课程设计的评估锚点**：用 6 领域 × 3 级做能力成长地图，明确"学生从跟随到自主再到创造"的递进路径
- **作为学分/证书/徽章的等级标准**：与知识库《1+X证书与技能认证体系.md》《技能竞赛体系-三专业赛项与备赛.md》可互相对照
- **与安全培训挂钩**：Safety.1→2→3 正好对应"观察→独立操作→监督他人"的安全培训晋升路径，可并入《实训室安全与应急预案专项.md》

## 二、SCOPES-DF：数字制造教案社区（scopesdf.org）

**定位**：Fab Foundation 运营的**数字制造教育实践社区（Community of Practice）**，激活数字制造工具支持跨学科的真实学生学习。

| 维度 | 数据 |
|------|------|
| 教案规模 | **540+ 社区贡献教案**（2026-08 首页口径；此前宣传为 250+）|
| 社区成员 | 1,000+ 名教育者 |
| 对齐标准 | Common Core / NGSS / ITEEA + **Fab I Can Statements** 学习评估 |
| 学科分类 | Technology / Engineering / Art & Design / Language Arts / Cultural / Mathematics / Computer Programming / Science |
| 设备标签 | 教案按设备标注（3D 打印机 / 激光切割机 / 乙烯基切割机 / 电脑 / 焊台 / 手工工具等）|
| 运作 | 免费教案库 + 虚拟网络研讨会/工作坊/meetup + 教案竞赛 + Fab Educators Summit + Podcast |

**社区机制（可借鉴）**：
- **Fab26 教案竞赛**：为 FAB26 提交教案最高奖 $500 USD——用竞赛激励内容共创
- **Fab Educators Summit**（2026-07-26，FAB26 会前会议）：免费全球教育者峰会（详见 `../05-案例研究/全球Fab-Lab案例.md` 中 Liz Whitewolf 介绍）
- **Chevron Fab STEM Fellowship**：雪佛龙资助的 STEM 教师奖学金 + 播客（案例：巴西教育技术协调员、越南教师全球旅程等）——**企业资助教育者的模式**
- **贡献者图谱**：正式/非正式教育者、Fab Academy 毕业生、博物馆（如美国国家建筑博物馆）、政府数字青年战略机构（如沙特 STUDIO 5）等

**代表性教案示例**（证明跨学科包容性）：
- *Emotions in Motion*：用 Makey Makey 制作情感表达海报，面向残障儿童（电子 + 艺术 + SEL）
- *Emotion Box*：7–9 年级学生为 1–4 年级设计"情绪调节盒子"（SEL + 电子 + 服务学习）
- *Growing Smarter*：用激光/乙烯基切割搭建城市模型，探讨人与地球（地理 + 制造 + 地球日主题）
- *Accessible Museums*：为视障人士设计可触摸博物馆展品（3D 打印 + 激光 + 包容设计）

## 三、National Fab Lab Network Act（美国政策对标）

> Fab Foundation 长期推动的立法：**每个美国国会选区至少一个 Fab Lab**。对中国创客空间的价值主要是"政策推动参考"，不直接适用。

| 维度 | 内容 |
|------|------|
| 法案 | National Fab Lab Network Act of 2019（Bill S.2752 / H.R. 3837）|
| 提出 | 2019-07-18，两党两院：参议员 Van Hollen、Murkowski，众议员 Foster；2023 年再次引入（H.R. 9205）|
| 目标 | 成立联邦特许非营利组织"National Fab Lab Network (NFLN)"作中央种子资金源，**目标每个国会选区至少 1 个 Fab Lab（或约每 70 万人 1 个）**|
| 类比 | 类似 Little League Baseball 等非营利特许模式 |
| 使命 | 先进制造工具的普遍获取，服务劳动力发展、STEM 教育、发明创造、创业、个性化产品、风险缓解 |
| 现状 | 官网（2026-08）：已提交参议院、正在众议院推进；美国各州 Fab Lab 分布图显示已有相当覆盖 |

**借鉴点**：① "分布式制造 = 国家基础设施"的政策叙事；② 非营利联邦特许 + 种子资金的网络组织形态；③ 以"选区/人口"为单位的覆盖目标量化方法。

## 四、对知识库的启示与衔接

1. **评估体系缺口补齐**：知识库此前有教案/课程设计（《课程与教育项目.md》《三专业典型实训项目库.md》），但缺**能力等级评估框架**——Fab I Can Statements 的"6 领域 × 3 级"可直接作为实训项目的能力达成标准模板。
2. **教案共创机制**：SCOPES-DF 的"竞赛 + 峰会 + 奖学金 + 播客 + 贡献者图谱"是社区内容共创的完整机制，可平移至柴火/社区空间的教案征集与教师社区建设。
3. **设备-教案双标签**：SCOPES-DF 每份教案标注所需设备（3D 打印/激光/乙烯基切割/电子），与《设备清单与选型.md》联动，形成"设备 → 能开什么课"的映射。
4. **数据口径补充**：Fab Foundation 官网首页另有"2,300+ Fab Labs / 120+ 国"口径（与 Fab Hub Kendall 的 2,700+/165 国、宣传口径 3000+/160 国并存），引用时注意统一来源。
