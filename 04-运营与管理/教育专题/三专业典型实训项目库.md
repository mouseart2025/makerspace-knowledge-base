# 三专业典型实训项目库

> 调研时间：2026-08-30 ｜ 说明：面向**智能制造 / 人工智能 / 新能源汽车**三专业的典型实训项目库，可直接排课。每个项目卡含：目标技能 / 设备需求 / 课时 / 考核点 / 对接证书或赛项。
> 依据：教育部 2026《职业教育专业目录》增补 27 专业、教职成〔2026〕1号《深化职业教育教学关键要素改革的意见》（课程能力图谱/项目化教学）、NVIDIA 等设备厂商课程资源。

---

## 使用说明

- **项目阶梯**：基础（✱）→ 综合（✱✱）→ 创新（✱✱✱）
- **课时**：建议值，可拆分模块化排课
- **对接**：标注对接的 1+X 证书 / 技能竞赛 / 职业标准
- **设备**：指向知识库设备清单中的对应设备，避免为项目单买设备

---

## 一、智能制造方向（12 个项目）

### 基础层

**1. 数控编程与加工基础**（✱，24 课时）
- 目标技能：数控车/铣编程、工艺参数、安全操作
- 设备：数控加工中心/数控车床
- 考核点：程序编写正确率、工件尺寸精度
- 对接：数控车铣加工 1+X / 全国技能大赛数控车铣

**2. 工业机器人示教编程**（✱，24 课时）
- 目标技能：示教器操作、点位示教、基本轨迹
- 设备：工业机器人工作站（六轴/协作）
- 考核点：轨迹编程、安全操作规范
- 对接：工业机器人应用编程 1+X / 机器人系统集成赛项

**3. PLC 与电气控制基础**（✱，32 课时）
- 目标技能：PLC 编程（西门子/三菱）、继电器控制、电气接线
- 设备：PLC 实训台
- 考核点：程序逻辑、接线正确性
- 对接：可编程控制器 1+X

**4. 机械装配与调试基础**（✱，24 课时）
- 目标技能：装配工艺、公差测量、机构调试
- 设备：装配实训台、量具
- 考核点：装配精度、调试结果
- 对接：机械产品三维模型设计 1+X

### 综合层

**5. 机器人视觉分拣系统集成**（✱✱，40 课时）
- 目标技能：视觉识别、机器人+视觉联动、抓取策略
- 设备：机器人工作站 + 视觉模块
- 考核点：分拣准确率、系统集成完整性
- 对接：机器人系统集成赛项

**6. 智能产线运行与维护**（✱✱，48 课时）
- 目标技能：产线调试、MES 操作、故障诊断
- 设备：模块化智能产线
- 考核点：产线联调、故障排查
- 对接：智能产线运行与维护赛项

**7. 数字孪生与虚拟调试**（✱✱，32 课时）
- 目标技能：虚拟仿真建模、虚实映射、工艺验证
- 设备：数字孪生实训平台（虚拟仿真软件）
- 考核点：虚拟调试正确性、节拍分析
- 对接：数字孪生应用技术赛项 / 虚拟仿真实训

**8. 工业互联网数据采集**（✱✱，32 课时）
- 目标技能：传感器组网、数据采集、边缘网关
- 设备：工业互联网实训系统
- 考核点：数据完整率、平台接入
- 对接：工业互联网应用与维护赛项

### 创新层

**9. 柔性制造单元综合项目**（✱✱✱，64 课时）
- 目标技能：多设备协同、产线规划、项目管理
- 设备：柔性制造单元（加工中心+机器人+AGV）
- 考核点：单元集成、产能指标
- 对接：综合赛项/毕业设计

**10. 定制化产品智能制造**（✱✱✱，48 课时）
- 目标技能：订单驱动排产、工艺柔性调整
- 设备：智能产线 + MES
- 考核点：定制化生产实现
- 对接：产教融合真实项目

**11. 智能仓储与物流**（✱✱✱，32 课时）
- 目标技能：AGV 调度、立体库管理、WMS
- 设备：智能仓储实训线
- 考核点：调度策略、库存准确率
- 对接：供应链管理 1+X

**12. 智能制造产线改造实战**（✱✱✱，40 课时）
- 目标技能：产线诊断、改造方案、实施验证
- 设备：企业真实产线（校企合作）
- 考核点：改造方案、落地效果
- 对接：技术服务/社会服务

## 二、人工智能方向（12 个项目）

### 基础层

**1. Python 与数据处理基础**（✱，32 课时）
- 目标技能：Python 编程、NumPy/Pandas、数据可视化
- 设备：PC/图形工作站
- 考核点：代码正确性、数据分析结果
- 对接：Python 相关证书

**2. 机器学习入门**（✱，40 课时）
- 目标技能：监督/无监督学习、模型评估
- 设备：AI 算力平台
- 考核点：模型准确率、调参能力
- 对接：AI 应用工程师 1+X

**3. 深度学习基础（PyTorch）**（✱，40 课时）
- 目标技能：神经网络、CNN/RNN、训练调优
- 设备：GPU 服务器/工作站
- 考核点：模型训练、loss 收敛
- 对接：人工智能工程技术赛项

**4. 计算机视觉入门**（✱，32 课时）
- 目标技能：OpenCV、图像处理、目标检测（YOLO）
- 设备：PC + 摄像头 + Jetson（可选）
- 考核点：检测准确率
- 对接：机器视觉相关赛项

### 综合层

**5. 边缘 AI 部署（Jetson）**（✱✱，32 课时）
- 目标技能：模型转换、边缘推理、TensorRT 优化
- 设备：Jetson Orin Nano 等边缘设备
- 考核点：推理速度、部署成功
- 对接：NVIDIA 教育生态/智能硬件赛项

**6. 智能语音交互**（✱✱，32 课时）
- 目标技能：ASR/TTS、语音命令控制
- 设备：AI 算力平台 + 麦克风阵列
- 考核点：识别率、交互体验
- 对接：AI 应用项目

**7. 机器人视觉导航**（✱✱，48 课时）
- 目标技能：SLAM、路径规划、自主避障
- 设备：移动机器人 + 激光雷达 + Jetson
- 考核点：导航成功率
- 对接：智能机器人赛项

**8. 大模型应用开发**（✱✱，32 课时）
- 目标技能：Prompt 工程、RAG、Agent 搭建
- 设备：GPU 服务器 / 云 API
- 考核点：应用功能实现
- 对接：AIGC/智能体应用

### 创新层

**9. 具身智能机械臂抓取**（✱✱✱，48 课时）
- 目标技能：机械臂+视觉+强化学习、物体抓取
- 设备：协作机械臂 + 视觉系统
- 考核点：抓取成功率
- 对接：具身智能方向/人形机器人赛项

**10. AI 视觉质检系统**（✱✱✱，40 课时）
- 目标技能：缺陷检测、工业场景部署
- 设备：工业相机 + 算力平台
- 考核点：检出率、误检率
- 对接：产教融合真实项目

**11. 多模态智能体项目**（✱✱✱，48 课时）
- 目标技能：多模态理解、工具调用、任务编排
- 设备：GPU 服务器
- 考核点：任务完成度
- 对接：创新项目/竞赛

**12. AI 边缘巡检系统**（✱✱✱，40 课时）
- 目标技能：边缘推理 + 传感器融合 + 远程监控
- 设备：Jetson + 传感器 + 云平台
- 考核点：巡检系统功能
- 对接：综合实战

## 三、新能源汽车方向（10 个项目）

### 基础层

**1. 动力电池拆装与检测**（✱，32 课时）
- 目标技能：电池包结构、拆装规范、电压/内阻检测
- 设备：动力电池实训台架
- 考核点：拆装安全、检测数据
- 对接：新能源汽车检测与维修赛项 / 1+X

**2. 驱动电机与控制系统**（✱，32 课时）
- 目标技能：电机结构、控制器原理、三相检测
- 设备：驱动电机台架
- 考核点：电机控制逻辑、故障判断
- 对接：新能源汽车检测与维修赛项

**3. 高压安全与绝缘检测**（✱，16 课时）
- 目标技能：高压系统安全、绝缘电阻测量、断电流程
- 设备：高压安全实训装置
- 考核点：安全流程执行
- 对接：高压电作业安全（必考）

**4. 整车结构与认知**（✱，16 课时）
- 目标技能：整车三电布局、底盘认知、高压部件识别
- 设备：实训整车
- 考核点：部件识别、安全标识

### 综合层

**5. 新能源汽车故障诊断**（✱✱，48 课时）
- 目标技能：诊断仪使用、故障码读取、系统排查
- 设备：实训整车 + 诊断仪
- 考核点：故障定位准确率
- 对接：汽车技术赛项

**6. 电池管理系统（BMS）分析**（✱✱，32 课时）
- 目标技能：BMS 原理、SOC/SOH 估算、均衡策略
- 设备：BMS 实训平台
- 考核点：数据分析、策略理解
- 对接：1+X 智能新能源汽车

**7. 智能网联与 ADAS**（✱✱，40 课时）
- 目标技能：传感器（雷达/摄像头）、融合、辅助驾驶
- 设备：智能网联实训平台
- 考核点：系统标定、功能验证
- 对接：智能网联汽车相关赛项

**8. 充电系统与设施运维**（✱✱，24 课时）
- 目标技能：充电桩原理、安全规范、故障处理
- 设备：充电桩实训装置
- 考核点：充电流程、故障排查
- 对接：充电设施运维

### 创新层

**9. 新能源汽车电气系统改装**（✱✱✱，40 课时）
- 目标技能：电气设计、线束改造、功能集成
- 设备：实训整车 + 电气工具
- 考核点：改装功能、安全性
- 对接：创新项目

**10. 电池梯次利用与回收**（✱✱✱，32 课时）
- 目标技能：电池评估、梯次利用方案、环保合规
- 设备：电池检测设备
- 考核点：评估报告、方案
- 对接：双碳/绿色方向

## 四、项目库设计原则

### 4.1 "岗课赛证"四维对齐

```
岗位（真实岗位能力） → 课程（项目化教学） → 赛项（竞赛标准） → 证书（1+X/职业技能等级）
```

### 4.2 设备复用

- 项目设备全部来自知识库 [../03-设备与工具/设备清单与选型.md](../../03-设备与工具/设备清单与选型.md) 的实训区配置，**不新增专用设备**
- 一机多用：机器人工作站 = 教学 + 竞赛 + 社会服务

### 4.3 分层教学

| 层 | 目标 | 课时占比 | 形式 |
|----|------|---------|------|
| 基础 | 技能达标 | 40% | 单项训练 |
| 综合 | 系统集成 | 40% | 项目制 |
| 创新 | 真实任务 | 20% | 竞赛/企业项目/毕设 |

### 4.4 项目来源更新

- 项目内容随**赛项更新、企业技术迭代、新专业目录**每 6 个月核验更新
- 鼓励校企联合开发真实生产项目（参照教职成〔2026〕1号"项目化、案例化、模块化"要求）
