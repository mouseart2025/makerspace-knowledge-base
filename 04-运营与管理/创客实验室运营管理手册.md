# 创客实验室运营管理手册

> 创客实验室日常运营的落地体系：组织架构、人员配置、值班制度、开放管理、预约系统、日常SOP、巡检、财务管理、年度考核
> 调研时间：2026-08 ｜ 主要来源：Delaware大学Design Studio（Minions学生运营）、南理工X·Space管理规定、湖南大学创客空间管理办法、高职7S管理制度、MakeHaven数据仪表盘、Fab Foundation人员配置模型
> 定位：本文是 [运营模式与收入结构.md](运营模式与收入结构.md) 的**落地深化篇**——前者回答"空间靠什么活"，本文回答"每天怎么转"。直接服务于某职业院校创客空间（三专业共享）的运营体系设计。

## 一、组织架构与治理

### 1.1 职业院校创客实验室治理模型

```
                   校方（教务处/二级学院）
                          │ 立项、资金、合规
               ┌──────────┴──────────┐
       教学负责人（专业教师）      运营负责人（实验员/主任）
              │ 课程/教学/竞赛         │ 日常运营/安全/设备
        ┌─────┼─────┐          ┌──────┼──────┐
     专业教师  指导教师  学生助理   值班员   设备管理员
      （三专业） （竞赛） （TA体系） （开放时段）（维保）
```

> **双负责人制借鉴**：Delaware Design Studio由两位教师共同主导，按"数字制造与电子"、"轻原型与测试"分工分管；本项目可按"教学与竞赛"、"运营与安全"分工。["https://files.eric.ed.gov/fulltext/EJ1255251.pdf"]

### 1.2 治理机制

| 机制 | 说明 |
|------|------|
| **负责人制** | 空间有明确负责人、专职管理、值班人员和稳定指导教师队伍（南理工X·Space要求）["https://xspace.njust.edu.cn/_upload/article/files/35/23/e96e1c1b4bcaafca1b8a382f80eb/55fa4bfb-04fc-4210-97e6-64665daece44.pdf"] |
| **周例会** | 负责人+学生TA每周复盘：维护、空间使用、升级、补货、低效点（Delaware模式）["https://files.eric.ed.gov/fulltext/EJ1255251.pdf"] |
| **年度考核** | 按条件建设、指导教师、开放、活动、成果五维度年度考核，优秀/合格/不合格三档（南理工）["https://xspace.njust.edu.cn/_upload/article/files/35/23/e96e1c1b4bcaafca1b8a382f80eb/55fa4bfb-04fc-4210-97e6-64665daece44.pdf"] |
| **动态调整** | 工作室分A/B类，不合格降级摘牌或整改撤销（南理工）["https://xspace.njust.edu.cn/_upload/article/files/35/23/e96e1c1b4bcaafca1b8a382f80eb/55fa4bfb-04fc-4210-97e6-64665daece44.pdf"] |

## 二、人员配置与职责

### 2.1 岗位配置模型（对标Fab Foundation + 职业院校实际）

| 岗位 | 配置 | 核心职责 | 来源 |
|------|------|---------|------|
| **运营负责人** | 1 | 全面管理、安全、预算、对外 | Fab Foundation 经理 |
| **技术管理员** | 1-2 | 设备维护、系统、网络、安全 | Fab Foundation 技术经理 |
| **专业指导教师** | 三专业各1+ | 课程、实训、竞赛指导 | 校方师资 |
| **值班员** | 开放时段1-2 | 值守、安全监督、基础指导 | 可聘学生 |
| **学生助理（TA）** | 6-15 | 分岗负责设备、材料、整理 | Delaware Minions |
| **实验室协调员** | 兼职 | 安全合规、设施 | Delaware 10%时间 |

### 2.2 学生助理（TA/勤工助学）体系

> Delaware"Minions"模式是低成本运营的关键：**约15名本科生TA按小时计酬，负责大部分日常事务**。["https://files.eric.ed.gov/fulltext/EJ1255251.pdf"]

**TA岗位分工（角色清单示例）**：

| 角色 | 职责 |
|------|------|
| 3D打印队列管理员 | 管理打印队列、维护打印机、接收提交 |
| 激光切割管理员 | 操作指导、维护、耗材管理 |
| CNC/机床管理员 | 安全监督、维护、操作考核 |
| 材料与库存管理员 | 补货、台账、领用登记 |
| 整理与5S专员 | 空间整理、清洁、归位监督 |
| 值班/引导员 | 开放时段值守、新人引导 |

**TA管理要点**：
- 公开招募（大二大三优先），按技能选拔
- 每学期初明确角色与职责文档，共同评审
- 每周例会同步维护/补货/低效问题
- 与学号绑定门禁权限，离职即回收
- 可纳入勤工助学/志愿服务学分（国内院校实践）

### 2.3 师生比与安全值守

| 场景 | 最小人员要求 |
|------|-------------|
| 正常教学 | 主讲1 + 助教1-2（40人班） |
| 高危操作（CNC/高压） | 师生比≤1:8，教师在场 |
| 开放时段 | 值班员1 + 安全负责人可远程响应 |
| 学生机器加工区 | 须有技师/管理员在场（Delaware：仅工作日8-17点开放）["https://files.eric.ed.gov/fulltext/EJ1255251.pdf"] |

## 三、开放管理

### 3.1 分级开放模型（借鉴Delaware + 国内实际）

| 层级 | 区域 | 开放方式 | 访问控制 |
|------|------|---------|---------|
| **L1 全开放** | 学习区、讨论区、电子区 | 全天候（8:00-22:00） | 门禁刷卡 |
| **L2 半开放** | 数字制造区（3D/激光） | 工作时间+TA在场时段 | 门禁+设备认证 |
| **L3 受控开放** | CNC、金属加工、高压区 | 仅预约+管理员在场 | 门禁+设备认证+预约 |
| **L4 封闭** | 材料库、工具库、危化品 | 管理员领用 | 双人领用 |

### 3.2 设备分级管控（Delaware经验）

> Delaware用**低成本方式**实现分级：部分设备（带锯、圆锯、台钻、砂轮机）用**线缆锁**锁定，TA在场时开锁，课后立即锁回——比昂贵门禁软件更灵活、成本更低。["https://files.eric.ed.gov/fulltext/EJ1255251.pdf"]

| 设备等级 | 管控方式 |
|---------|---------|
| 高危险设备（CNC/金属） | 线缆锁/钥匙锁 + 认证 + 管理员在场 |
| 中危险设备（激光/台锯） | 认证通过即解锁 + 排队系统 |
| 低危险设备（3D/焊台） | 开放使用 + 值班监督 |

### 3.3 门禁管理

- 门禁与学生/教职工ID绑定（国内校统一卡通）
- 权限分级：基础(全开放区)→认证(半开放)→预约(受控)
- 团队入驻/成员变更即时更新权限（湖南大学：与学号绑定门禁）["https://etet.hnu.edu.cn/info/1157/2928.htm"]
- 离职/毕业即回收权限，每学期清理一次

## 四、预约与排队系统

### 4.1 预约层级

| 对象 | 预约方式 | 机制 |
|------|---------|------|
| **课程** | 学期排课 | 教务处排课表，固定时段 |
| **团队/项目** | 线上预约 | 申请表+时长（1-12个月），3个工作日初审（湖南大学）["https://etet.hnu.edu.cn/info/1157/2928.htm"] |
| **设备（激光/CNC）** | 设备预约 | 按时段预约，防止冲突 |
| **3D打印** | 提交队列 | 在线提交文件，TA管理队列（Delaware Google Forms）["https://files.eric.ed.gov/fulltext/EJ1255251.pdf"] |
| **活动/工作坊** | 场地预约 | 提前申请，审批 |

### 4.2 预约管理要点

- 统一入口：可用"一网通办"式校园平台或独立预约系统
- 设备预约设**时长上限**（如单次≤3小时），保障公平
- 高噪音设备预约**自动叠加时段限制**（避开宿舍休息时段）
- 爽约率监控：连续爽约限制预约权限
- 预约数据反哺规划（哪些设备最缺、哪些时段最挤）

## 五、日常运营SOP

### 5.1 每日运营流程

```
开馆前（值班员/管理员）：
  ① 巡查安全（门窗/水电/消防通道）
  ② 设备状态检查（异常挂牌）
  ③ 补充耗材、整理工具归位
  ④ 打开开放区门禁

运营中：
  ⑤ 接待与引导新人
  ⑥ 监督安全操作、设备使用登记
  ⑦ 处理预约/排队/领用

闭馆前：
  ⑧ 设备关闭、断电、清理
  ⑨ 工具清点、材料盘点
  ⑩ 安全复查、锁门、填写日志
```

### 5.2 高频SOP清单（每项上墙）

| SOP | 要点 |
|-----|------|
| 设备开机/关机 | 启动步骤→常见故障→关机清理（柴火指南第20章） |
| 新人准入 | 安全培训→考核→认证→建档 |
| 材料领用 | 登记→限量→归位 |
| 工具借还 | 押证/登记→归还检查→丢失追责 |
| 事故报告 | 记录→复盘→改SOP→公示 |
| 设备报修 | 挂牌→登记→报修→验收 |

### 5.3 周/月/季节奏

| 周期 | 事项 |
|------|------|
| **每周** | 负责人+TA周例会、工具盘点、设备巡检 |
| **每月** | 设备维护日（社区清洁日合并）、安全巡检、材料补货、使用数据统计 |
| **每学期** | 全面盘点、耗材采购、培训认证更新、优秀团队评选 |
| **每年** | 年度考核、设备报废评估、预算编制、A/B类评定 |

## 六、使用统计与数据监控

### 6.1 核心运营指标（参考MakeHaven仪表盘）

> MakeHaven创客空间公开数据仪表盘是标杆：工作坊出席人数（近12个月712人）、工作坊容量利用率58%、项目容量利用率69%。["https://www.makehaven.org/makerspace-dashboard/overview"]

| 指标 | 定义 | 用途 |
|------|------|------|
| **到访人次** | 周期内进空间人次 | 总人气 |
| **设备使用率** | 设备被使用时长÷可用时长 | 设备配置合理性 |
| **空间利用率** | 使用人时÷可用人时 | 空间规模合理性 |
| **认证通过数** | 完成安全认证人数 | 用户增长 |
| **课程/活动场次** | 周期内教学与活动数 | 运营活跃度 |
| **材料消耗** | 耗材领用量 | 预算与需求 |
| **事故/近失** | 安全事件数 | 安全水平 |
| **成果数** | 作品/竞赛获奖/项目数 | 育人成效 |

### 6.2 数据采集方式

| 数据 | 采集方式 |
|------|---------|
| 到访 | 门禁刷卡记录 |
| 设备使用 | 设备开关机日志/预约系统/手动登记 |
| 空间利用 | 门禁分区统计 + 人工抽样 |
| 材料 | 领用登记台账 |
| 安全 | 事故/近失报告（匿名） |
| 成果 | 作品登记、获奖汇总、项目档案 |

### 6.3 数据驱动的决策

- **季度分析**：哪些设备闲置→考虑置换/共享；哪些时段爆满→延长开放/扩容
- **空间利用率>70%**→启动分期扩建评估；<40%→审视需求与运营
- **成果数据**→年度考核与预算申请的依据

### 7.1 年度预算结构（参考Delaware + Fab标准）

| 科目 | 占比参考 | 说明 |
|------|---------|------|
| 材料/耗材 | 40-50% | 木料、线材、打印耗材、电子件 |
| 人力（TA/值班） | 20-25% | 学生助理、兼职值班 |
| 设备维护 | 20-25% | 保养、维修、备件 |
| 水电物业 | 5-10% | 视校方承担情况 |

> Delaware $50k/年运营参考：材料50%、人力25%、维护25%。["https://files.eric.ed.gov/fulltext/EJ1255251.pdf"]

### 7.2 资金来源组合（职业院校场景）

| 来源 | 说明 |
|------|------|
| 学校运营经费 | 按年度考核结果浮动（南理工：经费与级别、考核、活动、育人成效挂钩）["https://xspace.njust.edu.cn/_upload/article/files/35/23/e96e1c1b4bcaafca1b8a382f80eb/55fa4bfb-04fc-4210-97e6-64665daece44.pdf"] |

- 每学期财务对账公示
- 报废设备走正规手续，收益入账

## 八、5S/7S现场管理

> 7S（整理、整顿、清扫、清洁、素养、安全、节约）是国内职业院校实训室管理的**标配制度**，与创客空间的"影子板/工具墙"（见[工具组织与现场管理.md](../03-设备与工具/工具组织与现场管理.md)）互补。["https://www.dyxy.edu.cn/attachment/sites/item/2022_06/25_16/3c1c8b112dc8280d.pdf"]

| S | 实训室落地要点 |
|---|---------------|
| **整理** | 必需与非必需区分，非必需坚决清走 |
| **整顿** | 定位定量：工具/量具分类标示、通道划线、按使用频率放置 |
| **清扫** | 设备清洁、工作台面清理、地面无油污 |
| **清洁** | 制度化维持前三S，检查标准可视化 |
| **素养** | 设备台账账物相符、学生实训守则、行为规范 |
| **安全** | 隐患排查、设备完好率、应急预案 |
| **节约** | 材料用量控制、设备待机断电、耗材领用登记 |

**落地工具**：
- 通道划线、区域标识、设备状态牌（可用/维修/停用）
- 每台设备一张"设备卡"（照片+操作要点+责任人）
- 每周二/四固定安全卫生检查日（多校做法）
- 检查评分表上墙，纳入班级/团队考核

## 九、激励与考核体系

### 9.1 对团队/学生的激励（借鉴湖南大学）

| 激励 | 做法 |
|------|------|
| **项目孵化资金** | 阶段性成果、市场前景好的团队给予支持 |
| **投资对接** | 对接校内外投资机构、天使投资人 |
| **优秀团队评选** | 年度评选、表彰、优先推荐参赛 |
| **荣誉认证** | 设备认证证书、技能证书、志愿时长 |

> 湖南大学：入驻团队须提交创新项目、宽进宽出、出勤率考核、损坏赔偿。["https://etet.hnu.edu.cn/info/1157/2928.htm"]

### 9.2 对空间的年度考核（借鉴南理工）

| 考核维度 | 指标 |
|---------|------|
| 条件建设 | 设备完好率、设施完备度 |
| 指导教师 | 教师投入、指导质量 |
| 开放度 | 开放时长、到访人次、预约满足率 |
| 活动开展 | 工作坊、竞赛、讲座场次与质量 |
| 成果 | 竞赛获奖、作品数、项目孵化、学生评价 |

> 南理工：考核结果分优秀/合格/不合格三档，与运行经费、A/B类评级、是否摘牌直接挂钩。["https://xspace.njust.edu.cn/_upload/article/files/35/23/e96e1c1b4bcaafca1b8a382f80eb/55fa4bfb-04fc-4210-97e6-64665daece44.pdf"]
