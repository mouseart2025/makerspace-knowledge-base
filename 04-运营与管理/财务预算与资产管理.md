# 创客空间财务预算与资产管理

> **本文是什么**：一份面向创客空间/实训室的**财务与资产操作规范**——把"钱从哪来、怎么花、设备怎么入账、怎么报废、年度怎么决算、审计看什么"讲成可执行的流程与表格。
> **为什么需要**：创客空间是**重资产、多品类、快迭代**的场所——单台设备从几百元的开源硬件到数十万元的工业机器人不等；耗材消耗快、报废周期短；既有财政资金也有企业捐赠和对外服务收入。**如果没有分类台账与预算纪律，会出现三类典型问题**：设备"买来就找不到"、耗材"用超了没人知道"、到了审计时"账、卡、物对不上"。
> **口径说明（重要）**：本文引用的是**公开的会计与资产管理一般原则**；但**具体会计科目、折旧年限与残值率、固定资产单价标准、政府采购限额与公开招标门槛、地方财政的具体要求**，**各单位与各地差异很大，必须由本单位财务处/资产管理部门人工复核后执行**。本文不构成财务或审计意见。
> **脱敏声明**：本文不含任何真实单位名称、真实金额、真实合同编号或本地路径；出现的价格一律标注为"区间/估算锚点"，具体采购以实际招标与预算批复为准。

---

## 一、钱的三个方面：预算、核算、资产

创客空间的财务工作常被简化成"报个预算、买买东西"，实际是三条线并行：

| 线 | 回答的问题 | 关键输出 | 责任岗位 |
|----|-----------|---------|---------|
| **预算线** | 明年需要多少钱、花在哪些类别 | 年度预算表（收入/支出分项） | 空间负责人 + 财务对接人 |
| **核算线** | 钱实际花到哪了、科目对不对 | 记账凭证、费用报销、决算表 | 财务处/会计 |
| **资产线** | 买了什么、现在在哪、状态如何、值多少 | 资产台账、卡片、盘点记录、报废单 | 资产管理员 |

> ★ **核心结论**：三者必须**同一套编码**打通。设备采购时的"资产编号"，应当同时出现在：预算表的支出明细、发票与凭证的备注、资产台账、设备管理系统、盘点表、报废单。**编码不统一的组织，盘点必然失真。**

## 二、收入侧：钱从哪来、怎么记

创客空间的收入来源通常比一般教学单位更杂，**必须按"资金性质"分账**，因为它们的预算、使用与审计规则不同。

| 资金性质 | 典型来源 | 使用限制 | 记账要点 |
|---------|---------|---------|---------|
| **财政拨款/专项经费** | 上级拨款、项目专项、双高/实训基地建设资金 | 专款专用，按批复科目与进度使用 | 独立项目号，**不得挪用**；支出须符合专项要求 |
| **学校自筹/公用经费** | 学校预算内安排 | 按学校财务制度 | 常规科目 |
| **企业投入/捐赠** | 企业资助设备、材料、奖学金 | 依捐赠协议或合作合同 | 明确是否指定用途、是否需单独核算 |
| **对外服务收入** | 研学、培训、技术服务、空间租赁 | 依单位创收管理办法，可能涉及上缴与分配比例 | 与 [对外服务与科普研学运营.md](对外服务与科普研学运营.md) 的定价体系统一核算 |
| **项目/横向课题经费** | 企业委托开发、科研课题 | 按合同预算与科研经费管理办法 | 与 [作品权属与知识产权管理.md](作品权属与知识产权管理.md) 合作条款联动 |
| **会员/工位/活动收费** | 社会会员、工位出租、工作坊 | 依单位制度 | 关注是否需纳入"收支两条线" |
| **上级竞赛/活动补助** | 赛事承办、专项活动 | 按文件要求 | 单独核算、按时结题 |

**三条纪律**：

1. **专款专用**：专项经费用于非专项事项，是审计的高频问题点——**预算调整需走审批，不要"先花后补"**；
2. **收入不设"小金库"**：任何收费（含零星活动费）都应进入单位账户或按规定渠道，**禁止以个人账户代收**；
3. **捐赠与配套设施要区分**：企业捐赠设备的**所有权转移**与"借用/展示"是两回事，前者入台账，后者登记借用协议。

## 三、支出侧：五类支出与配比参考

| 支出类别 | 内容 | 占比参考（经验估计，非标准） | 备注 |
|---------|------|--------------------------|------|
| **设备购置** | 主机设备、工具、仪器、工作站 | 一次性建设期占大头（60–75%） | 分期采购要留升级空间 |
| **耗材与易损件** | 3D 打印耗材、木材、电子元件、刀具、防护用品 | 年运营的 10–20% | **最易被低估**；与开班量正相关 |
| **维护与维修** | 保养、校准、配件更换、外委维修 | 年运营的 5–10% | 应按设备原值的固定比例预留 |
| **人员与培训** | 兼职导师、师资培训、外部专家 | 年运营的 10–20% | 与 [师资队伍建设专项.md](师资队伍建设专项.md) 联动 |
| **运营杂项** | 水电、网络、软件订阅、保险、活动物料 | 年运营的 5–15% | 软件订阅是近年增长较快项 |

**预算编制四步**：

1. **按"设备—耗材—维护—人员—杂项"五类列支**，不要只做一张总表；
2. **耗材按开班量测算**：单班耗材成本 × 预计班次 = 年耗材预算（比按面积或人数拍脑袋可靠）；
3. **维护按原值比例预留**：建议**不低于设备原值的 3–5%/年**（含校准与易损件，经验估计）；
4. **留不可预见费**：建议总预算的 **5–10%**，用于设备涨价、紧急维修、政策变化。

> ⚠️ **最常见的预算失误**：**只预算买设备，不预算养设备。** 一台 30 万元的设备，若每年维护与耗材不预留，三年后的实际使用成本可能超过购置价的一半。**预算表里没有"养"的钱，设备就会沦为摆设。**

## 四、设备资产全流程：从立项到报废

| 阶段 | 关键动作 | 产出物 | 常见错误 |
|------|---------|--------|---------|
| **1 立项/论证** | 需求论证、必要性、场地与配套条件（电、气、承重、网络）、全生命周期成本测算 | 立项论证表 | 只看采购价，不看安装/维护/耗材成本 |
| **2 预算与采购** | 编制预算、确定采购方式（政府采购/招标/询价/框架协议） | 采购申请、预算批复 | 拆分采购规避招标门槛 |
| **3 采购执行** | 招标/询价、合同签订、履约跟踪 | 合同、中标通知 | 合同未写验收标准与质保条款 |
| **4 到货验收** | 开箱验货、安装调试、性能测试、培训、资料交接 | 验收单、资产卡片、技术档案 | 验收走过场，缺陷留到使用期才暴露 |
| **5 入账建卡** | 编号、贴标签、录入台账与设备系统、确定折旧参数 | 资产台账、资产卡片 | 标签缺失/重复；台账与系统不同步 |
| **6 领用与使用** | 领用登记、责任人、使用记录、准入培训 | 领用单、使用日志 | 责任人不明；设备"共享"变成"失联" |
| **7 维护保养** | 定期保养、校准、故障维修、备件管理 | 维护记录、校准证书 | 无保养计划；维修记录不归档 |
| **8 调拨/借用** | 内部调拨、外部借用需协议 | 调拨单、借用协议 | 借用无期限、无归还验收 |
| **9 盘点** | 定期盘点（建议每学期/每年至少一次），账卡物三相符 | 盘点表、差异说明 | 只盘数量不盘状态与位置 |
| **10 报废处置** | 技术鉴定、审批、残值处理、数据擦除、台账销账 | 报废单、处置记录 | 未擦除存储介质；残值收入不入账 |

**账、卡、物三相符（核心纪律）**：

| 项 | 含义 | 检查方式 |
|----|------|---------|
| **账** | 财务/资产系统的账面记录 | 系统导出清单 |
| **卡** | 每台设备的资产卡片（含编号、规格、责任人、存放位置） | 现场卡片 vs 系统记录 |
| **物** | 实际存在的设备实体 | 现场清点 + 状态核对 |

> ★ **三相符不是"数量对得上"就够**——还要**位置对、状态对、责任人对**。审计时的典型问题正是"数量对得上，但三台设备早已损坏停用、两台被借走未登记"。

## 五、折旧：怎么算、怎么用

折旧不是"设备贬值了心里有数"，而是**有会计规则、影响后续预算与报废决策的参数**。

| 概念 | 说明 |
|------|------|
| **原值** | 购置价 + 相关税费 + 运输安装调试费等达到可用状态前的支出 |
| **预计使用年限** | 依单位会计政策与设备类别确定（**具体年限须由本单位财务确认**） |
| **残值率** | 报废时可回收价值占比，通常较低（**须按单位政策**） |
| **折旧方法** | 常用直线法（年限平均法）：年折旧 =（原值 − 残值）÷ 使用年限 |
| **累计折旧** | 已计提的折旧总额 |
| **净值** | 原值 − 累计折旧 |

**折旧的三项实际用途**：

1. **预算依据**：为设备更新周期预留资金；
2. **报废判据**：当"年维修成本 > 年折旧额"且设备故障频繁时，进入更新评估（与 [../03-设备与工具/设备全生命周期管理与信息化.md](../03-设备与工具/设备全生命周期管理与信息化.md) 的报废判据衔接）；
3. **成本核算**：计算单班/单项目的设备使用成本，支撑对外服务定价。

**更新决策表（可直接使用）**：

| 指标 | 计算 | 判据 |
|------|------|------|
| 年维修成本 | 近 12 个月维修支出 | —— |
| 年折旧额 | （原值 − 残值）÷ 年限 | —— |
| 维修/折旧比 | 年维修成本 ÷ 年折旧额 | **> 1 且持续上升** → 优先考虑更新 |
| 停机影响 | 年停机小时数 / 影响课时 | 影响教学连续性 → 优先考虑更新 |
| 技术落后度 | 是否无法支撑现有课程/赛项 | 已无法支撑 → 必须更新 |

> ⚠️ **注意**：**折旧年限与残值率各地各校政策不同**，本文不给出具体数字，避免"照抄错误参数"。请以本单位财务与资产管理制度为准。

## 六、耗材管理：最容易失血的地方

耗材的特点是**单价低、频次高、易损耗、难盘点**，是财务漏洞的高发区。

| 环节 | 做法 | 工具 |
|------|------|------|
| **采购** | 按学期集中采购 + 少量应急采购；建立常用耗材目录与供应商 | 采购清单、比价记录 |
| **入库** | 验收数量与规格，登记批次与保质期 | 入库单、耗材台账 |
| **领用** | 按课程/项目领用，登记使用人 | 领用单、二维码/系统 |
| **消耗核算** | 单班耗材成本 = 领用量 × 单价；按课程统计 | 成本统计表 |
| **安全库存** | 设定最低库存告警线（建议保持 1–2 周用量） | 库存预警 |
| **盘点** | 每月抽盘、每学期全盘；差异要说明原因 | 盘点表 + 差异分析 |
| **危废与过期** | 过期/失效耗材单独处置；危废按环保要求 | 处置记录（与 [../03-设备与工具/车间与创客空间安全-危害分级与设备防护-专题补充.md](../03-设备与工具/车间与创客空间安全-危害分级与设备防护-专题补充.md) 危废流程衔接） |

## 七、政府采购与合规要点

| 事项 | 要点 | 风险 |
|------|------|------|
| **采购方式** | 公开招标 / 邀请招标 / 竞争性谈判 / 询价 / 单一来源 / 框架协议——**按金额门槛与项目性质确定** | 方式选错导致程序违法 |
| **限额标准** | **公开招标数额标准、分散采购限额标准各地不同**，以本地财政部门规定为准 | 照搬外地标准 |
| **禁止拆分** | 不得将应招标项目拆分为多个小额采购规避招标 | 审计重点 |
| **需求参数** | 不得以不合理条件限制或排斥潜在供应商（如指定独家品牌型号） | 被质疑、投诉 |
| **进口设备** | 需符合进口产品管理规定与论证程序 | 程序缺失 |
| **合同管理** | 明确交付、验收、质保、付款节点、违约责任 | 尾款纠纷 |
| **履约验收** | 成立验收组、按合同技术参数逐项核验 | 走过场 |
| **信息公开** | 按规定公开采购意向、公告、结果 | 程序瑕疵 |

**采购合规五问（每次采购前问）**：

1. 这笔采购在**预算内**吗？科目对不对？
2. 金额是否**达到须招标/须上平台**的门槛？
3. 需求参数**是否指向特定品牌**（限制竞争）？
4. 有无**关联方**参与（需回避）？
5. **验收标准**在合同里写清了吗？

## 八、年度决算与绩效评价

| 环节 | 时间 | 内容 |
|------|------|------|
| **预算执行跟踪** | 季度 | 对照预算看执行率；偏差 > 20% 的科目分析原因 |
| **年末清理** | 年末前 | 清理暂付款、盘点资产、核对耗材、催收应收（若有） |
| **决算编制** | 按单位时间 | 收入/支出/结转结余，按资金性质分列 |
| **绩效自评** | 决算同期 | 对照绩效目标：产出指标（开班数、人次、设备完好率）、效益指标（利用率、满意度、成果转化） |
| **审计配合** | 按安排 | 提供凭证、台账、合同、验收单、盘点记录 |

**绩效指标建议（与 [职业院校创客实验室绩效评估与产教融合.md](职业院校创客实验室绩效评估与产教融合.md) 对齐）**：

| 维度 | 指标示例 |
|------|---------|
| 投入 | 预算执行率、设备到位率 |
| 产出 | 开班数、培训人次、作品数、设备完好率 |
| 效果 | 空间利用率、学生/教师满意度、竞赛获奖、成果转化数 |
| 可持续 | 对外服务收入占比、企业投入、耗材单位成本趋势 |

> ★ **一句话**：**决算不是"把账平了"，而是回答"钱花得值不值"。** 没有绩效指标，决算就只是数字汇总。

## 九、资产盘点操作手册

**盘点前**：打印台账清单、准备盘点表与标签、锁定台账变更（盘点期间不调拨）、通知责任人现场配合。

**盘点中**：

| 项 | 动作 |
|----|------|
| 数量 | 逐台清点，不遗漏、不重复 |
| 位置 | 核对存放地点（房间号/工位） |
| 状态 | 在用 / 闲置 / 维修中 / 待报废 / 已停用 |
| 责任人 | 核对使用人或保管人 |
| 标签 | 编号清晰可读；破损补打 |
| 附件 | 配件、说明书、校准证书是否齐全 |

**盘点差异处理**：

| 差异类型 | 处理 |
|---------|------|
| 有物无账 | 查明来源，补建卡片或按盘盈处理 |
| 有账无物 | 追溯借用/调拨/丢失，出具说明并追责或销账 |
| 账物不符（数量） | 复核清点，修正台账 |
| 位置不符 | 更新台账位置字段 |
| 状态不符 | 更新状态，触发维修或报废流程 |

**盘点后**：出具盘点报告（含差异说明与整改责任），更新台账与设备管理系统，作为决算与审计材料归档。

## 十、审计常查的十项

| # | 审计关注点 | 自查方法 |
|---|-----------|---------|

## 十二、常见坑

| # | 坑 | 后果 | 纠正 |
|---|----|------|------|
| 1 | 只预算买设备，不预算养设备 | 设备闲置/失修 | 维护 + 耗材按比例预留 |
| 2 | 不设资产编号或编号不统一 | 盘点失真、责任不清 | 一套编码贯穿全流程 |
| 3 | 验收"看外观签字" | 缺陷在使用期爆发 | 按合同参数逐项测试 |
| 4 | 耗材"谁用谁拿" | 成本失控、无法定价 | 领用登记 + 单班成本核算 |
| 5 | 为避招标拆分采购 | 审计问题 | 按限额合并采购 |
| 6 | 报废不擦除存储介质 | 数据泄露 | 报废前数据销毁留痕 |
| 7 | 借用无期限、无归还验收 | 设备失联 | 借用协议 + 归还验收 |
| 8 | 决算只平账不做绩效 | 无法证明值不值 | 建立绩效指标 |
