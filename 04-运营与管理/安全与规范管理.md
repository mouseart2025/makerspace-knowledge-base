# 安全与规范管理

> "安全：不伤害人或机器。" —— Fab Charter 第一条用户责任
> 调研时间：2026-08

## 一、安全哲学：开放与安全的平衡

**欧洲经验的两端教训**：
- 规则太严 → 用户被吓退，实验欲被扼杀
- 规则太松 → 事故、设备损坏、运营方法律责任

**破局之道**：**共享责任文化**——有经验的会员（Key Member / "Paten 教父"）引导新人并监督规则执行，而不是靠管理员单方面管制。

**伯克利经验（Joey Gottbrath）**：
> "不要因为设备可能损坏就限制使用——那是次要问题。鼓励人们学会安全地使用它们。简化你的系统，让说明和流程容易理解，你就能砸碎使用门槛。"

## 二、安全制度四件套

### 2.1 分层准入培训（设备认证制）

```
基础安全培训（全员必过）
   ├── 激光切割认证 → 解锁激光区
   ├── 3D 打印认证 → 解锁打印机
   ├── 木工机械认证 → 解锁木工区
   ├── 电子/焊接认证 → 解锁焊台
   └── 高危设备（CNC/水刀）→ 一对一考核后解锁
```

### 2.2 SOP（标准操作程序）

柴火《创客空间搭建及运营指南》第 20 章专题："创建和使用 SOP"。要点：
- 每台关键设备一张 SOP 卡（贴设备旁）：启动步骤 → 常见故障 → 关机清理
- SOP 由使用者共同维护（宪章"协助改进实验室"责任）
- 新人教学用 SOP，而不是口口相传

### 2.3 标识系统（Signage）

- 区域标识：噪音区 / 安全区 / 潮湿区 / 数字区
- 设备状态牌：可用 / 维修中 / 停用
- 警示标识：激光、高温、旋转刀具、锂电池充电区

### 2.4 应急预案

- 灭火器（干粉/CO₂ 分区配置，激光区必配）+ 烟雾报警
- 急救箱 + 附近医院信息上墙
- 事故报告流程（记录 → 复盘 → 改 SOP）
- 定期演练（Emergency Preparedness）

## 三、空间级安全设计（硬件层）

| 措施 | 说明 |
|------|------|
| **通风与排气** | 激光切割/焊接/喷涂区机械通风不可妥协；激光机配烟雾净化器（滤芯寿命预警）|
| **激光安全** | 安全门联锁（开门即停）、Class1 防护、高温/燃烧探测报警 |
| **锂电池防爆** | 专用充电防爆箱——创客项目大量锂电池，爆燃范围限于箱内（科普场馆方案标配）|
| **粉尘控制** | 木工区工业吸尘（Festool CTL 系列）、防爆灯 |
| **PPE 库存** | 护目镜、手套、防尘口罩、耳罩放置于易取处 |
| **电源管理** | 教学区下垂式电源（可收起）；设备分区断电开关 |
| **防火分区** | 明火/高温作业与其他区域隔离；材料阻燃存储 |
| **地面处理** | 陶艺/水槽区防水处理 |

## 四、责任与法律工具（柴火指南附件全套范本）

柴火《创客空间搭建及运营指南》附件提供**中文化全套法律模板**（源自 Makerspace Playbook）：

| 模板 | 用途 |
|------|------|
| **责任豁免书范本**（p.190）| 会员签署，明确自担风险 |
| **展品安全计划范本**（p.194）| 展出作品的电气/结构安全自检 |
| 导师申请表范本（p.191）| 导师筛选 |
| 项目计划范本（p.192）| 高风险项目报备 |
| 成员/导师"工作内容描述"范本（p.186-187）| 角色权责界定 |

**保险与合规清单**：
- 公众责任险（Public Liability）——开放日的法律底线
- 财产险（设备）
- 消防验收与安全检查合规
- 营业执照/民办非企业/其他法律实体形式选择（非营利/合作社/公司制各有优劣，需咨询当地法律人士）
- 未成年人参与：监护人知情同意书

## 五、中国情境特别注意

1. **"创客教室"与"生产车间"的消防标准差异**——教育培训场所与工业场所审批口径不同，装修前与消防部门确认用途定性
2. **政府/学校主办空间的双重束缚**：国有资产保值要求 vs 设备开放使用损耗——需要在制度上写明"教学损耗"的合法性，避免"怕坏锁设备"死循环
3. **锂电池**是国内创客项目（机器人、无人机、iot）最常见火源，防爆充电箱应列为**强制标准件**
4. **参观动线与作业动线分离**（科普场馆方案）：公众参观的透明走廊不进入作业区，防止误触

## 六、工程级安全参数速查（硬件层定量依据）

> 来源：CLEAPSS G014《实验室设计与规划》（详见 [../02-空间搭建/实验室工程参数-G014-专题补充.md](../02-空间搭建/实验室工程参数-G014-专题补充.md)）。英标条款国内落地须对照 GB 与当地消防口径，**数量级可直接复用**。

| 系统 | 硬参数 |
|------|--------|
| **配电** | 学生工位环路可在教师区一键切断；RCD 漏保 30mA/30ms；≥2 条独立 30A 环形电路；通风柜/大功率设备**独立电路**（学生断电时不得连带停机）|
| **燃气**（若有）| 入口机械切断阀或教师区电磁阀按钮（远离学生门）；防意外开启阀（拉转式）；Liverpool 防转板 |
| **易燃品** | 酒精/丙酮/喷漆等高度易燃液体 ≤50L 专用阻燃柜（30 分钟耐火、紧固件熔点 >750°C、内溢可收）；通风 2 次/小时、开关外置、避免西晒 |
| **给排水** | 每槽防虹吸瓶式存水弯（可清出异物）；插座远离水源，低置必须防溅+遮檐 |
| **环境** | 工坊/实验室通风 ≥6 次/小时；一般照明 300 lux + 精细区局部照明 |
| **消防** | 每间 2×2kg CO₂ 灭火器 + 1 灭火毯，置教师/管理员区旁（不靠学生门）；设计早期做消防评估定第二出口 |
| **急救** | 优先管道式洗眼器；用洗眼水槽时旁置可躺卧台面 |
| **储运** | >10kg 重物存放高度 800–1100mm（黄金高度带）；层架 ≤2000mm；每教室 2 台手推车（一送一收）|

## 七、安全文化的日常运营

- **入职三件事**：安全培训 → 豁免书 → 认证记录归档
- **每月设备巡检日**（社区清洁日合并举办）
- **事故近失（Near Miss）报告制**：没出事但差点出事也要记录，社区匿名提交
- **"安全灯塔"角色**：指定安全负责人，出席社区活动，让安全有面孔而非只是规则
- **把安全做成社区荣誉**：连续无事故月份公示、安全之星致谢
