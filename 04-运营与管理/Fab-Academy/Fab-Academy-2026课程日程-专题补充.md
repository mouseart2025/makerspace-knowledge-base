## 三、模块进阶逻辑（八阶段递进）

```
① 奠基（W1-2）     理念与记录：Principles → Project Management → CAD
                    ← 核心：先建立"记录与文档化一切"的习惯
② 数字制造入门（W3-5）2D 切割 → 嵌入式编程 → 3D 打印/扫描
③ 电子技术主线（W6,8-11）电子设计 → 电子生产 → 输入(感知) → 输出(执行) → 联网
                    ← 完整"感知-处理-执行-联网"嵌入式闭环
④ 大型制造与机械（W7,12）CNC 大型铣削；团队协作造机器
⑤ 中场检查点（W13）期中评审
⑥ 综合与扩展（W14-17）模塑铸造 → 界面编程 → 系统集成 → Wildcard 自选
⑦ 收尾与转化（W18-19）项目立项 → 开发计划 → 知识产权与商业化
⑧ 成果输出：6 月答辩 → 7 月 FAB26 展示
```

**设计的巧妙处**：
- **电子三件套分离**：Design（W6）与 Production（W8）隔两周——中间插入大型制造，让"设计→生产"有沉淀间隔，而非连续赶工
- **评估不打断教学**：期中评审放在 Break 周（W13），不占用任何模块周
- **软硬双轨**：周三硬核技术课 + 隔周周一软性专题（版本控制/AI/可持续/机器构建/Fab 生态/教育/创业），体现"技术 + 社区 + 商业"完整培养观

## 四、Recitation 专题体系（软性双轨）

| 专题 | 周次 | 价值 |
|------|------|------|
| Version Control | W2 | 文档管理基本功（与 W1 建站呼应）|

| Education | W15 | 教育专题 |
| Fab All-In | W17 | 综合专题 |
| Start-ups | W19 | 创业（与商业化模块衔接）|

> 对柴火：Recitation 是**可借鉴的双轨模式**——硬课之外配软性专题，成本低（隔周一次）但极大丰富课程生态位。训练营/工作坊可复制为"主课 + 主题分享"双轨。

## 五、评估体系线索（日程页透露）

| 机制 | 说明 |
|------|------|
| **每周评审** | 每个模块配 review 视频链接——每周作业有专门评审环节 |
| **区域评审** | "global lab sections and regional reviews are scheduled throughout the week"——全球分组 + 区域性评审分布在一周内 |
| **期中评审** | 04-15（Break 周内）|
| **最终答辩** | 06-08~06-12 连续 5 天，每天独立视频记录 |
| **展示平台** | finalprojects.fabacademy.org 往届作品存档 |

> 两段式评估（期中 + 期末）且都不占用教学周——时间管理上的细节值得所有长周期课程借鉴。
