# 实训室安全与应急预案专项

> 调研时间：2026-08-30 ｜ 说明：针对创客空间/实训室（尤其宿舍楼内高价值设备场景）的安全体系与应急预案。含风险矩阵、分设备安全 SOP、PPE 采购清单、应急预案模板、责任体系。
> 来源：应急管理部《熔化焊接与热切割作业考试点设备配备标准》、焊接/激光焊接官方安全指引、职业院校公开安全管理制度。

## 二、分设备安全 SOP

### 2.1 激光切割机

1. **上机前**：佩戴滤激光波长护目镜；检查排气/集尘是否开启；确认材料可切割（禁 PVC/金属反光超限）
2. **作业中**：全程留人监护；严禁打开防护罩运行；保持工作区无易燃物
3. **紧急**：立即按急停 → 关闭激光 → 确认无明火
4. **维护**：每日清渣、每周清洁镜片、定期校准

### 2.2 焊接作业

**风险分级（官方安全指引）**：
- 手工电弧焊 → 触电为主
- CO₂/二保焊密闭空间 → CO/烟尘中毒
- 氩弧焊 → 放射性粉尘（钍钨极打磨，优先用铈钨极）、强紫外线
- 点焊 → 夹手截指

**SOP**：
1. 必须持特种作业证（或教师全程监护下的教学演练）
2. 动火作业：清理易燃物、办动火证、设监护人、备灭火器
3. 穿戴：阻燃焊工服 + 变光面罩（滤光片）+ 耐高温手套 + 劳保鞋 + 防尘口罩
4. 焊机：机壳有效接地、一次线≤5m、二次线绝缘、禁止用金属结构当地线、装二次空载自动断电装置
5. 气瓶：固定、远离热源、胶管密封、禁曝晒

### 2.3 CNC / 木工 / 打磨

1. 护目镜/面屏 + 防尘口罩 + 集尘系统
2. **旋转设备严禁戴手套操作**（防卷入）
3. 工件夹紧牢固、急停可用、禁超规格切削
4. 木工粉尘：湿式作业 + 集尘 + 禁止明火

### 2.4 锂电池充电

1. 充电区隔离：**锂电池充电防爆箱**（如科普场馆档案配置）
2. 温控监测、禁过充、禁满电长期存放、禁混充不同品牌
3. 充电时留人、周围无易燃物
4. 热失控征兆（鼓包/异味/高温）：断电、移至空旷、专用灭火器

### 2.5 3D 打印 / 化学品

- FDM：通风良好，ABS 需强制通风
- SLA：防烫手套 + 护目镜 + 树脂密封保存 + 通风
- 化学品：MSDS 上墙、分类存放、防护手套、禁混放

## 四、应急预案模板

### 4.1 火灾

1. 立即断电 → 就近灭火器扑救（初起）
2. 火势失控：按下手动报警 → 疏散（弯腰、湿毛巾）→ 集合点清点人数
3. 锂电池火：使用专用灭火器/沙土，勿用水
4. 报 119 并说明位置与危险源

### 4.2 触电

1. **先断电**（拉闸/绝缘物挑开电线），严禁徒手拉拽
2. 断电后立即评估：无呼吸心跳 → 心肺复苏（CPR）+ AED
3. 同步拨打 120，送医

### 4.3 机械伤害

1. 立即急停/停机
2. 止血包扎（按压/绷带）
3. 断指/严重创伤：保护残肢（干净袋装、低温保存）、速送医
4. 报 120

### 4.4 化学品泄漏

1. 撤离无关人员、通风
2. 按 MSDS 处置（吸附/中和/回收）
3. 皮肤/眼睛接触：大量清水冲洗（洗眼器 15 分钟）→ 就医

### 4.5 锂电池热失控

1. 立即断电、移出热源
2. 专用灭火器/沙土覆盖
3. 移至室外空旷区隔离
4. 观察至完全冷却（防复燃）

### 4.6 应急演练计划

| 类型 | 频次 | 内容 |
|------|------|------|
| 消防疏散演练 | 每学期 1 次 | 报警/疏散/灭火器实操 |
| 急救演练 | 每学期 1 次 | CPR/AED/止血包扎 |
| 专项演练 | 每年 1 次 | 锂电池火、化学品泄漏 |
| 安全准入培训 | 每学期 | 培训→考核→发证→方可预约使用 |

## 五、安全责任体系

- **三级责任书**：学校（院级）→ 实训室负责人 → 使用者，每学期网签
- **安全准入**：在线安全培训 + 考核 + 发证，未通过不得进入高危险区
- **日常巡检**：每日巡检（设备/电源/通风/灭火器）、每周深度检查、每月专项
- **上报制度**：对接教育部实训室安全年度报告（数据自动采集）

## 六、宿舍楼场景特别提醒

若实训区位于宿舍楼/教学楼上，额外关注：
1. **降噪减振**：重型设备（CNC/木工/激光）置于楼板减振层（浮动地台），避开休息时段
2. **激光/焊接排气**：独立排风 + 过滤，避免烟气倒灌
3. **锂电池**：充电区远离宿舍，设防爆箱与温控
4. **消防通道**：疏散路线保持畅通，夜间接入门禁监控
