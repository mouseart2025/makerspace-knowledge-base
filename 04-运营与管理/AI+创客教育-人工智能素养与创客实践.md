## 一、政策导向（2026战略级）

> 教育部等五部门《"人工智能+教育"行动计划》(2026.4)：到2030年人工智能与教育深度融合格局基本形成；推动人工智能成为高校公共基础课；职业教育传统专业智能化升级；打造**未来课堂、未来学校、未来学习中心、未来实训中心**。["https://www.gov.cn/zhengce/zhengceku/202604/content_7065138.htm"]

**关键信号（对本项目的意义）**：
1. 职业教育传统专业（智能制造/新能源）需**智能化升级**——创客空间是"AI+专业"融合的载体
2. "未来实训中心"是政策重点——创客空间可申报/定位为AI实训与创客实践融合空间
3. 人工智能高技能人才集群培养计划——与产教融合联动
4. 教师智能素养纳入标准与考核——教师培训是配套刚需

## 二、AI素养框架

### 2.1 "感知-理解-思辨-创造"螺旋进阶（通识教育研究共识）

| 阶段 | 内容 | 创客实践对应 |
|------|------|-------------|
| **感知** | AI体验、智能应用认知 | 体验AI应用、智能设备 |
| **理解** | 数据意识、算法思维 | 数据采集、算法原理可视化 |
| **思辨** | 伦理反思、人机协作 | 伦理讨论、AI伦理案例 |
| **创造** | 智能系统设计制作 | 项目式AI创客制作 |

> 来源：中小学AI通识教育研究["https://blog.csdn.net/qq_23488347/article/details/161486408"]

### 2.2 AI通识教育内容维度（山东纲要）

- 智能体验、数据意识、算法思维、伦理反思、人机协作
- **智能创新设计**：探索具身智能、智能体领域创新设计，从感知/处理/决策/执行维度构建简易智能系统（需求分析→方案设计→原型搭建→测试优化）
- **智能社会责任**：AI对社会伦理、隐私安全、公平正义、就业结构的影响思辨
- 来源：山东省中小学人工智能通识教育教学指导纲要["http://edu.shandong.gov.cn/art/2026/7/30/art_107055_10348130.html?xxgkhide=1"]

## 三、生成式AI赋能创客教育

### 3.1 AI在创客项目全流程的介入

| 创客流程环节 | AI工具介入 | 教学价值 |
|-------------|-----------|---------|
| 创意构思 | 生成式AI头脑风暴、发散方案 | 激发创意、拓宽思路 |
| 设计表达 | AI文生图、文生3D、参数化设计 | 降低表达门槛 |
| 编程实现 | AI编程助手（代码生成/调试） | 聚焦问题解决而非语法 |
| 原型制作 | AI辅助排料、工艺建议 | 提升效率 |
| 测试优化 | 数据分析、AI检测 | 数据驱动迭代 |
| 作品呈现 | AI文案、演示生成 | 提升表达质量 |

### 3.2 教学设计驱动式AI编程（IDDAC）

> 人民教育出版社提出IDDAC：**教学设计驱动式AI编程**——教师以系统化教学设计为先导，通过结构化提示语驱动AI生成可执行代码。核心：教学逻辑、交互流程、教学策略、评估体系的整体设计**先于**代码生成。["https://www.pep.com.cn/bks/kcjcjf/xszh/202606/W020260616568341121609.pdf"]

**对创客教育的启示**：
- AI不是替代学生编程，而是让"设计意图"先行，AI辅助实现
- 教师角色从"代码讲解"转向"设计引导"
- 学生聚焦创新性、问题解决与评估

### 3.3 AIGC项目式学习案例（淄博）

> 真实任务驱动："为家乡设计文创产品"——利用AIGC技术，融合多学科，解决"创意实现难"的痛点。["https://edu.zibo.gov.cn/art/2026/5/27/art_6842_3004635.html"]

## 四、创客空间的AI教育产品线

### 4.1 分层次课程（面向职业院校+科普研学）

| 层级 | 对象 | 内容 | 空间配套 |
|------|------|------|---------|
| **AI通识体验** | 全体学生/科普研学 | AI应用体验、智能设备互动、伦理讨论 | AI体验区、机器狗/人形机器人演示 |
| **AI素养基础** | 非AI专业 | 数据意识、算法思维、低代码AI | 公共机房+AI平台 |
| **AI专业实训** | AI专业 | 机器学习、深度学习、视觉、大模型 | AI实训区+GPU算力 |
| **AI+专业融合** | 智能制造/新能源 | AI视觉质检、预测性维护、智能产线 | 跨区项目 |
| **AI创客项目** | 创新团队 | 智能硬件+AI Agent、具身智能开发 | 创客区+具身智能区 |

### 4.2 生成式AI教育工具建议

- 本地化部署教育大模型（数据安全合规，见AI实训区）
- 智能体工作台：学生创建自己的AI Agent完成项目任务
- AI编程助手：教学环境内的代码助手（防滥用需管理）
- 开源生态：参与AI开源社区，贡献与学习

## 五、教师智能素养建设

### 5.1 政策要求（五部门行动计划）

- 制定**教师智能素养标准**，分层分类培训全覆盖
- 构建情境化测评系统，规模化教师素养测评
- 将人工智能纳入教师资格考试和认证内容
- 国家/省级教学成果奖设智能教育项目

### 5.2 创客空间教师的AI能力清单

| 能力 | 说明 |
|------|------|
| AI工具使用 | 生成式AI、AI编程、智能教学系统 |
| AI教学设计 | 将AI融入创客项目课程（IDDAC思维） |
| AI素养教学 | 能讲授数据意识、算法思维、AI伦理 |
| AI+专业融合 | 能结合本专业（制造/新能源）设计AI应用实训 |
| AI风险管理 | 识别学术造假、隐私、过度依赖风险 |

## 六、AI伦理与安全（创客空间场景）

| 风险 | 管控 |
|------|------|
| 学术造假 | 明确AI使用边界，作业原创性审查 |
| 隐私泄露 | 数据本地化，不上传学生隐私 |
| 过度依赖 | 教学上"先思考后AI"，AI辅助而非替代 |
| 内容安全 | 教育大模型内容审核机制 |
| 应试内卷 | 评价转向能力与创造，而非AI速成 |

> 五部门行动计划明确：深化AI教育应用安全审核机制，健全AI评估备案、技术监测、风险预警、应急响应机制，防范伪造诈骗、学术造假、应试内卷、隐私泄露。["https://www.gov.cn/zhengce/zhengceku/202604/content_7065138.htm"]
