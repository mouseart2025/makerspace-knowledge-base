```
认知层 → 规划层 → 建设层 → 运营层 → 教育课程层 → 案例研究层 → 资源索引层 → 项目落地支撑

```

## 四、补充路线图（建议执行顺序）

```
第一阶段（高优先·直接支撑本项目）：
  1. 三专业典型实训项目库
  2. 三专业技能竞赛体系
  3. 职业院校实训基地案例集
  4. 风险与应急预案专项

第二阶段（中优先·深化运营）：
  5. 开源硬件与AI开发套件选型
  6. PPE与安全防护设备采购清单
  7. 对外服务与科普研学运营
  8. 师资队伍建设专项
  9. 数据驱动的智慧运营
  10. 开源软件工具链清单

第三阶段（低优先·前沿储备）：
  11. 绿色双碳制造 / 12. 低空经济无人机
  13. 制度模板文档库 / 14. Benchmark数据库 / 15. 供应商渠道
```

**执行原则**：
- 每个方向都遵循既有模式：检索→提炼→回写，标注来源与时效
- 优先产出"可直接用"的清单/模板/项目库，而非长篇论述
- 案例类文档重点补充**职业院校语境**（区别于现有社会创客空间案例）

> 📌 **逐项落地规划**：每个方向的调研发现、可落地内容、首选来源与补充路径，见 [逐项补充规划-基于资源调研.md](逐项补充规划-基于资源调研.md)。该文档已完成 15 项缺口的广泛资源调研（教育部/人社部/应急管理部政策、政府采购中标数据、院校公开案例、开源社区），并按 🔴🟠🟡 优先级给出执行顺序。

### 6.3 定期核验约定

- **时效敏感内容**（政策、标准、赛事、价格、Fab Academy 年度信息）建议**每 6 个月**核验一次，更新后登记到 6.1。

- 每次核验在文档内更新 `date`（frontmatter）与来源标注。
- 新增文档必须：① 带 frontmatter（六字段 `title`/`type`/`scope`/`source`/`date`/`tags`）；② 在 README 目录树登记；③ 在 GLOSSARY 检索索引补充术语映射；④ 在 6.1 登记。
